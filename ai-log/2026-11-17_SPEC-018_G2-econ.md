## 요약

- 실패 1(G3 비)과 실패 2(산업화 사망<0)는 **같은 뿌리**(1~3단계 vocational 효과)다. 실패 3(`autoEconomy` 9.90%p)은 **다른 뿌리 — 표본 잡음**이다: 잡음 없는 기대 차는 13.26 → 13.10%p로 그대로이고, 끈 엔진(off)도 다른 시드 묶음에서 8.13%p로 실패한다.

## 0. 측정 방법

- 표본: `check:economy`·`tests/economyBalance.test.ts`와 같다 — `playLife`와 같은 걸음(`scripts/economyCheckLib.ts`), 무작위 선택 `chooserFor('random', seed)`, 시드 `economySeed(i) = (i × 7368787 + 1009) >>> 0`, i = 1..6000, 세대마다 6000판. 40대 순자산 = 40~49세 사람-년 줄의 중앙값(`guardsOf`와 같은 식). 「econ」 묶음이 시험 표본이다.
- 잡음을 보려고 다른 시드 묶음 alt1·alt2(`(i × 2654435761 + k × 1000003) >>> 0`, k = 1·2, 각 6000판)를 산업화·알파에 더 돌렸다.
- 팔(arm) — 모두 같은 시드의 짝:
  - `off` = `withGateTogether(false)`(엔진 변경 전과 바이트 동일, 개발 기록 ⓪), `on` = 지금.
  - `null` = 켬 + G2 선택지 6개의 효과(stats·family·setFlags·bonuses)를 모두 뺀 풀(난수 소비는 같다). `bare` = null + `act`도 뺌(기질 성장 없음). 이 둘은 **G2 혼자 난 판에서도** 효과를 뺀다 — 그래서 「재추첨만」은 동반 판만 null 값으로 바꿔 끼운 표본으로 잰다(아래 「바꿔치기」).
  - `nofam`·`noflag`·`nostat` = 켬 + G2의 그 효과 하나만 모든 판에서 뺀 풀 — 처리안 (a)의 어림으로 쓴다.
- **바꿔치기 분해**: off 표본에서 동반 판(on에서 15세에 G2와 다른 선택 카드가 함께 난 판)만 null 판으로 바꾼 표본 = 「재추첨만」(G2는 났지만 효과 0, 난수 한 칸 밀림). off → 재추첨만 = 재추첨 몫, 재추첨만 → on = G2 효과 몫.
- 점검: 동반 아닌 판은 세 세대 모두 on과 off가 **판 단위로 같다**(다른 판 0) — 변화는 전부 동반 판에서 온다. on 값은 `check:economy` 출력과 같다(산업화 73,697 / 25,565 = 2.88, 알파 80,185 / 21,885 = 3.66). R1(지금 세상)은 G2가 풀에 없어 on = off(4.85배).
- 표준오차: 판 재표본 짝 부트스트랩(150~400회)과 **시드 묶음 사이의 퍼짐**을 함께 적는다. 중앙값의 부트스트랩 SE는 작게 나오는 경향이 있어, 판정은 묶음 사이 퍼짐과 판 평균 짝 차의 SE로 했다.

- 3: 실제 비율 차는 G2와 무관한 표본 잡음이다(끈 엔진도 alt4에서 8.13%p). 받아들이는 방법은 표본을 늘리거나(8000 → 16000판이면 SD 약 3 → 2%p, 시험 시간 약 2배) 임계를 낮추는 것(r1이 7%p로 낮췄다가 R-364로 되돌린 이력)인데, 둘 다 G2와 별개의 시험 설계 문제다. 기대 확률 차 시험(잡음 없음, 13.10%p)은 통과한다.
