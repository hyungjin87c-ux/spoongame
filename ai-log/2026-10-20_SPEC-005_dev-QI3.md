## 2. 해석·판단 (마스터 확인 대상은 7절에 따로)

1. **머리 = 워드마크(D5-01 A안)**. 요청서에는 로고 얘기가 없지만 diff-005 7절 D5-31(「워드마크(52px) → 배너 그림 224px」)과 형진 님이 본 시안 샷(`illust-r3-*.png`)이 워드마크 머리라서 같이 옮겼다. 세로·가로 로고(`LOGO_STACKED_SVG`·`LOGO_ROW_SVG`)는 첫 화면에서 쓰지 않는다(자산 파일은 그대로, `brandAssets` 상수만 지움). 워드마크는 선(stroke)으로 그려져 e2e 색 단언을 fill → stroke로 바꿨다.
2. **무거운 장면 가리기 스위치 = 렌더하지 않음**(마스터가 「애매하면 렌더하지 않고 보고」). SPEC HS3 ④는 슬롯 순서만 정하고 QI3에서 렌더할지는 말하지 않는다(diff-005 D5-07은 「자리와 값 저장」). 동작 없는 스위치를 사용자에게 보이지 않으려고 `GentleSwitch` 컴포넌트·CSS·문구(`TITLE_TEXT.gentle*`)와 `TitleScreen`의 `gentle?: { on, onToggle }` prop까지만 만들고 App은 넘기지 않는다 — QI6에서 `gentle`만 넘기면 인생 길이 아래 설정 줄에 나온다. 단위 시험(`tests/homeScreen.test.tsx`)이 prop을 주었을 때의 마크업을 본다. 설정 v5(`gentle`)도 이번에 만들지 않았다(SV2는 QI6).
3. **오른쪽 열은 flex가 아니라 block**(diff-005 8절): 시안의 `.title__side { display:flex; flex-direction:column }`는 sticky + `max-height` + 안쪽 스크롤 컨테이너와 만나면 flex 자식이 줄어 카드가 눌린다. block이면 시안 측정값이 그대로 재현된다(4절).
4. **분절 컨트롤 포커스 링은 칸에**(`.seg__opt:focus-within`) — 시안은 컨트롤 전체(`.seg:focus-within`). CM10 감사(`auditFocus`)가 링 주인의 한가운데에서 맞는 요소가 포커스 요소여야 한다고 보는데 컨트롤 전체의 한가운데는 이웃 칸이라 걸렸다. 거친 포인터에서 라디오 클릭 영역은 `top:-8px; height:calc(100% + 16px)`(WebKit은 `top`·`bottom`만으로는 `input`을 늘리지 않는다 — WebKit 시험이 잡았다). 폭 320 · 글자 200%에서는 두 칸이 두 줄로 접히고(`flex-wrap`) 칸 안 낱말은 끊기지 않는다(`word-break: keep-all` — 「30분」이 「30」/「분」으로 갈라지던 것을 `line-breaks.spec.ts`가 잡았다).
