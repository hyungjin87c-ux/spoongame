## 4. P6 판정 — **맞는 기대**

동작: 탭이 가려지면 해 시계가 멈추고(진행률은 그 자리에 머문다) 자동 선택 타이머도 걸리지 않으며, 다시 보이면 멈춘 자리에서 이어서 흐른다. 가려져 있던 30초는 세지 않는다(따라잡기 없음).

근거(코드)
- `src/App.tsx#usePageVisible`(`visibilitychange` → `visible`) → `useYearClock({ running: inLife && visible && !game.paused && … })`.
- `src/ui/useYearClock.ts#useYearClock`: `running`이 false면 효과 정리에서 타이머가 지워지고 `fraction`은 보존, 다시 켜지면 `last = performance.now()`로 새로 재서 **이어서** 흐른다(파일 머리 주석 10행).
- `src/ui/decisionFold.ts#autoChooseArmed`(`visible` 필요) → 선택지 앞에서도 자동 선택이 가린 동안 걸리지 않는다.
- 1배속 한 해는 조용한 해 8.75초 · 서술 해 21.25초 · 결과 해 16.25초(`src/data/timingTable.ts#HOLD_MS` × 30분 모드 계수 1.25). 시계가 안 멈췄다면 30초에 최소 1.4해에서 3해 넘게 지나므로, 이 점검은 의미가 있다.

근거(시험)
- `e2e/robust.spec.ts` "탭이 가려져 있는 동안은 진행이 멈추고, 다시 보이면 이어진다"(1배속·자동 모드·`?__timescale=20`: 가린 750ms가 한 해(약 0.44초)보다 길어도 저장이 변하지 않고, 보이면 다시 진행).
- `e2e/m4-dashboard.spec.ts` "일시정지 중 탭이 가려졌다 돌아와도 재개하지 않는다. 대조: …"(대조군: 일시정지가 아니면 같은 가림·복귀 뒤 시간이 흐른다).
- `tests/playClock.test.ts` "불변식: 연출 시계의 running이 참인 모든 상태는 hold이고 …"(시계 조건 `visible`과 자동 선택 조건을 256조합으로 대조)·"표의 핵심 칸: … 탭 가림 … = idle", `tests/decisionCollapse.test.tsx` "접은 동안에는 걸지 않는다 (다른 정지 조건과 같다: … 가려진 탭 …)".
- 상한: `tests/progress.test.ts`의 `advanceFraction` 시험("advanceFraction(비율, dt, 연출 시간): 시계가 흐르는 방식")이 보이듯 진행률은 1에서 막히고 해 시계는 한 번만 `onElapsed`를 부른다 → **어떤 경우에도 한 해 안쪽**.

세부(문구에 영향 줄 만한 것)
- 보통: 돌아왔을 때 나이는 **나갈 때와 같다**(진행 바가 멈췄던 자리에서 이어서 찬다).
- 드문 경우: 가림 이벤트를 처리하는 렌더보다 해 시계의 늦은 타이머가 먼저 돌면(앱 전환 직후 페이지가 멈췄다 풀릴 때) 가린 시간만큼이 한 번 반영돼 **한 살이 더 오를 수 있다**. 그래도 **두 살 이상은 불가능**하다(위 상한). 따라서 P6 문구 「한 살 넘게 뛰어 있지 않고」는 맞다. 점검자가 「한 살 올라 있음」을 실패로 읽을까 걱정되면 문구를 「나이가 나갈 때와 같거나 많아야 한 살 많고」로 다듬을 만하다(선택, 마스터 판단).
- 운영체제가 30초 사이 탭을 버려 다시 불러오는 경우: 나갈 때(`pagehide`·가림)의 저장(`src/App.tsx` 저장 `flush`)에서 이어서 열린다 — 나이는 같고 올해 진행 바만 0%부터(알려진 제한 QA M4-O01).
- 빈 곳(**새 시험 후보 1건, 지금 추가하지 않음**): 가림 이벤트 직후 페이지가 길게 멈췄다 풀리는 상황(M8 시험 `e2e/m8-playtime-save.spec.ts` "가려짐 이벤트 직후 메인 스레드가 7초 멈춰 …"·"실제 브라우저의 페이지 수명주기 동결 …"의 모사)에서 **나이(해 시계)**를 단언하는 시험은 없다 — 그 두 시험은 플레이 시간(hold/idle)만 본다. 필요하면 같은 장치로 「복귀 뒤 나이 ≤ 가리기 전 나이 + 1」을 단언하는 e2e 한 개(예: `e2e/m4-dashboard.spec.ts` 곁)를 더하면 된다. 구조상(상한 1) 통과할 것이라 1차 릴리스 차단 사유는 아니다.

## 5. 번들 크기 (W2 예비) — SPEC 완료 기준 13 「초기 로드 ≤ 400KB(gzip)」
