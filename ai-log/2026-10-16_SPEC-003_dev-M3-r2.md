## 2. 명세와 다른 점 (기록)

- **R-267 주거 3칸(코드 변경 없음)**: SPEC BR2는 「자가·전세·월세·반지하 등」인데 구현은 「자가 / 임차(전세·월세) / 무상 거주」 3칸이다. 이유: 전세·월세 구분 통계(`s-037`)가 아직 출처 확인이 안 됐다(`koreaStats.json` 해당 지표 미확인). 마스터 결정(REV-003-M3-1)으로 1차는 3칸 유지, SPEC에 반영됨, 전세·월세 구분은 **M5(경제) 착수 조건**으로 `s-037` 수집을 이월. 시안(`docs/design/mockups/birth.html:64`의 「월세 · 다세대주택」)과의 차이는 R-270(designer)의 구현-시안 차이 목록에서 다룬다.
- **임차 이름의 쉼표**: 화면 이름을 「임차(전세·월세)」에서 「임차(전세, 월세)」로 바꿨다(`birthReportTable.ts#HOUSING_LABEL`). SPEC 문구는 3칸의 뜻이고 화면 글자는 정하지 않았다. 가운뎃점이면 R-262 표본(글자 150~200%)이 「임차(전세·」가 줄 끝에 혼자 남는 것을 잡았다 — QM2-10 규칙 2(한 줄을 넘을 수 있는 나열은 쉼표 나열)를 따랐다. 뜻은 같다.
- **기대수명 서술의 위치**: 마스터 결정은 「모든 단계에 같은 한 줄 서술」인데, R-263(지난·다가올 세상은 비교 표 숨김)과 함께 **비교 카드 안(표 아래)**에 두어 지난·다가올 세상에서는 서술도 함께 숨는다(2017년 지금 통계라 그 시대 가정과 견줄 수 없다는 같은 이유). 지금 세상 5단계 모두에 같은 글이 나간다.
- **시안과 다른 점 추가**: 출생신고 비교 표 행이 3행(사교육 참여율·월평균 사교육비·자기 집)이고 기대수명 서술이 표 아래 한 줄, 또래 목록에서 성별이 이름 옆 「여성/남성」·칩이 좁은 폭에서 이름 아래, 지난·다가올 세상에는 비교 카드가 없음 — 시안 갱신은 R-270(designer).

## 4. R-265 부모 나이 — 방법과 측정

### 방법 (`src/data/parentAgeModel.ts`, 순수 계산)
1. **구간 비중은 그대로**: 구간별 출생아 수에서 나이별 확률을 만들고(구간 안 모양은 이웃 구간 밀도를 이은 선, 구간 합은 공표 비중으로 다시 맞춤), 평균이 공표 평균과 어긋나면 **구간 안에서만** 기울여(`exp(λ·(나이 − 구간 가운데))`) 맞춘다. 구간 합은 안 변한다.
2. **형제 순서·수저 단계 차이도 같은 방식**: (출산 순위 3 × 수저 5단계) 15개 집단의 어머니 나이 분포를 목표 평균(공표 순위별 33.2·34.7·35.8, 수저 단계는 설계 차이 −1·0·0·+1·+1에서 비중 가중 평균을 뺀 값)에 맞추되, 집단을 비중대로 합치면 전체 분포와 정확히 같도록 IPF(반복 비례 보정). 그래서 어떤 집단 구성에서도 전체 구간 비중·평균이 공표값이다.
3. **아버지**: 전체 분포는 1번 방식(공표 구간 비중·평균 36.1), 어머니와의 나이 차(−4~+15) 범위 안 조합만 가진 결합 분포를 IPF로 만들어 어머니 나이의 조건부로 뽑는다. 옛 「어긋나면 다시 뽑기」(최대 12번)와 「나이 차 2살씩 안쪽 받기」(`FATHER_GAP_DRAW`)는 없어졌다.
4. 시대 보정(지난 −6살·다가올 +1살)은 두 부모에게 같은 살수를 더하고 허용 범위(16~56)로 맞춘다 — 나이 차는 그대로(범위 맞춤으로 나이 차가 범위 밖이 되지 않음을 시험).
5. 모델 만드는 시간 약 20ms(처음 쓸 때 한 번). 추첨 난수는 어머니 1·아버지 1(옛 방식은 가변). 갈라낸 RNG라 인생 RNG·`finalDistribution`에 직접 영향은 없다(부모 나이를 읽는 사건 조건을 통해서만 간접 영향 — 6절).

2. **시안 갱신 필요(R-270, designer, M3 승인 뒤)**: 이번 r2에서 화면이 시안과 더 달라진 곳 — 비교 표 3행·기대수명 서술 한 줄·지난/다가올 세상은 비교 카드 없음, 또래 목록(성별 이름 옆, 칩 아래로), 「태어난 곳」 좁은 화면 한 줄, 문서 띠 오른쪽 표기가 좁으면 제목 아래로, 도장이 본문 위쪽 모서리 기준, 임차 이름 쉼표.
3. **부모 나이 모델은 설계값을 얹은 것**: 수저 단계 차이(−1·0·0·+1·+1)와 나이 차 초기 모양(`FATHER_GAP.peak/spread`)은 설계값이고 통계에 없다. 아버지의 순위별 공표 평균(첫째 35.4)은 직접 맞추지 않고 어머니와의 결합으로 따라온다. 모델은 `Math.exp`를 써서 엔진마다 마지막 비트가 다를 수 있다 — 저장은 결과 값을 저장하므로 영향이 없고, 같은 시드의 재현은 같은 엔진 안에서 보장된다(시험은 모두 같은 엔진).
4. **전세·월세 구분(s-037)**: M5(경제) 착수 조건으로 이월(마스터 결정). 시안 「월세 · 다세대주택」과의 차이는 R-270에서.
5. **실기기·WebKit·스크린리더·실제 Windows 고대비 팔레트**: M9 목록(그대로).
6. **e2e 한 번의 불안정**: 전체 e2e 첫 번째 최종 실행에서 `e2e/first-screen.spec.ts` 「낮은 데스크톱 창(1280x620)에서 키보드로 카드 안쪽을 끝까지 내릴 수 있다 (R-224)」가 PageUp 뒤 `scrollTop`이 0이 아닌 15로 한 번 실패했다(첫 화면 스크롤 시험이라 이번 변경과 무관). 같은 시험을 5번씩(총 10개) 단독으로 돌리면 모두 통과하고, 그 앞선 전체 실행에서도 통과했다 — 병렬 부하에서 스크롤 완료를 기다리는 시험의 흔들림으로 본다(아래 7절 두 번째 실행 결과).
