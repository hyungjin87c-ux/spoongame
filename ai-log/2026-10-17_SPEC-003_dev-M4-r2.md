## 2. 설계 판단 (정직 보고)
- **R-328 (또래)**: 처음에는 「이전 상태를 확률로 이어받기」(Markov)를 만들었다가 표 분포가 심하게 틀어졌다(수저 2단계 27세의 「학교에 다님」이 표 6%인데 68%로 남음 — 이어받은 상태가 표가 바뀌어도 그대로라서). 인생 운 u를 블록마다 이어받고 **표에 u를 대 보는** 방식(copula)으로 바꾸니 21세처럼 상한에 걸릴 수 없는 나이는 표와 정확히 같다. 「구직 중」 상한은 세 변형을 재 보고 골랐다 — ① 상한 뒤 한 해만 막기: 분포는 표와 같으나 「4년 구직 중 → 1년 → 4년 구직 중」이 반복돼 흙수저의 **32.7%**가 어떤 10년 창에서 8년 이상 「구직 중」(고정관념 재발) ② 운을 새로 뽑기: 흙수저 27세 「구직 중」 28% → 17%로 표에서 크게 벗어남 ③ **채택: 상한에 걸린 해부터 4년(=블록)은 같은 u를 「구직 중」을 뺀 가중치에 대 봄** — 8년/10년 창 **0.2%**, 대가로 상한이 걸릴 수 있는 나이의 「구직 중」이 표보다 조금 적다(흙수저 35세 표 14% → 약 8%). 표는 설계값이고 마스터 기준(평생 미취업 ≤ 5%, 최장 연속 ≤ 4년)을 구조적으로 지킨다 — 실측 평생 미취업 0.00~0.02%, 최장 연속 4. 표본 시험의 허용 오차를 상한 없는 나이는 3%p, 걸릴 수 있는 나이는 7%p로 둔 이유다. 마스터가 표 분포를 더 우선하면 `PEER_SEEKING_COOLDOWN_YEARS`를 1로 줄이면 되지만(분포는 표와 같아지고 반복이 33%로 돌아온다) 권하지 않는다.
- **R-330 (형제)**: 생성기(`rollParentAges`)가 어머니 16~17세에 둘째 이상을 드물게 만든다(18000판 중 약 0.24%, 43판 — 최소 간격 2살로도 한도에 못 들어간다). 이 판은 출생신고 문장의 「둘째입니다」와 식구 카드의 위 형제 수가 어긋난다 — 불가능한 형제를 보이는 쪽보다 보이지 않는 쪽을 택했다. 근본 수정은 출생 생성기를 건드려 모든 시드의 결과(RNG)가 바뀌므로 M4 범위 밖이다 — **마스터 결정 필요**(7절).
- **R-321 (대시보드 이름)**: 이름 h1은 기본이 본문과 같은 크기(`--fs-md`)라 줄일 상한이 없다 — 상한을 걸면 본문보다 작아진다. 대신 이름·나이 알약을 `flex-wrap`으로 두고, 이름이 성 1글자 + 풀의 이름(최대 4글자)임을 단위 시험으로 잠가 폭 320 · 글자 200%의 한 줄(9글자)에 든다는 전제를 지킨다. 밀린·오류 화면의 상한 바닥은 `--fs-md`(본문과 같은 크기) — 폭 320 · 글자 200%에서 카드 내용 폭 246px이라 바닥을 `--fs-lg`로 두면 「바뀌었습니다.」(7글자)가 252px로 넘친다. 이때만 제목이 본문과 같은 크기이고 굵기·색으로 구분된다.
- **R-326 (생각 남기기)**: 버튼은 `aria-disabled`라 포커스는 받고(낭독 사용자가 이름과 이유를 듣는다) 입력은 무시한다. 시각 표식 「준비 중」은 라디오 카드 「약 1시간」의 메타 알약과 같은 모양이다. 도구 줄 버튼이 360px에서 64px → 83px(+19px)로 높아진다(실측) — 마음에 안 들면 designer가 알약 모양·여백을 조정한다.
- **R-325 (BGM)**: 입력 핸들러가 `touchend`/`pointerup` 안에서 곧바로 `createBgm()`·`start()`·`resume()`을 부른다(React 효과를 기다리지 않는다). 사용자 활성화가 없어 거절됐거나 iOS가 중단한 장치(`suspended`·`interrupted`)는 다음 입력마다 `resume()`한다. e2e는 실제 Chromium의 장치 상태를 본다(`running`) — 실기기 모바일 자동재생 정책 자체는 기계로 못 본다.

## 6. 구현 중 알게 된 것 (정직 보고)
- **셸 heredoc의 역슬래시 반감**: 로그 dev-M4가 적은 함정이 다시 있었다(`\d`가 `\`로 줄어듦). 정규식·이스케이프가 든 패치는 쓰기 도구로 스크립트 파일을 만들어 실행했다.
- **Python 텍스트 모드 쓰기는 Windows에서 LF를 CRLF로 바꾼다**: 패치 스크립트가 파일 29개를 CRLF로 바꿔 놓은 것을 변이 스크립트가 못 찾아서 알았다 → 내가 건드린 파일만 LF로 되돌렸다(`.gitattributes`는 `text=auto eol=lf`라 저장소 내용은 어차피 LF). 이후 패치는 `newline=''`로 읽고 썼다.
- **내가 만든 시험의 오류 두 건**을 실행으로 고쳤다: ① 밀린 화면 제목은 6낱말(7이라 적었다), ② 오류 화면 메시지는 상한 없이도 폭 320 · 글자 200%에 들어가(「생겼습니다.」 229px < 246px) 「상한을 빼면 갈라진다」 대조는 밀린 화면에만 성립한다.
- `scripts/design/buildMockups.mjs:508`이 읽는 `DASH_TEXT.noteSoon`을 삭제했다(생각 남기기 안내가 없어졌다). 시안 생성기는 designer 몫이라 건드리지 않았다 — 지금 다시 생성하면 `?state=tools` 시안에 「undefined」가 찍힌다(7절).
