## 1. 스프라이트 — 추가한 id 셋 (`src/assets/icons/ui-icons.svg`)

- **`i-proj`**(심볼 19번째, 24×24): 실선 꺾은선 `M3 17l5-6 4 3 4-5` + 점선 이음 `M16 9h3.5v3.5`(2.5 1.8) + 점선 바닥 `M3 20h18`(2 2). fill·색·style 속성 없음 — 다른 선 아이콘처럼 바깥 `svg.icon`의 `stroke: currentColor`를 따른다(칩 14px·`stroke-width 2.4`, 강제 색상 CanvasText). 시안 `title-005.html` 인라인 심벌과 같은 글자.
- **`hatch`**(pattern 6×6 `userSpaceOnUse` `rotate(45)`, line 2.2) = **「전망」 전용** 놋쇠 빗금(폭염 전망 막대 `.chart-bar--proj`·범례 `.swatch-rect--proj`). **`dots`**(pattern 5×5, circle r 1.1) = 아기 누적 막대 65세 이상 칸 `.chart-seg--old`·범례 `.swatch-rect--old`, 중립 잉크색(R-477).
- **둔 곳 — 차트 SVG 안 `<defs>`가 아니라 스프라이트 `ui-icons.svg`의 `<defs>`**(심볼 뒤, 파일 끝). 15절 「무늬의 뜻은 캐러셀 전체에서 하나」와 맞는 한 곳 정의: 슬라이드 20장이 DOM에 함께 있어도 id 중복 0, 강제 색상 규칙 `#hatch line`·`#dots circle`의 대상이 하나. `fill: url(#hatch)`는 같은 문서 안 pattern만 참조하므로 `SPRITE_SVG`가 문서에 한 번 인라인되는 것으로 충분하고, `patternUnits="userSpaceOnUse"`라 `.sprite` 상자 0×0과 무관하다(`display: none`이 아니라 paint server가 산다). **developer: `brandAssets.ts` 변경 없음**(`iconsRaw`에 이미 포함), 차트 SVG에 `<defs>`를 넣지 않는다. 결정은 `diff-005.md` D5-69 r3 한 줄 + `design-system.md` 15절 머리.
- **색**: `<pattern>`의 `style="color:var(--c-accent,#8a6a14)"` / `var(--c-text-2,#4f4a41)` + 내용 `stroke="currentColor"`/`fill="currentColor"`. 시안 인라인은 `<line style="stroke:var()">`였는데 바꾼 까닭 — 무늬 내용은 참조한 rect가 아니라 pattern의 **조상**에서 상속받으므로 색을 pattern 자신에게 두어야 하고, `color`는 강제 색상에서 브라우저가 시스템 색으로 강제하는 속성이라(인라인 style 특이도와 무관) 두 무늬가 CanvasText가 된다. tokens.css도 `--c-accent`·`--c-text-2`를 CanvasText로 두므로 이중 안전. 속성 안 `var()` 없음(REV-003-D-4), 폴백 밖 고정 색 없음. 시안 77행도 같은 글자로 고쳐 자산 = 시안(도형·간격 불변).
