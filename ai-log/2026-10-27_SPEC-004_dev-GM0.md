## 3. 측정하며 알게 된 것 (마스터 확인 필요)

1. **AL10 ①(알파 경로 엔트로피 ≥ 밀레니얼의 1.5배)은 지금 정의로 달성할 수 없다.** 941판 표본에서 25칸 경로가 이미 약 82%가 서로 다르고 엔트로피가 표본 상한(log2 n = 9.88비트)의 95%라서 최대 약 1.06배다. 정의를 바꿔야 한다(나이별 5축 벡터 엔트로피 평균 4.3~4.6비트 등).
2. **AL10 ②·③ 기준 숫자**: X 대리 N잡이 이미 17.3%(엄격), 정석 4단이 X·밀레니얼 대리에서 3~4%(AL10식 3.5 / 4.2%, auto는 8.6 / 11.8%)다. SPEC의 「X ≤ 15%」·「X·밀레니얼 ≥ 35%」와 맞지 않는다. 지금 모델은 일 슬롯이 없어 선택·플래그로 대리한 값이라 GM9에서 같은 정의로 다시 재야 한다. 「겸업 플래그」 대리값(25~28%)은 「사업을 시작한다」 선택이 취업 플래그를 지우지 않아 부풀려진 값이라 참고로만 적었다.
3. **번들 여유 26.6KB**(WebKit PC)와 SPEC 완료 기준 18의 해석(400KB 고정 대 +100KB). 지금 JS gzip의 38%가 JSON 데이터 4덩어리(koreaStats 50KB·이벤트 31KB·인용 31KB·이름 7KB)이고 `EVENT_POOL`이 core 5곳에서 정적 import라 지연 로드에 구조 변경이 필요하다. `initial-load.spec.ts`는 networkidle + 1.5초 안의 모든 응답을 세므로 미리 받기를 쓰면 합계에 들어간다.
4. **TL13의 4초 가정은 모델 상수와 어긋난다.** 조용한 해에 연표 줄이 앉으면 해가 서술 해(28.7초)가 되어 +16.9초, 사건 있는 해에는 줄당 +8.4초다. 목표 12줄/판은 4초 가정(0.8분)에서는 여유(1.6~2.0분)에 들지만 모델 상수로는 2.6분이다. 연표 줄이 연출 타이머(`holdMsFor`)에 주는 영향을 GM1에서 정해야 한다. 카드 수 판정 하한까지 덜어 낼 수 있는 카드는 0.6~1.8장뿐이다.
5. **시대 제한 이벤트 33개 중 22개**(지금·다가올 제한 영유아·학창 소재 등)는 지금·다가올 출생이 사라져 어느 세대에도 후보가 아니다 → MG2 `yearRange` 전환 때 컷 연도(1995 / 2000 / 2005)와 `infant-care-alert`·`infant-talking-toy`(알파 영유아기는 실제 구간이라 쓸 수 없음) 처리가 필요하다.
