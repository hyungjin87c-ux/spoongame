# 2026-11-08 SPEC-014 spec — 결정 줄 질문 문장 (초안 r1)

- 누가: planner (마스터 지시 — SPEC-013 r2 작업에 이어). 쓴 파일은 `docs/spec/SPEC-014-질문문장.md`(새)와 이 로그뿐이다. `src/`·`tests/`·`scripts/`·`docs/TODO.md`·`docs/design/*`·`docs/data/*`·다른 SPEC은 읽기만 했고 커밋하지 않았다. 도구는 읽기·검색·파일 쓰기뿐이라 시험·측정을 돌리지 못했다 — 수치는 저장소 값에서 직접 계산한 **손계산(▲)**이다.
- 무엇을: 형진 님 Q2 (나) 「별도 SPEC-014로 나누고 같은 배포에 싣는다」를 받아, 인생 기록 결정 줄의 질문을 사건 제목에서 「…할까?」 꼴 문장으로 바꾸는 SPEC 초안을 썼다. 항목 QS1~QS5, 완료 기준 11항, 마스터 질문 Q1~Q3(추천 포함), 가정 G1~G5.
- 읽어서 확인한 것
  - 결정 줄 저장은 `life.ts#resolveChoiceCore` **한 곳**(본인·부모·흘러감이 모두 지남). 줄 필드: `title`≤60·`choice`≤80·`text`≤400·`eventId`·`by`. `appendHistory/clipEntry`는 `{...e}` 복사 + `title`·`choice`만 자름(새 필드는 길이 상한을 직접 더해야 함).
  - **`storage.ts#isHistory`는 모르는 필드를 막지 않는다**(`age`·`kind`·`text`·`title`·`choice`·`eventId`만 검사). `by`·`gentleUsed`는 **선택 필드 + `SCHEMA_VERSION` 9 유지 + 이상 값은 그 필드만 버림**(`withValidBy`·`withValidGentleUsed`)의 선례. 스키마 버전을 올리면 v8 이하처럼 새 게임으로 시작 — 이어하기가 통째로 사라지므로 올리지 않는다.
  - 선택지 이벤트 94개(infant 15·school 17·youth 22·middle 22·senior 18), 서술 이벤트 약 50개는 질문 불필요. 이벤트 JSON은 `import.meta.glob(…, { eager: true })`로 **초기 로드에 들어간다**(gzip +3~4KB▲).
  - 카드 읽기 글자 수는 판 길이 모델의 입력(`life.ts` 567행) — 선택지 카드 문구를 바꾸면 재측정이 필요해 이번 범위에서 뺌.
  - 화면: 인생 기록은 SPEC-012 QF4로 이미 「제목 → 고른 길 → 결과」(`LogList.tsx` 67~71행 판정), 엔딩 연표는 제목 굵게 → 고른 길 → 결과.
- 설계 요지
  - **저장 방식(Q1 추천 (가))**: 새 선택 필드 `HistoryEntry.question?`(`EventDef.question?`를 `resolveChoiceCore`가 있을 때만 기록), `maxQuestionLength` 60▲, `isHistory` 검사 + `withValidQuestion`(이상 값은 필드만 버림), **`SCHEMA_VERSION` 9 유지**. 옛 줄은 제목 그대로(소급·풀 조회 안 함 → `save→load→save` 바이트 동일). 새 저장을 옛 앱이 열어도 필드를 무시해 열림(코드 확인) → **위험도 Two-way / 파급 중간**(스키마 버전을 올리면 One-way이므로 올리지 않음).
  - **범위(Q2 추천 (나))**: 인생 기록 + 엔딩 연표. 선택지 카드는 판 길이 입력이라 제외.
  - **문장 규칙**: 「…할까?」 한 문장 ≤ 30자▲, 사람 주어 0(본인·부모·흘러감 모두 읽힘), 상황 되묻기·새 사실 0, 중립(선택지 문구 반복·결과 암시·평가·계층어 0), 무거운 장면은 사실 서술 수준·자해 암시 0(109), 시대·나이 일치, 94개 유일, 글꼴 조각 안.
  - **승인(Q3 추천 (가))**: 생애 단계 5묶음 전수 승인, infant(15)를 첫 묶음으로 말투 확정. 코드는 문장 승인을 기다리지 않음(합성 데이터). 일부 묶음만 승인돼도 코드는 안전(없으면 제목)하나 배포 기준은 94개 전부.
  - **레인**: 정밀 2(QS1 저장·검증, QS5 검수·QA·배포) · 표준 1(QS2 화면) · 경량 2(QS3 문장 94개 + 형진 님 묶음 승인 게이트, QS4 문서·새 소식).
