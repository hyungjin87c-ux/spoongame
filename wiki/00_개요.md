# 수저 게임 — 큰 그림

**한 줄**: 태어날 때 받은 '수저'(부모 재력·교육, 외모, 시대)로 시작해 한국식 인생을 사는 웹 시뮬레이션 게임.
**벤치마크**: 80억분의 1 (1in8b.life) — 구조·흐름만 참고, 그래픽·로고·고유 문구는 복제하지 않는다.

## 게임 요약 (2026-10-20 기준)
- **플랫폼**: 서버 없는 웹 게임 (모바일 360px~데스크톱) · GitHub Pages 배포 · 진행은 브라우저에 자동 저장 · 1차는 서비스 워커 없음(오프라인 새로고침 불가)
- **첫 화면**: 「{N}명이 이 시뮬레이션 속에서 각자의 삶을 살고 있어요.」(브라우저 안 가상 인구) · 통계 캐러셀 · 하단 고정 「태어나기」 · 세상·인생 길이 고르기
- **시대**: 지난 세상 1950~1989년생 · 지금 세상 2026년생 고정 · 다가올 세상(2차 계획 「2026년생 + 공식 전망」)은 SPEC-004 세대 7종으로 대체
- **출생**: 「태어나기」 → 수저·지역 룰렛 → 출생신고 서류 · 수저 5단계(흙·동·은·금·다이아몬드) 직접 표시 · 외모는 「상위/하위 약 N%」 · 이름은 법원 통계에서 랜덤
- **인생 화면**: 대시보드 한 화면에서 해마다 진행 · 구성은 [01_시스템_지도](01_시스템_지도.md)
- **경제**: 20세부터 순자산·연 소득·부채를 원 단위로 보이고, 해마다 소득·생활비·이자가 흐른다. 선택지마다 「자산 ▼▼ · 부채 ▲」식 영향 줄이 뜬다. 20세 전은 「집안 살림」으로 센다.
- **선택**: 선택지는 중대 결정 카드로 뜬다. 맞는 통계·연구 인용이 있으면 붙지만, 인용은 선택을 권하거나 말리지 않는다. 자동 모드를 켜면 시트 대신 인라인 카드로 뜬다.
- **기록**: 도구 줄 「생각 남기기」로 적는 한 줄(글은 이 기기에만 저장) · 나이에 맞춰 저절로 뜨는 기록 카드 7종(판당 최대 7장). 기록은 인생 결과를 바꾸지 않는다.
- **진행**: 0세~사망, 1년 단위 · 사연 이벤트 140개 (선택지 90 · 서술 50) · 판당 결정 카드 23.3~29장(30분 모드 판정) · 인생 길이 약 30분(1차, 실측 통과 10-20) / 약 1시간은 준비 중(2차)
- **엔딩**: 담담한 회고. 출발선 막대 · 최종 순자산 금액 · 이 판의 플레이 시간 → 다시 태어나기
