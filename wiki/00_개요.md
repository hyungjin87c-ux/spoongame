# 수저 게임 — 큰 그림

**한 줄**: 태어날 때 받은 '수저'(부모 재력·교육, 외모, 시대)로 시작해 한국식 인생을 사는 웹 시뮬레이션 게임.
**벤치마크**: 80억분의 1 (1in8b.life)

## 게임 요약 (2026-10-15 기준)
- **플랫폼**: 서버 없는 웹 게임 (모바일 360px~데스크톱) · 한 판 10~30분 · 진행은 브라우저에 자동 저장
- **시대**: 지난 세상 1950~1989년생 / **지금 세상 2008~2025년생 (기본)** / 다가올 세상 2030~2060년생
- **출생**: 부모 재력(5단계)·교육방식·외모를 담담하게 표시 (순위는 "우리나라 출생아 중 상위 몇 %"). 이름은 입력 없이 랜덤 차용, 다시 뽑기 없음
- **진행**: 0세~사망, 1년 단위. 사연 이벤트 **112개** (선택지 78 · 서술 34), 판당 선택지 약 **23개**
- **연출·속도**: 1배속 기준 조용한 해 7초 · 선택 결과 뒤 13초 · 서술 이벤트 17초. 1·2·4·8배, 다음 결정으로, 자동 모드 (선택지에서는 멈춤, 자동 제외)
- **엔딩**: 담담한 회고. 출발선은 "상위 N~M% 사이" 구간으로, 도착은 같은 시대 분포표 기준 자리로 보여 주고 앞섬·비슷함·뒤쪽으로 정리 → **다시 태어나기**
