# 시스템 지도

**한 판 흐름**: 첫 화면(세상·인생 길이 고르기, 통계 캐러셀) → 「태어나기」 → 수저·지역 룰렛 → 출생신고 서류 → 인생 화면(0세~사망) → 사연 이벤트·선택 → 회고 엔딩 → 다시 태어나기
(인생 화면의 「나가기」 → 첫 화면 「이어서 살기」로 복원. 별도 시대 선택 화면은 없다. 첫 화면이 맡는다.)

## 인생 화면 (대시보드, M4·M5)
| 구역 | 내용 |
|---|---|
| 헤더 | 게임명 로고 · 이름 · 나이 · 올해 진행률 바 |
| 재생 | 일시정지 · 배속 1·2·4·8 · 다음 결정으로 · 자동 모드 |
| 도구 | 칩튠 BGM(기본 꺼짐) · 생각 남기기(준비 중, M7c) · 다크(수동) · 의견 보내기(GitHub 이슈) · 나가기 |
| 프로필 | 나이별 얼굴 96px · 외모 「상위/하위 약 N%」(점수 없음) · 출신 가정 칩 |
| 상태 | 건강·행복·지식·관계 4색 · 자산 카드(20세부터 순자산·연 소득·부채, 원 단위 · 20세 전은 「스무 살부터 셉니다」 문구) |
| 선택지 | 선택지마다 영향 줄(변화 있는 항목만 · ▲▼ 개수 = 크기 · 색 = 이로움·해로움) · 안내 한 줄 |
| 인생 기록 | 해마다 쌓이는 한 줄 기록 · 위로 올려 읽어도 자리 유지, 「새 기록」으로 맨 아래 복귀 |
| 식구 | 부모(나이·상태) · 형제(N째) · 배우자·자녀(20세 전엔 없음) |
| 같은 해 태어난 사람들 | 또래 4명 · 수저 칩 · 「요즘 모습」(나이대별 재추첨) |

## 경제 모델 (M5)
금액은 내부 만 원 정수, 화면은 원 단위다. 지난·다가올 세상 금액 옆은 「지금 가치로 환산」.

| 자리 | 위치 | 하는 일 |
|---|---|---|
| 해마다 계산 | `src/core/economy.ts` | 순자산 = 전년 + 소득 − 생활비 − 주거비 − 의료·돌봄 − 이자. 모자라면 부채가 자동으로 늘어난다 · 생활비 차입 한도 · 65세 이상 노년 안전망 |
| 선택 적용 · 영향 줄 | `src/core/apply.ts` · `impact.ts` → `src/data/impactText.ts` | 영향 줄 데이터와 실제 적용이 같은 경로(표기 = 실제, 숨은 효과 0) |
| 간이 상속 | `src/core/inherit.ts` | 부모가 모두 떠난 해 끝에 한 번, 형제 수로 나눠 더함. 인생 기록 한 줄, 영향 줄에는 없음 |
| 계수 | `src/data/economyTable.ts` | 통계 근거와 설계값을 구분해 적음 · 설계 문서 [economy-model](../docs/data/economy-model.md) |
| 밸런스 점검 | `scripts/economyCheck.ts` (`npm run check:economy`) | 가계금융복지조사와 견줌 · 허용 밖은 보고 |
| 저장 | v8 | 재산 스탯 폐지 · 20세부터 `assets`, 20세 전은 `familyFund`(집안 살림) |
