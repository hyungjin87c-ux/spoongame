# 시스템 지도

**한 판 흐름**: 시대 선택 → 출생(수저·이름·외모) → 0세~사망 나이별 진행 → 사연 이벤트·선택 → 회고 엔딩 → 다시 태어나기

| 영역 | 위치 | 하는 일 |
|---|---|---|
| 순수 로직 | `src/core` | 출생 뽑기·스탯·인생 진행·사연 조건·엔딩 계산·저장. 화면 없이 테스트 |
| 사연 이벤트 | `src/data/events` | 생애 단계별 JSON 5개 파일, 112개. 코드 수정 없이 추가 |
| 데이터 | `src/data` | 시대별 출생 연도·이름 풀·금지 조합·문구 |
| 원자료 | `src/data/sources` | 법원 이름 통계 수집본 (이름 풀의 근거) |
| 화면 | `src/screens`, `src/ui` | 타이틀·시대 선택·출생·진행·엔딩·다른 탭 안내·오류 화면, 공용 버튼(연타 방지) |
| 진입 | `src/App.tsx` | 화면 전환과 저장 연결 |
| 테스트 | `tests` (vitest), `e2e` (Playwright) | 단위 테스트, 브라우저 시나리오 |

**검증 도구** (`npm run`): `check:todo` TODO 근거 대조 · `check:dist` 엔딩 분포표 · `sim:1000` 1000판 시뮬레이션
