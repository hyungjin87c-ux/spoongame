# 시스템 지도

**한 판 흐름**: 첫 화면(세상·인생 길이 고르기, 통계 캐러셀) → 「태어나기」 → 출생(수저·지역·이름·외모) → 0세~사망 나이별 진행 → 사연 이벤트·선택 → 회고 엔딩 → 다시 태어나기
(별도 시대 선택 화면은 없다. 첫 화면이 맡는다.)

| 영역 | 위치 | 하는 일 |
|---|---|---|
| 순수 로직 | `src/core` | 출생 뽑기·스탯·인생 진행·사연 조건·엔딩 계산·저장. 화면 없이 테스트 |
| 사연 이벤트 | `src/data/events` | 생애 단계별 JSON 5개 파일, 112개. 코드 수정 없이 추가 |
| 출생 데이터 | `src/data/birthTable.ts`, `names`, `forbiddenNames` | 시대별 출생 연도·가중치, 이름 풀, 민감 인물 동명 금지 |
| 통계·인용 | `src/data/koreaStats.json`·`citations.json` → `koreaStatsAccess.ts` | 지표 50개(확인 43·미확인 7)·인용 59건. 화면은 접근 함수만 쓴다 |
| 근거 문서 | `docs/data/` | 통계 근거, 생애 단계별 데이터 소스, 소재 유형(128개, 2차 M7 사용) |
| 디자인 | `docs/design/` | 디자인 시스템, 심볼·얼굴·수저 아이콘, 시안 |
| 화면 | `src/screens`, `src/ui` | 첫 화면·출생·진행·엔딩·오류 화면, 하단 고정 띠, 공용 버튼(연타 방지) |
| 진입·배포 | `src/App.tsx`, `.github/workflows/deploy.yml` | 화면 전환·저장 연결. main 배포는 검수 승인분만 |
| 테스트 | `tests` (vitest), `e2e` (Playwright) | 단위 테스트, 360px·데스크톱 브라우저 시나리오 |

**검증 도구** (`npm run`): `check:todo` TODO 근거 대조 · `check:basis` 근거 문서 대조 · `check:motifs` 소재 원문 겹침 점검 · `check:dist` 엔딩 분포표 · `sim:1000` 1000판 시뮬레이션
