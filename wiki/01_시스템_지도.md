# 시스템 지도

**한 판 흐름**: 첫 화면(세상·인생 길이, 통계 캐러셀) → 「태어나기」 → 수저·지역 룰렛 → 출생신고 → 인생 화면(0세~사망) → 사연 이벤트·중대 결정 카드·기록 카드 → 회고 엔딩 → 다시 태어나기. 인생 화면 「나가기」 → 첫 화면 「이어서 살기」.

## 인생 화면 (대시보드)
| 구역 | 내용 |
|---|---|
| 조작 | 헤더(이름·나이·진행률) · 재생(일시정지·배속·다음 결정·자동 모드) · 도구(BGM · 생각 남기기 · 다크 · 의견 보내기 · 나가기) |
| 정보 | 프로필(얼굴 · 외모 「상위/하위 약 N%」, 점수 없음) · 상태 4색 · 자산(20세부터 원 단위, 20세 전은 「집안 살림」) |
| 선택 | 중대 결정 카드(제목 · 상황 · 인용 · 선택지) · 영향 줄(변화 있는 항목만 · ▲▼ 개수 = 크기 · 색 = 이로움·해로움) · 안내 한 줄 |
| 기록·사람 | 인생 기록(해마다 한 줄, 기록 카드·수동 기록 포함) · 식구 · 또래 「같은 해 태어난 사람들」 |

|---|---|---|

| 저장 검증 | `src/core/storage.ts` | 게임이 만든 글(이름·연표·사망 원인)은 숨은 문자가 있으면 거부(옛 규칙). 사용자 글은 거부하지 않는다 |
| 시트 | `src/ui/dash/NoteSheet.tsx` · `NoteText` | 자동 카드(모달 또는 인라인)와 수동(도구 줄) 두 경로. 글은 그대로 보여 준다 |
| 시트 공통 | `src/ui/useScrollLock.ts` · `src/ui/useVisualViewport.ts`(compact) · 닫힘 직후 가드(`bumpGuard`) | 결정 시트와 기록 시트가 함께 쓴다 |
| 저장 | 연표 note 행 + `seen`의 `note-` 키 · 스키마 v8 유지 · 설정 v4(`noteCards`) | 기록은 스탯·자산·플래그·`rngState`를 바꾸지 않는다 |

## 경제 (M5)
금액은 내부 만 원 정수, 화면은 원 단위. 지난·다가올 세상 금액 옆은 「지금 가치로 환산」.

| 자리 | 위치 | 하는 일 |
|---|---|---|
| 해마다 · 상속 | `src/core/economy.ts` · `inherit.ts` | 순자산 = 전년 + 소득 − 생활비 − 주거비 − 의료·돌봄 − 이자. 빚 자동 증가 · 차입 한도 · 65세 이상 안전망 · 간이 상속 |
| 선택 · 영향 줄 | `src/core/apply.ts` · `impact.ts` → `src/data/impactText.ts` | 표기 = 실제(같은 경로, 숨은 효과 0) |
| 계수 · 점검 | `src/data/economyTable.ts` · `npm run check:economy` | 가계금융복지조사와 견줌 · 설계 [economy-model](../docs/data/economy-model.md) |
| 저장 | v8 | 재산 스탯 폐지 · 20세부터 자산 · 20세 전 집안 살림 |
