# 시스템 지도

**한 판 흐름**: 첫 화면(세상·인생 길이 고르기, 통계 캐러셀) → 「태어나기」 → 수저·지역 룰렛 → 출생신고 서류 → 인생 화면(0세~사망) → 사연 이벤트·선택 → 회고 엔딩 → 다시 태어나기
(인생 화면의 「나가기」 → 첫 화면 「이어서 살기」로 복원. 별도 시대 선택 화면은 없다. 첫 화면이 맡는다.)

## 인생 화면 (대시보드, M4)
| 구역 | 내용 |
|---|---|
| 헤더 | 게임명 로고 · 이름 · 나이 · 올해 진행률 바 |
| 재생 | 일시정지 · 배속 1·2·4·8 · 다음 결정으로 · 자동 모드 |
| 도구 | 칩튠 BGM(기본 꺼짐) · 생각 남기기(준비 중, M7c) · 다크(수동) · 의견 보내기(GitHub 이슈) · 나가기 |
| 프로필 | 나이별 얼굴 96px · 외모 「상위/하위 약 N%」(점수 없음) · 출신 가정 칩 |
| 상태 | 건강·행복·지식·관계 4색 · 자산 자리(금액은 M5, 20세 전은 「스무 살부터 셉니다」 문구) |
| 인생 기록 | 해마다 쌓이는 한 줄 기록 · 위로 올려 읽어도 자리 유지, 「새 기록」으로 맨 아래 복귀 |
| 식구 | 부모(나이·상태) · 형제(N째) · 배우자·자녀(20세 전엔 없음) |
| 같은 해 태어난 사람들 | 또래 4명 · 수저 칩 · 「요즘 모습」(나이대별 재추첨) |

## 영역
| 영역 | 위치 | 하는 일 |
|---|---|---|
| 순수 로직 | `src/core` | 룰렛(`roulette.ts`)·출생신고(`birthReport.ts`)·스탯·인생 진행·사연 조건·엔딩·저장(v7, 설정 v3). 식구(`family.ts`)·또래 「요즘 모습」(`peerNow.ts`)도 여기서 계산. 화면 없이 테스트 |
| 사연 이벤트 | `src/data/events` | 생애 단계별 JSON 5개, 112개. 코드 수정 없이 추가 |
| 출생 데이터 | `src/data/birthTable.ts`, `names`, `forbiddenNames`, `birthReportTable.ts`, `parentAgeModel.ts` | 시대별 출생 연도·가중치, 이름 풀, 민감 인물 동명 금지, 출생신고 표·부모 나이 분포 |
| 통계·인용 | `src/data/koreaStats.json`·`citations.json` → `koreaStatsAccess.ts` | 지표 50개(확인 43·미확인 7)·인용 59건. 화면은 접근 함수만 쓴다 |
| 근거 문서 | `docs/data/` | 통계 근거, 생애 단계별 데이터 소스, 소재 유형(128개, 2차 M7 사용) |
| 디자인 | `docs/design/` | 디자인 시스템, 심볼·얼굴·수저 아이콘, 시안 |
| 화면 | `src/screens`, `src/ui` | `LifeScreen.tsx`(인생 화면) · 첫 화면·룰렛(`RouletteScreen.tsx`)·출생신고(`BirthScreen.tsx`)·엔딩·밀린·오류 화면(공통 헤더 `Brand.tsx#SiteHead`) · 하단 고정 띠 · 공용 버튼 |
| 대시보드 카드 | `src/ui/dash/*` | `Cards.tsx`(프로필·상태·자산·식구·또래), `LogCard.tsx`(인생 기록) |
| 소리 | `src/audio/*`, `src/ui/useBgm.ts` | 칩튠 BGM. 악보 `score.ts`, 연주기 `bgm.ts`. 코드가 직접 소리를 만든다(음원 파일·외부 요청 없음) |
| 진입·배포 | `src/App.tsx`, `.github/workflows/deploy.yml` | 화면 전환·저장 연결. main 배포는 검수 승인분만 |
| 테스트 | `tests` (vitest), `e2e` (Playwright) | 단위 테스트, 360px·데스크톱 브라우저 시나리오 |
