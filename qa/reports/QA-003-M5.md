## 방법: 「표기 = 실제」 대조 (케이스 E 계열)

**문제**: 선택지를 누르면 같은 걸음에서 한 해가 마무리된다(소득·생활비·이자·상환·자연 변화). 선택 전후 차이에는 선택의 효과와 해마다 규칙이 섞인다.

**방법**
1. 실제 플레이(세 시대 × 16판, 시드 1~16, 개발 서버 시간 배율 60·8배속)에서 선택지가 뜰 때마다 저장 원문과 화면의 영향 줄을 수확(1,108개)

3. 선택지 쌍의 결과 차이를 화면에 보였던 영향 줄의 범위와 견줌. 해마다 규칙은 선택지와 상관없이 같아 차이에서 지워짐

**판정 규칙**
- **스탯 4개**: 차이가 [하한_i − 상한_j, 상한_i − 하한_j] 안. 항목 없음 = 0, 1칸 1~2 / 2칸 3~6 / 3칸 7~. 성인 행복·관계는 4의 배수 나이에 ±1 여유(MOOD_DRIFT). 0·100은 자르기라 건너뜀
- **집안 살림(18세 이하)**: 저장의 `familyFund` 차이를 칸 범위로. 19세 선택은 20세 전환 후 순자산+부채로 환산
- **부채**: 허용 오차 2 + 0.15 × (|Δ순자산|+|Δ소득|). 항목 없는 쌍의 부채 차이는 상환(12%)·해 끝 자동 대출·한도·안전망 반응으로 설명돼야 함
- **자산**: 점수 = Δ순자산 + 3 × Δ연 현금흐름. 소득·주거·가족 구성이 같은 쌍은 순자산 차이로 직접 대조. 현금흐름이 낀 쌍은 점수 차이 = ΔP.net + 2 × (CF'_i − CF'_j)로 복원(CF' = 선택 직후 상태에서 사건 없는 한 해를 더 살아 화면에서 잰 순자산 변화). 순자산 0 근처라 한도가 걸리는 쌍과 경계 나이(29→30 등)는 판정 보류
- **변형 rich**: 순자산에 +10억을 얹어 한도·안전망이 걸리지 않는 상태에서 같은 재생·측정
