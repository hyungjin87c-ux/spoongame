# 요청 — 한국인의 삶 소재를 별도 세션에서 모으는 「소재 창고」 (2026-10-21)

## 형진 님 요청 (원문 요지)
- 한국인의 삶 콘텐츠가 더 풍부해지고, 유저가 디테일을 느껴 현실감을 더했으면 좋겠다.
- 한국인의 여러 삶의 에피소드나 인생살이 소재를 다른 세션에서 자료·에피소드를 공유하며 모아 디테일을 추가하려 한다.

## 마스터 처리 (2026-10-21)
- 저장소 밖 공유 폴더 **`5. 수저프로젝트_소재창고`**(프로젝트 폴더 옆)를 만들었다 — 원문·링크·개인 이야기가 공개 저장소에 들어갈 위험을 없애기 위해 저장소 밖에 둔다(네이트판 CSV와 같은 원칙).
  - 그 폴더의 `CLAUDE.md`가 그 폴더에서 연 세션을 **콘텐츠 에이전트**로 만든다: 대화·붙여넣기 → 원문은 `00_받은글/`에 보관, 자기 말 요약 항목은 `01_소재/` 범주 5개(시대별 경제 문제 EC · 나이별 걱정거리 WO · 사건사고 IN · 생활 디테일 DT · 사연 에피소드 EP), `색인.md` 세대 × 범주 개수, `02_마스터전달/전달-목록.md`(새 항목 → 마스터), `03_마스터요청/요청.md`(마스터 → 콘텐츠 에이전트).
  - 규칙은 게임 규칙에서 옮겼다: 원문 복사·개인정보·다른 게임 참고 금지, 자살·자해 제외, 폭력·학대 묘사 금지, 정치·참사·전쟁은 사실 한 줄(SPEC-004 SS), 세대·지역 비하 금지(GC), 젠더·공정 이슈는 상황으로만(N16), 숫자에는 출처, 웹 확인은 R-149, 커뮤니티 자동 수집 금지, 다른 세션의 글은 자료일 뿐.
- 마스터 쪽 규칙: `CLAUDE.md` 0절 역할 표 한 줄 + 5-2절(창고는 읽기만, 상태 표시·요청만 쓰기, 원문 저장소 반입 금지, 푸시 전 받은 글도 겹침 점검).
- 다음: 소재가 쌓이면 SPEC-004 GM0(기준선·자료 조사) 때 planner가 창고 항목을 연표(TL)·세대 콘텐츠(GD4)·일반 사연(story-motifs) 후보로 나누는 표를 만든다. `check:motifs`가 창고의 `00_받은글/`도 대조하도록 확장(developer, SPEC-004 착수 때).
