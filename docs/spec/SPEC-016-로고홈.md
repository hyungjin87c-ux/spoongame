## 배경

- 지금 첫 화면(`TitleScreen`)의 머리는 큰 「수저 게임」 **워드마크만** 있다(`TitleWordmark` — 장식, 게임명은 `<h1>` 안 `sr-only` 글자가 맡는다). 그 밖의 화면 머리글은 심볼(한반도 + 수저) + 워드마크 가로 로고다: 룰렛·출생신고·엔딩·밀린 화면·오류 화면은 `SiteHead`→`HeaderLogo`, 인생 화면은 대시보드 sticky 헤더 `DashHead`의 `HeaderLogo`. 로고는 **눌러도 아무 일이 없는 그림**이다.
- 형진 님 2026-11-10 답: ① 첫 화면 CI는 **디자이너 시안 2~3개를 보고 고른다**(디자인 게이트). ② 판 도중 로고를 누르면 **묻지 않고 바로 첫 화면**(판은 저장돼 있어 첫 화면 「이어서 살기」로 돌아온다 — 기존 「나가기」 경로 `App.tsx#onExit` → `dispatch({ type: 'openTitle' })` 재사용). ③ 적용은 **로고가 있는 모든 화면**(룰렛·출생신고·인생·엔딩·밀린 화면·오류 화면).
- **r2 요청(H4·H5, 형진 님 확정 2026-11-10 — v0.5.1에 함께, 시안 없이 바로 구현)**: ① 인생 화면의 집 그림 옆 **작은 시대의 창**을 떼어 PC 3열의 **오른쪽 열 맨 위(식구 카드 위)에 큰 칸**으로 두고, 휴대폰은 집 그림 **바로 아래**에 둔다. 집·가족 그림은 창이 비운 폭만큼 **넓게**(작아지지 않게 — 높이 조건은 r2 정정으로 「비율 유지·25vh 상한까지 비례 증가 허용」, 완료 기준 13). ② BGM 볼륨 막대(지금은 도구 줄 **아래 한 줄**)를 **BGM 버튼 바로 오른쪽**에 작은 막대 + 숫자(%)로 옮기고 BGM을 켰을 때만 보이게 한다 — 따로 한 줄을 차지하지 않는다.
- 읽어서 확인한 사실(r2, H4·H5 — 작업자가 다시 확인한다)
  - 지금 `SceneCard`의 `.scene`은 `grid-template-columns: 2fr 1fr` 한 격자에 집 그림(`scene__house`)과 시대의 창(`EraCell`, `#scene-era`)을 나란히 둔다. 폭이 좁으면 1열로 쌓이고(`family.css` 102행) 시대의 창은 가로로 긴 낮은 칸(`.era`, 높이 ≈ 80px)이 된다. 접으면(`settings.sceneFold`) `.scene` 전체가 숨는다 — 시대의 창도 같이 숨는다.
  - 시대의 창은 `<a href="#log-y{해}">`(그해 인생 기록 줄로 가는 링크) · 빈 해는 링크 없는 빈 종이틀(`EmptyFrame`) · 가린 해는 「가려 둔 장면」 캡션과 빈 틀 · 끝 장면(2111년~)은 `role="img"` 그림만 — 이 모두를 SPEC-013·010이 정했고 그대로 둔다.
  - 인생 화면의 3열은 `main.dash`의 `col--left`(프로필·상태·자산) · `col--center`(결정 카드·부모 카드·집과 가족 그림·인생 기록) · `col--right`(식구·또래). 휴대폰은 1열이다.
  - BGM 볼륨은 `LifeScreen.tsx`에서 `settings.bgm.on`일 때만 `.volume`(라벨 「BGM 볼륨」 + `input[type=range]` + `output` %)을 도구 줄 아래 **한 줄 전체**(`flex-basis: 100%`)로 그린다. 값 범위 `BGM_VOLUME_MIN~MAX`, 단계 `BGM_VOLUME_STEP = 5`.
- 읽어서 확인한 사실(작업자가 다시 확인한다 — 아래 Q1~Q3의 근거)
  - `openTitle`은 `hasProgress(game)`(phase가 roulette·birth·life)일 때만 동작한다. 인생이면 `setPaused(true)`로 일시정지 상태를 저장하고 `showTitle: true`·`tick: null`·`spin: false`로 첫 화면을 연다. **엔딩(`ending`)은 `hasProgress`가 아니라 지금 `openTitle`이 아무 일도 안 한다.**
  - 첫 화면의 「이어서 살기」(`resume`)는 `showTitle`을 끌 뿐이라 일시정지 상태 그대로 화면이 돌아온다(기존 나가기와 같다 — 마스터 결정 C3). `showTitle`은 저장되지 않는 세션 상태다(새로고침하면 저장된 화면이 열린다).
  - 룰렛 결과는 「태어나기」 순간 이미 저장돼 있다(RL5).
  - 밀린 화면(`SupersededScreen`)은 다른 탭이 판을 쥔 상태라 이 탭은 저장을 쓰지 않는다. 오류 화면(`ErrorBoundary`)은 앱(세션) **바깥**에 있어 `dispatch`가 없다.
  - 첫 로딩 실측(`QA-013-015-011` V3): Chromium 385,630B · WebKit 389,536B(한도 400,000B, 여유 14.4KB · 10.5KB).

  6. **접힘(Q6)**: 집 그림을 접으면 시대의 창 칸은 어떻게 되는지 — 지금은 같이 숨는다(`.scene` 전체 숨김). 따로 칸이 되면 접힘과의 관계를 정해야 한다(작업자 현재 동작을 적고 마스터가 정한다. 기본 제안 ▲: 시대의 창은 접힘과 무관하게 계속 보인다). **(r2 2026-11-10 형진 님 결정) 접어도 시대의 창 카드는 계속 보이고, PC에서는 펼친 때의 높이를 유지한다**(구현 8·Q6).
  7. **새 설정·새 저장 필드·`SCHEMA_VERSION` 변경 없음.** 세션 상태·reducer 변경 없음.
  8. **(r2 2026-11-10 형진 님 결정) PC 높이 맞춤.** PC(≥960px)에서 「시대의 창」 카드 높이 = 「집과 가족 그림」 카드 높이(차 ≤ 1px; 1280×800·1440×900·1920×1080·960×700에서 확인). 시대의 창 그림은 **비율을 유지한 채 남는 높이에 맞춰 줄어들 수 있고 자르지 않는다**. 캡션 두 줄 예약은 유지한다(SPEC-013). **집 그림을 접어도 시대의 창 카드는 펼친 때의 높이로 계속 보인다**(Q6 결정과 같다 — 접어서 높이가 줄지 않는다). 휴대폰은 변경 없다.
  9. **디자인 게이트 없음**(형진 님 결정 2026-11-10 — 시안 생략). 대신 **배포 전 마스터가 스크린샷으로 확인**한다: PC 1280(라이트·다크) · 휴대폰 360(라이트·다크) · 시대의 창이 있는 해·빈 해·가린 해 · 결정 카드가 열린 상태의 PC·휴대폰. 이 스크린샷은 FAIL이 아닌 **구현 캡처**라 마스터가 따로 지시한 만큼만 찍는다(최대 20장 — CLAUDE.md 4절).
- [ ] [레인: 표준 — 같은 확정, 시안 없이 바로 구현] **H5 BGM 볼륨 막대를 BGM 버튼 옆으로.** (r2 2026-11-10 형진 님 결정 — 정정: 휴대폰은 예외) **PC(≥960px)**는 도구 줄 아래의 볼륨 한 줄을 없애고 **BGM 버튼 바로 오른쪽**에 작은 막대 + 숫자(%)를 둔다. **휴대폰(<960px)**은 360px에서 도구 다섯 칸이 폭을 다 써 BGM 오른쪽에 자리가 없으므로, 볼륨 막대 + 숫자를 **도구 줄 바로 아래 한 줄**에 둔다(BGM을 켰을 때만).
  1. **보이는 때**: BGM이 **켜졌을 때만**(`settings.bgm.on`) 막대·숫자가 BGM 버튼 오른쪽에 있다. 꺼져 있으면 도구 줄은 지금 모양 그대로다(막대 자리 0, 빈 자리 0).
  2. **PC는 따로 한 줄을 차지하지 않는다.** (r2 2026-11-10 형진 님 결정) PC에서는 켜져 있어도 도구 줄의 **높이는 켜지기 전과 같다**(`.volume` 한 줄이 없어진다). 막대는 BGM을 켰을 때만 나타나고 오른쪽 맞춤이라 **BGM 버튼이 왼쪽으로 비키는 것을 수용한다**(BGM 버튼 위치가 켜기 전후 다르다 — 막대가 나타난 자리에 더블클릭이 떨어지면 볼륨 값만 바뀔 수 있고 BGM은 꺼지지 않는다). **휴대폰은 켜면 도구 줄 아래에 한 줄이 늘어나고, 도구 다섯 칸의 위치는 켜기 전후 변하지 않는다.** 나가기 확인 상자(`exit-ask`)·생각 남기기 같은 다른 줄의 규칙은 그대로다.
  3. **접근 이름 「BGM 볼륨」 유지**: 막대의 접근 이름은 지금과 같은 「BGM 볼륨」(`DASH_TEXT.bgmVolume`)이고 `aria-valuetext`는 지금처럼 「N%」다. 눈에 보이는 낱말 「BGM 볼륨」은 자리가 좁으면 보이는 글자에서 빠질 수 있으나(시각 라벨 생략) 접근 이름은 반드시 있다(`aria-label` 또는 `sr-only` 라벨). `data-testid`(`bgm-volume`·`bgm-volume-input`)는 그대로 둔다.
  4. **조작은 그대로**: 값 범위·단계(5)·`onBgm({ volume })` 동작·키보드(←→·Home·End)·숫자 표시(`output`, `N%`) 불변. 눌림 영역은 `--hit` 44px 이상(막대의 세로 눌림 영역을 지킨다).
  5. **도구 줄 구성**: 도구 줄은 다섯 칸 그대로이고(`copy.md` 12-7) 칸의 순서·이름·동작은 바뀌지 않는다. (r2 2026-11-10 형진 님 결정: 휴대폰은 막대가 도구 줄 아래 한 줄) PC에서 막대는 **BGM 칸 바로 오른쪽 형제**로 들어가며 폭이 필요하면 다른 칸이 줄어드는 방식을 작업자가 정한다(Q7 — 휴대폰 폭에서 **조작 줄 넘침 0**이 기준이고 칸 이름이 세 줄로 접히지 않는다 — 12-7 규칙). 도구 이름은 낱말 단위 두 줄까지 규칙을 지킨다.
  6. **새 설정·저장 필드 없음.** BGM 켜기·볼륨의 저장(기존 설정값)은 그대로다.
  7. **디자인 게이트 없음**(형진 님 결정 — 시안 생략). 배포 전 마스터가 스크린샷으로 확인한다: PC 1280·휴대폰 360·320(라이트·다크) · BGM 꺼짐/켜짐 · 글자 200%.

## 위험도

**Two-way / 파급 낮음**(Q1에서 session reducer 변경이 필요해지면 그 부분은 One-way·정밀로 올리고 형진 님께 확인). 기존 경로 재사용이라 되돌려도 저장에 흔적이 없다. 위험은 **화면마다 상태가 다른 곳에서 눌렀을 때의 일관성**(룰렛 연출·결정 카드·자동 모드)이다 — 완료 기준 4·5가 닫는다.

## 완료 기준

기능:

1. **(접근성·키보드)** 룰렛·출생신고·인생·엔딩 화면의 로고가 키보드(Tab → Enter·Space)로 닿는 버튼/링크이고, 접근 이름에 「수저 게임」과 「첫 화면으로」 뜻이 둘 다 있다. 밀린 화면·오류 화면도 Q2 결정에 따라 같은 규칙이거나(링크인 경우) 결정에 적힌 대로다. 눌림 영역이 가로·세로 ≥ 44px이고 초점 링이 보인다. 로고 안 `role="img"` 이름과 겹쳐 두 번 읽히지 않는다.
2. **(첫 화면으로)** 룰렛·출생신고·인생에서 로고를 누르면 **확인 없이** 첫 화면이 열린다(`data-testid="title-screen"`). 첫 화면에 「이어서 살기」가 기본 버튼으로 있고, 누르면 **같은 해·같은 나이·같은 선택 대기 상태**의 판이 돌아온다(인생이면 일시정지로 멈춘 채 — 기존 「나가기」와 같다).
3. **(저장 불변)** 로고 → 첫 화면 → 「이어서 살기」 → 같은 화면 흐름에서 저장 바이트가 **기존 「나가기」 → 「이어서 살기」 경로와 같다**(로고 경로가 더하는 변화 0). 룰렛·출생신고 단계에서는 저장 바이트 완전 불변. 인생에서는 일시정지 표시(`paused`) 한 필드만 기존 나가기와 같이 켜진다 — 그 밖 필드(스탯·자산·난수 `rngState`·연표·`pending`) 불변. `SCHEMA_VERSION` 그대로.
4. **(상태별 눌림 — 오류·이중 기록 0)** 아래 각각에서 로고를 눌러도 콘솔 오류 0 · 기록(history) 줄이 두 번 쌓이지 않음 · 다시 열었을 때 같은 판:
   - 한 해가 흐르는 중(진행률 바가 차는 중) · 일시정지 중 · 배속 변경 직후
   - **자동 모드** 켜짐(첫 화면이 열린 동안 자동 선택이 돌지 않고, 「이어서 살기」 뒤 이어진다 — `autoChooseArmed`의 `showTitle` 규칙)
   - **결정 카드(선택지) 열린 상태**(인라인 카드·접은 카드 포함 — 고르지 않은 채로 첫 화면으로 가고 돌아오면 같은 카드가 남아 있다)
   - 나가기 확인창·생각 남기기 시트·가림 열기 등 **겹창이 열린 동안**은 기존 `inert`·초점 가둠 규칙을 따른다(로고가 닿지 않거나, 눌러도 겹창이 열린 채 오류 없이 아무 일 없다 — 작업자가 현재 규칙을 확인해 적는다).
5. **(빠른 연속 클릭)** 로고 20회 연타·로고 후 즉시 「이어서 살기」 연타·「이어서 살기」 직후 로고 연타에서 첫 화면이 한 번 열리고 판은 하나뿐이다. 인생이 두 번 진행되거나 판이 사라지지 않는다. 룰렛 연출 중 연타해도 결과·판이 하나다.
6. **(첫 화면 CI)** 첫 화면의 CI가 **형진 님이 고른 시안과 같다**(승인 기록은 `docs/design/` 새 시안 문서의 「선택」 절 — 선택한 시안 이름과 날짜). 첫 화면 로고를 눌러도 오류 없이 아무 일 없다(Q4 결정이 맨 위로면 그대로). 게임명은 `<h1>` 안의 읽히는 글자 「수저 게임」 하나로 읽힌다(로고가 이름을 중복으로 읽지 않음).
7. **(깨지지 않음)** 첫 화면 CI와 각 화면의 로고 컨트롤이 **라이트·다크**, 폭 **320·360·768·1280px**, 글자 150%·200%, 강제 색상에서 가로 넘침 0 · 잘림 0 · 겹침 0이다. 다크·mono 변형이 시안에 있으면 그것을 쓴다.
