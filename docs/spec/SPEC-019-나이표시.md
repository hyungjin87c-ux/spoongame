# SPEC-019 나이 표시 — 한국 나이 기본, 만 나이 전환

- 상태: **확정** (확정일: 2026-11-13 — 헤더 전환 모양 A 「옆에 글자 버튼」, 결정 후속 238) (형진 님 요청 2026-11-13 「유저는 한국 나이 기준이 익숙해서 한국 나이를 디폴트로 해 주고, 상단 나이 옆에 만 나이 기준으로 변경 옵션을 줘」)
- 레인: **STANDARD**. 여러 화면에 걸친 표시 기능이고, 설정에 칸 하나를 더한다. 게임 안의 나이 계산·저장된 판의 형식은 건드리지 않는다.
- 배포: v0.6.0과 함께.

## 배경
게임 나이는 태어난 해를 0세로 두고 해마다 1씩 오른다(`state.age` — 연 나이, 그해 생일이 지난 만 나이와 같다). 그래서 대학 4학년이 「22세」로 보여 한국 나이에 익숙한 사람에게 1년 어리게 읽힌다(형진 님 질문, 결정 후속 237).

## 할 것
1. **정의 한 곳**: 사람 나이를 화면 숫자로 바꾸는 함수를 한 곳에 둔다.
   - 한국 나이 = 게임 나이 + 1(태어난 해 1세).
   - 만 나이 = 게임 나이(그해 생일이 지난 뒤 기준 — 게임은 해 단위로 흐른다).
   - 모든 화면이 이 함수만 거친다.
2. **설정 `ageView`**: `'korean'`(기본) | `'man'`. 기존 설정 묶음(`suzeo-game:settings`)에 칸 하나를 더한다.
   - **설정 버전은 6 그대로 둔다** — 올리면 v0.5.1로 되돌렸을 때 설정 전체가 초기화된다. 없거나 이상한 값이면 기본(한국 나이)이다.
   - 이 설정은 이 기기 한 곳에만 남는다(다른 설정과 같다).
3. **헤더 전환(안 A 확정)**: 인생 화면 상단 나이 알약 오른쪽에 작은 글자 버튼을 둔다. 버튼에는 지금과 반대 기준을 적는다 — 한국 나이일 때 「만 나이」, 만 나이일 때 「한국 나이」. 360px에서 줄이 넘치면 알약과 버튼이 이름 아래로 함께 내려간다(`.who`의 flex-wrap).
   - 한 번 누르면 바뀌고, 새로고침해도 유지된다. 누르는 영역은 44px 이상이다.
   - 화면 읽기 이름은 「한국 나이 24세」 / 「만 나이 23세」. 버튼 이름은 「만 나이로 보기」 / 「한국 나이로 보기」.
4. **따르는 곳(사람의 나이 — 모두 같은 설정)**:
   - 인생 화면: 헤더 나이, 결정·부모 카드 머리 「{연도}년 · {나이}세」, 인생 기록 줄, 시대 줄, 가리기 줄 「{나이}세 무거운 일」
   - 가족: 가족 카드의 가족 나이·별세 나이, 장면 카드, 가족 변화 문장 「{N}세에 세상을 떠나셨습니다」
   - 출생신고: 부모 나이
   - 기록 시트의 나이
   - 엔딩: 머리 「… · {나이}세」, 연표 줄, 사망 문장, 생애 구간 「{from}~{to}세」
   - 첫 화면 세대 목록: 「올해 N~M세」
5. **만 나이일 때 표시**: 헤더 알약과 엔딩 머리에만 「만」을 붙인다(「만 23세」). 기록 줄 같은 목록에는 붙이지 않는다(줄마다 반복되면 시끄럽다). 한국 나이는 지금처럼 「24세」다.
6. 문구는 `docs/design/copy.md`에 새 절로 둔다.

## 안 할 것
- **통계의 나이는 바꾸지 않는다**: 연령 구간(0~14세·65세 이상), 기대수명, 인구 구성 슬라이드, 출처 문장. 통계는 만 나이 기준이다.
- 게임 규칙의 나이는 바꾸지 않는다: 사건 나이 범위, 진로 트랙, 경제, 저장된 판의 `age`. 바뀌는 것은 화면 숫자뿐이다 — 같은 시드의 판 결과가 그대로다.
- 생일 달을 읽어 한 해 안에서 만 나이를 바꾸지 않는다(해 단위 그대로).
- 사건 본문에는 나이 낱말이 없다(확인함 — 「스무 살」 같은 표현 0곳). 이번에 새로 넣지 않는다.

## 완료 기준
- 기능: 기본은 한국 나이다(새 설치·옛 설정 모두). 헤더 전환 한 번으로 4절의 모든 곳이 함께 바뀌고, 새로고침해도 유지된다. 통계 나이와 게임 결과는 그대로다.
- 시험:
  - 단위: 나이 함수(0세 → 1/0, 경계).
  - 설정 읽기: 없음·이상한 값 → 한국 나이. 설정 버전 6 유지. v0.5.1 파서가 새 설정을 읽어도 다른 값을 잃지 않는다.
  - 나이 표시가 한 함수만 거친다는 린트형 시험(화면 코드에서 `game.age`에 「세」를 바로 붙이는 곳 0).
  - 같은 시드 결과 불변.
  - 나이 글자를 읽는 기존 e2e(`life-age` 등)는 한국 나이로 고친다.
- QA: 인생 화면에서 전환 → 헤더·기록·가족 카드·결정 카드가 같이 바뀐다 → 새로고침 → 엔딩까지 확인. 360px에서 헤더가 넘치지 않는다(이름이 긴 경우 포함). 키보드 조작과 화면 읽기 이름도 본다.
