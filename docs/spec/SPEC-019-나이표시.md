# SPEC-019 나이 표시 — 한국 나이 고정, 헤더에 작은 만 나이 (r2)

- 상태: **r2 확정 2026-11-13 형진 님 — 전환 없음, 한국 나이 고정 + 헤더에 작은 만 나이** (형진 님 원문: 「나이는 한국 나이 기준으로 해줘. 만 나이는 게임화면 윗줄 나이 옆에 작게 표시하는거 제외하고 다 지워줘.」, 결정 후속 241). r1(2026-11-13, 결정 후속 238 — 한국 나이 기본 + 헤더 글자 버튼으로 만 나이 전환, 설정 `ageView`)은 이 r2로 대체됐다.
- 레인: **STANDARD**. 여러 화면에 걸친 표시 기능이다. 게임 안의 나이 계산·저장된 판의 형식·설정 저장 형식은 건드리지 않는다.
- 배포: v0.6.0과 함께.

## 배경
게임 나이는 태어난 해를 0세로 두고 해마다 1씩 오른다(`state.age` — 연 나이, 그해 생일이 지난 만 나이와 같다). 그래서 대학 4학년이 「22세」로 보여 한국 나이에 익숙한 사람에게 1년 어리게 읽힌다(형진 님 질문, 결정 후속 237). 형진 님은 전환 기능 없이 한국 나이로 고정하되, 인생 화면 헤더에만 만 나이를 작게 곁들이기로 했다.

## 할 것
1. **정의 한 곳**: 사람 나이를 화면 숫자로 바꾸는 함수를 한 곳(`src/core/format.ts`)에 둔다. 한국 나이 하나뿐이다.
   - 한국 나이 = 게임 나이 + 1(태어난 해 1세). `view` 인자·전환 설정은 없다.
   - 모든 화면이 이 함수만 거친다(린트형 시험).
2. **설정은 바뀌지 않는다**: 새 설정 칸·설정 버전 변경이 없다. 설정 저장 형식은 v0.5.1과 같다. (r1 시절에 저장됐을 수 있는 `ageView` 칸은 읽을 때 버린다.)
3. **헤더(인생 화면 윗줄)**: 나이 알약은 한국 나이 「24세」. **알약 옆에 작은 글자로 만 나이 「만 23세」(N = 게임 나이)를 늘 붙인다.** 버튼이 아니고 눌러서 바뀌는 것이 없다.
   - 화면 읽기 이름은 둘을 한 번에 「한국 나이 24세, 만 23세」.
   - 글자는 보조 글(작은 글자 `--fs-xs` · 흐린 색 `--c-text-2`)이고 대비 시험을 통과한다. 360px에서 넘치지 않는다(`.who`의 flex-wrap — 알약 묶음이 이름 아래로 함께 내려간다).
4. **따르는 곳(사람의 나이 — 모두 한국 나이)**:
   - 인생 화면: 헤더 나이, 결정·부모 카드 머리 「{연도}년 · {나이}세」, 인생 기록 줄, 시대 줄, 가리기 줄 「{나이}세 무거운 일」
   - 가족: 가족 카드의 가족 나이·별세 나이, 장면 카드, 가족 변화 문장 「{N}세에 세상을 떠나셨습니다」(저장된 글자는 그대로이고 보여 줄 때만 맞춘다)
   - 출생신고: 부모 나이
   - 기록 시트의 나이
   - 엔딩: 머리 「… · {나이}세」, 연표 줄, 사망 문장, 생애 구간 「{from}~{to}세」
   - 첫 화면 세대 목록: 「올해 N~M세」
5. **「만」 표기는 헤더의 작은 글자 한 곳뿐이다.** 엔딩 머리를 포함한 다른 모든 곳에는 붙이지 않는다.
6. **어긋나는 「스무 살」 문장**: 한국 나이로 읽으면 어긋나므로 독립 기준 문장으로 고친다 — 자산 카드 안내(`dashText.ts#assetsYoung`: 「독립하는 해부터 / 독립하면」), 엔딩 `early`(「독립하기 전이라 자산을 세지 않았습니다.」)·`JOURNEY_NOTE`(「독립한 뒤부터는」). 게임 규칙(20세 독립·`age < 20`)은 그대로다.
7. 문구는 `docs/design/copy.md` 21절에 둔다.

## 안 할 것
- **전환 버튼·설정 `ageView`·`AGE_VIEWS`·세션 액션은 만들지 않는다**(r1에서 만들었다가 r2에서 지웠다).
- **통계의 나이는 바꾸지 않는다**: 연령 구간(0~14세·65세 이상), 기대수명, 인구 구성 슬라이드, 출처 문장. 통계는 만 나이 기준이다.
- 게임 규칙의 나이는 바꾸지 않는다: 사건 나이 범위, 진로 트랙, 경제, 저장된 판의 `age`. 바뀌는 것은 화면 숫자뿐이다 — 같은 시드의 판 결과가 그대로다.
- 생일 달을 읽어 한 해 안에서 만 나이를 바꾸지 않는다(해 단위 그대로).
- 사건 본문에는 나이 낱말이 없다(확인함). 이번에 새로 넣지 않는다.

## 완료 기준
- 기능: 모든 화면의 사람 나이가 한국 나이다. 헤더 알약 옆에만 작은 「만 N세」가 있고, 전환은 없다. 통계 나이와 게임 결과·설정 저장 형식은 그대로다.
- 시험:
  - 단위: 나이 함수(0세 → 1세, 경계, 「만 N세」), 설정에 나이 칸이 없음(버전 6, v0.5.1과 같은 형식), 가족 변화 줄의 화면 변환.
  - 나이 표시가 한 함수만 거친다는 린트형 시험(화면 코드에서 사람 나이에 「세」를 바로 붙이는 곳 0).
  - 화면: 헤더(한국 나이 + 작은 만 나이 + 읽기 이름), 「만」은 헤더 한 곳뿐, 엔딩·목록·가족 카드는 한국 나이.
  - e2e: 헤더·기록·가족 카드, 새로고침 유지, 360px 넘침 0(이름이 긴 경우 포함).
- QA: 인생 화면 헤더가 360px에서 넘치지 않는다. 화면 읽기 이름도 본다.
