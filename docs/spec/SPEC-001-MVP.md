## 배경
출생(수저) → 나이별 진행 → 사연 이벤트 → 담담한 회고 엔딩까지, 한 판이 끝까지 돌아가는 웹 게임을 만든다.

## 할 것
### 플랫폼
- [ ] 웹 브라우저 게임 (Vite + React + TypeScript), 모바일 화면(360px)~데스크톱 대응
- [ ] 테스트: vitest(단위) + Playwright(QA 자동 조작·스크린샷)
- [ ] 서버 없이 동작, 진행 상황은 브라우저(localStorage)에 자동 저장 → 새로고침해도 이어하기

### 게임 정보
- [ ] 게임 제목: **수저 게임** (타이틀 화면·브라우저 탭 제목)
- [ ] 캐릭터 이름: 이름 입력 없이 **대한민국 출생아 실제 이름 통계에서 랜덤 차용**
  - 출처: 대한민국 법원 전자가족관계등록시스템 통계서비스 '상위 출생신고 이름 현황' (https://stfamily.scourt.go.kr/st/StFrrStatcsView.do?pgmId=090000000025)
    - 이 서비스는 **2008년 이후 등록분, 연도·성별당 상위 20위까지만** 제공한다 (등록일 기준 잠정치). 원자료: `src/data/sources/scourt-birth-names.json`, 수집 절차: `docs/data/names-source.md`
  - 출생 연도·성별에 맞는 이름 풀에서 뽑음 → `src/data/names.json`
    - **지금 세상(2008~2025년생)**: 출생 연도별 남/녀 공식 통계 상위 20개만 사용 (비공식 이름 0개)
    - **다가올 세상(2030~2060년생)**: 통계가 존재하지 않으므로 가장 최근 연도들의 공식 통계 풀을 사용하고 그 사실을 데이터에 명시
    - **지난 세상(1950~1989년생)**: 공식 서비스에 자료가 없음. 언론이 인용한 대법원 자료로 확인된 이름 + 시대 작명 경향에 맞춘 **추정 보충**으로 연대별 남/녀 각 20개 이상. 확인/추정을 데이터에서 구분 표기하고, 추정 이름을 통계라고 설명하지 않는다
  - 성(姓)은 통계청 인구 비율 상위 성씨로 가중 랜덤
  - 정치적으로 민감한 실존 인물과 같은 성+이름 조합(전·현직 대통령 등 소수)은 금지 목록으로 걸러 이름을 다시 뽑는다. 그 밖의 동명이인은 허용
  - 플레이어에게 "다시 뽑기"는 제공하지 않고 운명처럼 그대로 사용
  - 법원 자료 이용 조건에 따라 게임 안에 이름 통계 출처를 표기한다

### 진행 속도 (80억분의 1 방식)
- [ ] 한 판 목표 플레이 시간: **10분 ~ 최대 30분** (기본 1배속 기준 약 30분, 배속·자동 사용 시 10분 내외)
- [ ] 속도 컨트롤 상시 표시: **1배 / 2배 / 4배 / 8배**
- [ ] **다음 결정으로**: 선택지가 나오는 시점까지 연출을 건너뛰고 즉시 이동
- [ ] **자동 모드**: 선택지도 성향 기반으로 자동 선택하며 끝까지 진행 (언제든 해제 가능)
- [ ] 배속·자동 모드 중에도 선택지 이벤트에서는 기본적으로 멈춤 (자동 모드 제외)
- [ ] 마지막으로 쓴 속도 설정은 저장되어 다음 판에도 유지

### 시대 선택
- [ ] 시작 시 지난 세상 / **지금 세상(기본 선택)** / 다가올 세상 중 택1
- [ ] 시대마다 출생 분포·이벤트 풀·물가 등 가중치가 다르게 적용됨
- [ ] 시대별 출생 연도: 지난 세상 1950~1989 / 지금 세상 2008~2025 / 다가올 세상 2030~2060

### 출생 뽑기(수저)
- [ ] 부모 재력 5단계(흙·동·은·금·다이아 수저 성격, 화면엔 간접 표현)
- [ ] 부모 교육방식 (예: 방임 / 자유 / 헬리콥터 / 엄격) 중 1개
- [ ] 외모 점수 → 연애·결혼·사업 관련 이벤트 확률에 반영
- [ ] 뽑기 결과는 "우리나라 출생아 중 상위 몇 %"처럼 담담하게 보여줌
  - 상위 50% 안쪽은 "상위 약 N%", 하위 50% 안쪽은 "하위 약 N%", 중앙에 걸친 계층은 퍼센트 대신 전용 문구. 외모도 같은 규칙

### 나이별 인생 진행
- [ ] 0세 → 사망까지 1년 단위 진행, 생애 단계(영유아·학창·청년·중년·노년)별 이벤트 풀
- [ ] 스탯: 재산, 학력, 건강, 행복, 관계 (+ 고정 외모)
- [ ] 단계마다 선택지 2~3개, 선택이 스탯과 이후 이벤트에 영향

### 사연 이벤트
- [ ] 커뮤니티 사연을 **모티브로만** AI가 새로 쓴 이벤트 최소 ~~40개~~ **60개** (시대·단계별 분포) — 2026-10-14 변경, 아래 추가 결정 기록 참조
- [ ] 한 판의 선택지 이벤트 약 20~25개 (플레이 시간 목표를 맞추기 위함)
- [ ] 이벤트는 데이터 파일(JSON)로 분리 → 코드 수정 없이 추가 가능

### 엔딩

## 완료 기준
- 기능: 시대 선택 → 출생 → 사망 → 엔딩 → 재시작이 끊김 없이 동작
- 시간: 1배속 수동 플레이 30분 이내, 8배속+다음 결정으로 사용 시 10분 내외 (QA가 실측 기록)
- 이름: 1000판 시뮬레이션에서 이름이 출생 연대·성별 풀과 100% 일치
- 테스트: 출생 분포·스탯 변화·이벤트 조건 단위 테스트 (vitest), 1000판 자동 시뮬레이션에서 에러 0건
- QA: 정상 플레이 3판 + 공격 테스트(새로고침 연타 중 저장 복원, 버튼 연타, 뒤로가기, 특수문자 입력이 있다면 입력값) 전부 PASS, 스크린샷 첨부

## 추가 결정 기록 (2026-10-13, M2 검수 중 마스터 개입 → 형진 님 결정)
- 이름 출처를 법원 통계서비스 '상위 출생신고 이름 현황'으로 지정. 서비스가 2008년 이후·상위 20위만 제공하므로 "연대별 각 20개 이상"을 위 '캐릭터 이름' 항목처럼 수정 (REV-001-M2-1 R-012)
- 지금 세상 출생 연도를 2008~2025로 확정 (기본 시대는 100% 공식 통계). 지난 세상은 확인된 이름 + 추정 보충 유지, 구분 표기
- 민감한 실존 인물 동명 조합만 금지 (R-023) / "상위 약 N%"의 중간 계층은 전용 문구 (R-018)
- (2026-10-14, M3 QA 실측 후 형진 님 결정) 플레이 시간이 목표보다 짧음(1배속 약 10~13분, 8배속+다음 결정으로 약 3~6분, 판당 선택지 약 12개) → **판당 선택지를 약 20~25개로 늘리고 1배속 연출도 조금 늘려 목표에 맞춘다**. 이에 따라 이벤트 최소 개수 40 → 60. 시간 목표·완료 기준 문구는 그대로 (REV-001-M3-1 R-037, qa/reports/QA-001-M3.md)
