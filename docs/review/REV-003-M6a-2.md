### 새 검사의 동작 (CI 포함)
- **일반 경로 패턴**(어느 환경에서나): 드라이브 문자 + 사용자 폴더(슬래시·역슬래시·겹역슬래시·역슬래시가 빠진 꼴·URL 인코딩 꼴), Git Bash 꼴, macOS·Linux 홈 폴더 아래 계정 폴더. 자리표시(`<이름>`·`$USER`)와 CI 계정 폴더는 통과. 주소의 `https:`처럼 앞에 글자가 붙은 한 글자는 드라이브 문자로 보지 않는다.
- **실행 환경의 계정 이름**: 내 컴퓨터에서는 내 이름이 글에 남는 것을 막고, 계정 이름이 4자 미만이거나 runner·root·ubuntu 같은 흔한 말(GitHub Actions의 계정 포함)이면 우연히 걸리지 않게 건너뛴다. 즉 **CI에서는 일반 경로 패턴만 본다** — 작성자 이름 자체는 내 컴퓨터에서 푸시 전에 `npm test`를 돌릴 때 잡힌다. 이 한계는 테스트 머리 주석과 `localPathLeaks.ts` 머리말에도 적었다.
- 실패 메시지에는 걸린 글자를 싣지 않고 파일·줄·규칙만 적는다(공개 로그에 이름이 또 찍히지 않게). 감지기 시험 문장은 조각을 이어 붙여 만들어 테스트 파일이 감지기에 걸리지 않는다.
- 빈 목록으로 통과하지 않게 목록 크기(150개 초과)·핵심 파일 포함을 단언하고, 깃을 못 쓰는 환경을 위한 폴더 걷기 대비책(`ignoreMatcher`가 `.gitignore`의 간단한 규칙을 푼다)도 같은 단언으로 시험한다.
