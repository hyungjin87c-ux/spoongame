## 2. 격차 슬라이드 — 값이 형진 님 문장을 사실로 뒷받침하는가

- 뒷받침하는 것: 같은 나이대 안의 소득 격차는 66세 이상이 18~65세보다 크다 — 2024년 처분가능소득 5분위배율 6.90배 대 5.01배, **2011~2024년 14개 해 모두** 66세 이상이 더 크다(11.44>7.12 … 6.90>5.01, 지니 0.460>0.369 … 0.377>0.303). 시험 `koreaStatsProjection.test.ts:532-536`이 단언.
- 뒷받침하지 않는 것: ① 「나이들수록」의 점진성 — 같은 나이대 안 격차는 두 구간뿐이라 보일 수 없다. ② 「극심해져요」를 시간 변화로 읽는 경우 **같은 슬라이드의 그래프가 반대** — 66세 이상 11.44 → 6.90배(약 40% 감소), 18~65세 7.12 → 5.01배, 두 구간의 비 1.61 → 1.38로 좁아짐. ③ 「경제력」은 자산을 포함하지만 측정은 소득(캡션 「소득…(균등화 처분가능소득)」이 바로잡음).
- 캡션은 지표의 뜻만 말하고, 「같은 나이대 안 격차는 이 두 구간으로만 공표된다」는 한계는 화면 어디에도 없다 → R-476.
- 결론: 비교는 사실, 점진성과 변화는 근거 없음, 시간 쪽은 같은 슬라이드가 반대.
