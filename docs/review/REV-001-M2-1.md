- 고친 곳: `src/core/birth.ts` — 표현 결정을 순수 함수로 분리. `standingOf(topPct, bottomPct)`가 `{kind:'top'|'bottom', percent, within}` 또는 `{kind:'middle'}`을 돌려준다(이상 비율 ≤ 50 → top, 이하 비율 ≤ 50 → bottom, 둘 다 50 초과 → middle). 재력은 `wealthStanding(era, wealth)`(가중치 표 누적합), 외모는 `looksStanding(looks)`(`looksPmf`의 꼬리 확률) — 같은 규칙. 비율이 1% 미만이면 `within`(문구 "상위/하위 1% 안쪽")이라 "약 0%"가 없고, 50 초과 비율은 문구에 쓰이지 않아 "약 100%"도 없다. 기존 `Standing {side, percent}`는 새 형태로 교체.
- 문구: `src/data/birthText.ts#standingLabel/wealthStandingText/looksScoreText/MIDDLE_LABEL`("우리나라 출생아 가운데 딱 중간쯤의 집안 형편이었다.", 외모 "외모 50점 (딱 중간쯤)."). `src/screens/BirthScreen.tsx`는 core 결과를 문구로 그리기만 한다.
- 결과: 재력은 전 시대 2단계만 중간. 외모는 0~49점 하위 / 50점만 중간 / 51~100점 상위(23점 "상위 약 94%" → 하위 표현).
- 테스트: `tests/standing.test.tsx` "standingOf: 경계 값을 직접 적은 규칙 단위 테스트", "재력: 세 시대 × 5단계의 기대 표현 (표에 직접 적은 값)"(past/present/future 각 5단계), "외모: 0점 / 중앙 / 100점과 경계"(101점 전수 열거 기준값 `tests/helpers/looksReference.ts#expectedLooksStanding`과 대조 포함), "표시 문자열 전수 확인: 50을 넘는 숫자도, 약 0%/약 100%도 없다"(재력 15 + 외모 101문장), "화면은 core의 결과만 그린다 (BirthScreen 서버 렌더 전수)". 기대표는 `tests/helpers/standingExpectations.ts`에 직접 적어 vitest와 e2e가 공유. e2e: `e2e/birth.spec.ts` "재력 5단계의 순위 표현이 표와 같고, 어디에도 50%를 넘는 숫자가 없다 (R-018)"(3시대), "외모 순위 표현: 0·10·49·50·51·90·100점이 …".
