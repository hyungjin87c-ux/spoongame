## 지적

### CX-<번호>-001
- 심각도: 높음 / 중간 / 낮음
- 규칙: `CR-…` 또는 `NEW`
- 위치: `파일:줄`
- 문제:
- 재현 조건과 근거(시험 코드·시드·상태·명령):
- 실제 영향:
- 권장 대응:
- 미확인 사항:

## 결함이 없을 때
`NO_FINDINGS` — 검토한 범위와 확인한 질문 번호를 적는다.

## 심각도 기준
- 높음: 저장 손상·진행 불가·확률/계산이 명세와 다르게 플레이어 결과를 바꿈·보안
- 중간: 특정 조건에서 잘못된 결과·회귀 가능성이 재현됨
- 낮음: 영향이 작거나 문서·시험 보강 수준
