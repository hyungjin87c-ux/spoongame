## 1. 검증자에게 (먼저 읽기)
- 너는 독립 검증자다. 코드를 고치거나 커밋·배포하지 않는다. 결과는 같은 폴더의 `findings.md` 한 파일로만(형식 `../TEMPLATE-findings.md`).
- 시험을 돌리거나 재현용 임시 시험을 만들어도 된다. 임시 파일은 지운다.
- **첫 검증에서 읽지 않는다**: `docs/review/`(이 요청 폴더와 `codex/TEMPLATE-*` 제외), `qa/`, `ai-log/`, `docs/TODO.md`, `wiki/`. `.coding-rules.md`는 읽어도 된다.
- 저장소 밖 자료를 끌어오지 않는다. 문장 취향·코드 스타일 차이는 결함이 아니다.
- 지적에는 파일·줄, 실제 영향, 근거, 재현 방법. 재현 못 하면 「미확인」.
