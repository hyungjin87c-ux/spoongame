## 1. 검증자에게 (먼저 읽기)
- 너는 독립 검증자다. 코드·문서를 고치거나 커밋·배포하지 않는다. 결과는 같은 폴더의 `findings.md` 한 파일로만(형식 `docs/review/codex/TEMPLATE-findings.md`).
- 이번 대상은 **구현 전 설계**다. 「이대로 만들면 무엇이 틀어지는가」를 찾는다. 지금 코드를 읽고, 필요하면 지금 코드·시세 표로 임시 스크립트를 돌려 설계의 손계산(가상자산 상한 이득, 옮기기 효력 시점, 세대 차 Jaccard)을 다시 재 봐도 된다. 임시 파일은 지운다. `npx`는 쓰지 말고 `npm run …`·`npm exec -- vitest …`·`./node_modules/.bin/vite-node …`를 쓴다.
- **첫 검증에서 읽지 않는다**: `docs/review/`(이 요청 폴더와 `codex/TEMPLATE-*` 제외), `qa/`, `ai-log/`, `docs/TODO.md`, `wiki/`. `.coding-rules.md`는 읽어도 된다.
- 저장소 밖 자료를 끌어오지 않는다. 근거 문서(`docs/data/market-history.md`·`spend-era-items.md`)의 출처를 웹으로 확인하지 않는다 — 문서 안의 수치와 설계값·식이 서로 맞는지만 본다.
- 문장 취향·문서 문체는 결함이 아니다. 쓰기 항목(3-2·3-2b절)은 r2에서 시대 자료(`docs/data/spend-era-items.md`)로 보강했다 — 항목 수보다 **항목을 어떻게 고르고 보이고 값을 매기는지(규칙)**, 보임 연도의 근거 등급(공식/보조/설계값, ▲35)이 시대 격자 시험을 흐리지 않는지를 본다.
- 지적에는 문서 절·줄(또는 코드 파일·줄), 실제 영향(플레이어가 겪는 것·숫자), 근거, 재현(가능하면 잰 숫자). 못 재면 「미확인」.

## 5. 검증 질문
1. **돈 보존**: 쓰기(빚 포함)·해 끝 정산·요청 처리·상한 재조정·불변식 I2 위반 정리·집 대출·전세 보증금이 어떤 순서·반올림으로 겹쳐도 `net`·`debt`·`bal` 합이 보존되는가. 돈이 생기거나 사라지는 경로를 찾아라(특히 `liquid` 예약, I2 비례 축소, 구형 저장 열기).
2. **뒷일을 아는 전략**:
   - 상한·lag 1·재조정을 우회하는 길이 있는가? 소득 급등 사건, 모은 돈 부풀리기(빚·집·예약), 상품 사이 갈아타기, 사라지는 상품의 자동 예금 이전, 2026년 이후 시나리오 해 고르기를 본다.
   - 「수저 순위를 뒤집지 못함」의 정의와 게이트(▲24-a 격차 25%·▲24-b `F_k ≤ 3%p`·▲24 중앙값 비)가 SPEC 9절 6의 뜻을 제대로 재는가?
   - 손계산 값(B안 lag 1 이득 1,148만 원 = 수저 1→2 격차 5,891만 원의 19.5%)을 지금 시세 표로 다시 재 보라.
3. **흔들림·시나리오의 결정성**: 해시 키(2-4절)와 `famSeedOf(peerSeed ?? seed)`가 저장·복원·다시 태어나기·스위치 끄고 켜기에서 같은 값을 내는가? 기존 RNG 스트림 호출 수가 정말 그대로인가(자동 모드 포함)?
4. **실질 수익률 정의**: 곱셈식 정산과 `market-history.md` 4-3(단순 차)·4-4의 관계가 맞는가? 총수익 통일(배당 정액 ▲10, 가격 지수 그대로인 상품)이 상품 사이 지배를 만들지 않는가?
5. **저장·복원·롤백**: `withValidSpend`·`withValidHold`의 「그 필드만 버린다 / 그 키만 버린다 / 불변식에 맞춰 줄인다」가 서로 모순되거나 돈을 만들 수 있는가? 이전 버전으로 열 때(필드 통과·보존) 무엇이 멈추고 무엇이 어긋나는가? `SPEND_ENABLED`·`HOLD_ENABLED` 조합 4가지가 모두 일관된가?
6. **기존 경제·통계와의 충돌**: 집 지분을 생활비에서 빼는 변경(Q10), 이중 계산(쓰기 × 사건 비용 × 부모 투자 × 초점), 쓰기 스탯 상한이 20세 스탯 가드·엔딩 분포·`check:economy`를 흔드는 크기를 추정하라.
7. **자동 모드**: 기질·수저 가중(`RISK`·`TIERRISK`·`SPR`)이 한 전략으로 몰리거나(60% 가드) 수저 차를 키우는 방향으로 작동하는가? 자동 모드에서 가상자산 0(Q6)이 측정을 왜곡하는가?
8. **조건 금지와 민감 소재**: 외모·성별이 간접 경로(가족·연애 플래그·`has_partner` 등)로 가격·추천·효과에 들어오는가? 정치·도박·개별 종목·상호가 들어올 틈이 있는가?
9. **노년 경제 보정(5-11절, 9-3절 Q19~Q22)**: 원인 진단(0 흡수·55세 소진)이 지금 코드(`src/core/economy.ts`의 안전망·생활비·연금, `src/data/economyTable.ts`)와 맞는가 — 가능하면 지금 코드로 재 보라. 레버 L1~L3이 돈 보존·기존 가드(재력 1 < 2 엄격 가드, `check:economy`, 20세 스탯·판 길이)를 깨는가. 목표(1단계 ≤ 32%·배포 조건 ≤ 10%·끝 수저 칸이 출생 비율과 칸마다 ≤ 8%p)가 「수저 변화」 장면을 정직하게 만드는 기준인가.
