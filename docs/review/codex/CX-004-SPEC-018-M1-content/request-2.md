## 4. 검증 질문
1. **남길 것을 건드렸는가**: 수저 구간 글자(룰렛·출생신고·프로필), 출생 화면 백분위, 엔딩 최종 스탯의 처음 값 비교, 최종 순자산 줄(20세 전후·자산 없음), 연표·플레이 시간·사망 줄이 삭제 전과 같은가(`eede085`과 같은 시드·같은 저장으로 대조).
2. **저장·복원**: 엔딩 저장(옛 v0.5.1 저장 포함)을 열 때 깨지거나 다른 회고가 나오는가. 회고가 저장되지 않는다는 주장(`src/core/storage.ts`)이 맞는가.
3. **R1 스냅숏 해시 갱신이 정당한가**: 해시 입력에서 이동 판정 칸만 빠졌고 나머지(표본 줄 해시·연령대 표·목표·가드·사망 시점 순자산·`reportTime`)는 그대로인가. 해시를 다시 산출하면서 다른 회귀를 덮지 않았는가.
