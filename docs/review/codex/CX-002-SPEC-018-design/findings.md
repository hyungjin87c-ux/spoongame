- 미확인 사항: 신규 갱신의 실제 횟수·연표·가림 켬/끔 동치는 구현 후 검증 대상이다. 가족 사건과 `seen`의 단절은 현재 코드로 재현했다.

### CX-002-007 튜닝 사다리가 같은 버전 저장의 적성 상태를 바꾼다

- 심각도: 중간
- 규칙: `CR-SAVE`
- 위치: `docs/data/persona-model.md:85–90,188–198,203,215,245–248`
- 문제: 6-1절은 `g`를 정수 0~30으로 저장하고 범위를 벗어나면 `persona` 전체를 버린다. 7절은 같은 버전에서 `GMAX`를 25~35로 조정할 수 있게 한다. 저장 상한과 런타임 상한이 같이 움직이는지 규칙이 없다. 저장하지 않는 싹은 식·태그를 One-way로 묶었지만, 재계산에 쓰는 싹 계수도 사다리에서 바뀔 수 있어 같은 시드와 `g`의 자격이 배포 시 바뀐다.
- 재현 조건과 근거: `s=80,g=8`은 계수 0.70이면 적성 64(mid), 0.75이면 68(high)다. `g=30`인 합법 저장을 상한을 25로 내린 검증기에 주면 범위 위반이다. 반대로 상한 35로 키운 앱이 `g=35`를 쓰면 0~30을 검증하는 같은 `persona.v=1` 앱은 거부한다.
- 실제 영향: 사건·직업 자격이 활동 없이 달라지거나, 검증기가 런타임 상한을 그대로 쓰면 적성과 함께 기질·확정 직업도 사라진다. 상한을 낮춰도 30을 보존하는 구현과 25로 잘라 버리는 구현의 결과가 다르다.
- 권장 대응: 저장 허용 범위와 성장 상한을 분리하고 과거 저장의 높은 `g`를 어떻게 보존하는지 명시한다. 싹 계수 변경을 기존 판에 적용할지, 배정 버전에 고정할지 확정하고 양방향 로드와 자격 경계 시험을 둔다.
- 미확인 사항: 실제 값 조정 계획은 미확인이다. 사다리에 허용된 입력의 단계 이동과 범위 충돌은 산술로 확인했다.

### CX-002-008 활동 끌림의 합이 자동 선택 60% 기준을 넘을 수 있다

- 미확인 사항: 20회 같은 활동이 가능한 실제 사건표와 그 빈도는 미확인이다. 계산값과 지원 범위 안의 반례는 재현했다.

| 3. 외모·곱 상한 | 명시된 5개 사건에서 중립 배수 1을 생략한 네 개의 상호 배타적 모디파이어로 교체한 데이터는 현행 `validateEventFiles`를 통과했다. 사건당 4~5개, 보수적 최악 가중 전체 범위 1.365~36.72다. 새 결합에는 여유가 자동으로 보장되지 않는다. 예를 들어 기존 허용 경계 `0.1×0.2×0.5=0.01`에 ×0.30을 별도 채널에서 곱하면 0.003이다. 합성 가중도 빌드 검사에 포함해야 한다. 기존 외모 하드 조건 `youth-approached`는 승인된 예외로 유지했다. |
| 4. 낙인 | 성장 부분 모형의 20세 전 `shown` 분포 차이는 기질별 최대 2.32%p였다. 활동·역경·본보기와 새 콘텐츠를 제외한 모형이므로 8%p 가드나 실제 체감의 통과 판정으로 쓰지 않았다. 연애·결혼·출산의 교차 효과는 CX-002-011에 기록했다. |
| 5. 재시도·자동 | 동일 저장의 동일 나이·`tries`와 가족 시드에서 같은 지원 난수가 나온다. 나이를 바꾸면 같은 `tries`도 새 추첨이다. 밀레니얼 시드 8, `tries=0`의 `famHash01(famSeed,21,60,나이×10)`는 21세 0.985823, 23세 0.192847이다. 이전 행동을 바꿔 실제 지원 나이가 달라지면 동일 합격률 0.6에서도 실패→합격이 가능하다. 이것을 새 기회로 볼지 동일 지원의 재추첨으로 볼지 계약이 필요하다. 정상 UI에서 의도적으로 그 두 나이를 고르는 경로와 새 직업 자동 선택의 지배율은 미확인이다. |
| 6. 자격·선택지 | 현재 `visibleChoices`는 정의 순서를 유지하며 자르지 않는다. 새 `year`는 `isEventEligible`만 아니라 가중·선택지·보너스·변주에서 같은 달력 연도로 전달되어야 한다. 현재 `stepYear`는 `year`를 자격용 `view`에만 더하고 가중·가시성에는 별도 `ctx`를 쓴다(`life.ts:337–338,365,407`). 새 구현과 골든 보강은 CX-002-003~005에 기록했다. |
| 7. 직업 소득 | `jobMul`은 현행 소득 함수에 아직 없으므로 최종 경제 가드 미확인이다. 2026년 이후는 문서에서 2025년 값 연장을 명시했다. 앞쪽 공백과 비교 분모는 CX-002-010에 기록했다. |
| 8. 저장·One-way | 현재 v9 파서는 대기 없는 상태의 모르는 최상위 `persona` 필드를 통과·보존한다. 문제는 기존에도 검증하는 `pending`과 신규 값의 수명이다. 동일 이름·태그의 기존 충돌은 확인되지 않았으며, 직업 ID와 배열 길이·키는 재사용 없이 고정하고 `v`별 복구를 검증해야 한다. CX-002-001·007 참조. |

### 현재 엔진에서의 외모 사슬 대조

밀레니얼 `seed=100003×i+1979`(`i=1..1000`)의 같은 출생을 각 열에 사용했다. `startLife`가 출생을 마친 뒤 외모만 20(1단계) 또는 80(5단계)으로 지정했다. `stepYear`·`autoResolveStep`으로 45세 해까지 진행했다. 도달은 해당 나이 해를 포함해 한 번이라도 조건을 만족한 판의 수이며 분모는 각 1,000판이다.

교체 풀은 `school-first-love`, `youth-meeting`, `youth-meeting-again`, `youth-matchmaker`, `youth-workplace-romance`의 기존 외모 가중을 `LOOKW.romance`로 대체했다. `youth-startup`·`middle-business`의 외모 가중·보너스는 삭제했다. 두 풀 모두 기존 결혼 가중·첫사랑 결과 보너스·`youth-approached` 조건·현재 취업 흐름은 그대로 사용했다.

| 풀·외모 | 35세까지 `has_partner` | 35세까지 `married` | 40세까지 `has_child` | 45세까지 자가 주거 | 20세 관계 / 행복 평균 |
|---|---:|---:|---:|---:|---:|
| 현재·1단계 | 660 | 280 | 84 | 379 | 61.39 / 48.23 |
| 현재·5단계 | 879 | 485 | 127 | 298 | 62.97 / 51.20 |
| 교체·1단계 | 579 | 220 | 67 | 368 | 61.32 / 48.30 |
| 교체·5단계 | 874 | 471 | 132 | 290 | 62.87 / 51.09 |

20세 도달은 각 999판, 35세 해를 넘긴 판은 각 998판이었다. 교체 풀에서 수저 1(각 249판)의 연애 경험은 131/209판, 결혼은 44/100판, 출산은 12/33판이었다(각각 외모 1/5단계 건수). 이 표본에서는 자가 주거가 같은 방향으로 움직이지 않았다. 결혼 시 기존 주거와 수저별 이동·부채 규칙이 다르므로 연애 비율에서 자가 결과를 추론할 수 없다.

### 적성 성장 부분 모형

같은 밀레니얼 출생 시드 식으로 `i=1..5000`을 사용했다. 같은 `peerSeed`·양육 방식에서 수저 1·5를 대입했다. 9절 표와 현재 `famHash01`을 사용해 3~18세 양육 흐름, 6~18세 짝수 나이 학업 +1, 4~18세 투자·기질 친화·체감만 1회씩 적용했다. 주요 기질 세기에는 `(2,born)`을 사용했다. 값은 **학업·예술·운동·손재주·사람 상대** 순서다.

| 수저 | 평균 `g` | 축별 high 비율 | 하나 이상 high | 하나 이상 low | 상한 `g=30` |
|---|---|---|---:|---:|---:|
| 1 | 10.79 / 2.06 / 2.83 / 1.42 / 1.56 | 11.62 / 2.64 / 3.30 / 1.86 / 2.04% | 19.72% | 92.34% | 0 |
| 5 | 14.00 / 4.94 / 5.54 / 2.73 / 4.35 | 16.34 / 4.92 / 5.70 / 2.50 / 4.10% | 29.78% | 87.14% | 0 |

학교 공통분·싹이 포함된 최종 적성에서 수저 비율은 투자 확률 비율보다 완만해진다. 이 결과는 별도 활동 없이도 가난한 판의 high와 부유한 판의 low가 존재함을 보여 준다. 최종 활동·역경·본보기·선택지 노출의 결합은 미확인이다.
