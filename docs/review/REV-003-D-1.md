## 마스터 결정 (2026-10-15)
- **R-124**: SPEC-003의 해당 예시 문구는 「뜻 유지, 문구는 designer 자체 작성」으로 바꾼다. 단 **형진 님이 원문에서 직접 지정한 문구**(「0000명이 이 시뮬레이션 속에서 각자의 삶을 살고 있어요」, 「1. 적어두고 살기 / 2. 마음속에 담고 살기」, 버튼 이름 — 일시정지·BGM·생각 남기기·다크모드·의견 보내기·나가기·태어나기·살아가기)는 그대로 쓴다.
- **R-128**: DS1 기준은 **워드마크 글자 높이**로 — 첫 화면 ≥ 40px(현행), 화면 헤더 ≥ 22px(로고 요소 약 40px). A안은 헤더·파비콘 등 작은 크기용 **단순화 심볼**(지도 윤곽을 줄인 판)을 따로 둔다. 큰 크기 A안은 머리 안 지도를 머리 높이 70% 이상으로.
- **R-131**: 보조 문구에서 「접속자」를 쓰지 않는다 — 예: 「이 기기 안에서 계산한 가상의 사람들이에요. 지금 게임하는 실제 사람 수가 아니에요.」(designer가 다듬음). VP2 점검은 그대로.
- **R-135①**: 출생신고·프로필에 외모 **원점수는 숨기고** 「상위/하위 약 N%」(또는 중간 문구)만 — SPEC BR2·DB9 그대로.
- **R-136①**: 엔딩의 「출발선」 영역은 등급명(수저 칩) 허용 목록에 넣는다(회고에서 태어난 집을 되짚는 자리). 이벤트 본문·연표에는 여전히 금지(C4).
