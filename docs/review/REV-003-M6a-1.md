### 남은 것·한계(정직하게)
- Volling 2012 정오표(Psychol Bull 2014;140(2):465)의 내용은 확인하지 못했다(PubMed에 별도 기록이 없고 검색 결과 0건). 인용은 초록 요지만 쓰며 메모에 적었다.
- 보도자료 「조혼인율 전년대비 0.4건 증가」는 표 반올림 값과 0.3건 차이다(원인 미확인) — 문장에서 증감 건수를 뺐다.
- 지난 세상 시대별 시·도 목록의 직할시 독립 연도(부산 1963·대구/인천 1981·광주 1986·대전 1989)는 일반 연혁 지식이고 공식 연혁 원문과는 대조하지 않았다(설계값으로 표기).
- 2026 새 구의 출생아·합계출산율은 인구 비례 설계값이다(실제 출생 통계 아님 — 신생 구는 2026년분 통계가 아직 없다).
- 검수자 기억 값(15~29세 고용률 41.5·42.3·45.8)은 KOSIS 표와 달라 데이터를 고치지 않았다.
- 작업 중간에 전체 `npm test`가 한 번 `tests/pipeline.test.ts` 8개와 `tests/buildConfig.test.ts` 1개에서 실패했다. 파이프라인은 다른 작업자가 같은 작업 트리에서 고치던 `src/core/*`의 진행 중 상태 때문이었고(이번 작업은 `src/core`를 건드리지 않았고 그 테스트는 통계 데이터를 읽지 않는다) 다시 돌렸을 때 통과했다. `buildConfig.test.ts`는 이번에 더한 `check:basis`·`gen:basis` 스크립트 이름을 목록에 넣어 고쳤다. 중간 전체 실행: 37파일 / 1542개 통과(마지막 실행에서는 디자이너가 고치는 중인 `tests/designAssets.test.ts` 2개만 실패 — 이번 작업과 무관). `npm run check:todo`·`npm run check:basis` 통과.
