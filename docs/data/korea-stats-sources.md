## 2. 접근 규칙과 접근 기록 (SC3·EV3, 마스터 결정 2026-10-15 R-149)

### 접근 규칙 (이번 작업부터 적용, SPEC EV·SC4 갱신)
1. 로그인·가입·인증키 없이 열리는 공개 보도자료·통계표·기관 누리집 본문만 읽는다. 인증키가 필요한 API는 쓰지 않는다(C4).
2. **요청 사이 1초 이상**, **사이트당 한 작업에서 300회 이하**(넘으면 마스터 승인).
3. **위장하지 않는 식별 User-Agent**를 쓰고 기록한다.
4. **봇별 robots.txt(ClaudeBot · Claude-User · `*`) 확인을 본문 요청 전에 별도 단계로** 한다(확인과 본문 요청을 한 명령에 넣지 않는다).
5. 문서 뷰어의 쪽 단위 대량 내려받기는 지양한다(보도자료 본문·통계표 우선).
6. 차단·CAPTCHA·로그인 요구를 만나면 중단하고 우회하지 않는다(우회 도구(insane-search 포함)·프록시·계정 생성 금지).
7. 웹 확인은 내장 브라우저(`mcp__Claude_Browser__*`) 또는 WebFetch로 한다(스크립트로 요청하지 않는다).

### 1차 수집(M6a)의 접근과 인정 사항
- 1차 수집은 스크립트로 `mods.go.kr`에 **855회**(문서 쪽별 글자층 788쪽·쪽 이미지 13장·미리보기 연결·게시글·기관 연혁 등)를 순차(쪽마다 약 1초 간격) 요청했다. 사이트별 한도가 정해지기 전이었고 robots 허용·공개 자료·순차 요청이라 **마스터가 인정**했고(R-149), 위 규칙을 이후 작업에 적용한다. 그 스크립트의 User-Agent는 기록하지 않았다(**미기록**).
- 먼저 `robots.txt`를 열어 허용 여부를 확인했고 불허 출처는 쓰지 않았다(아래 표). 차단·CAPTCHA·로그인 요구를 만난 출처는 0건.
- ⚠ **robots 실수 1건**: 한국소비자원(`www.kca.go.kr`)의 `Disallow: /`를 확인한 같은 명령에서 그 도메인 페이지 1건이 요청됐다(실수). 내용은 읽은 뒤 쓰지 않았고 저장본을 삭제했으며 결혼 비용 값에 반영하지 않았다. 이 실수가 「확인과 본문 요청 분리」 규칙(위 4)의 이유다.
- 저장 대화상자 1회: 한국대학교육협의회(`kcue.or.kr`)의 PDF 첨부 주소를 브라우저 창이 열자 저장 대화상자가 떴다(저장하지 않음). 같은 내용은 교육부 보도자료 본문으로 읽었다.

### 1차 수집의 읽은 방법 (재현용)
1. **보도자료 문서**: 국가데이터처 누리집 게시글의 「미리보기」가 쓰는 문서 뷰어(`/attachPreview.es?bid=<게시판>&list_no=<글번호>&seq=<첨부>` → `/synap/preview/board/<게시판>/<해시>.files/<해시>_<쪽>.xml`)의 **쪽별 텍스트층**을 읽어 줄로 이어 붙였다. 첨부 파일(pdf·hwp)을 내려받지 않았다. 글자층에 숫자가 없는 쪽(혼인·이혼 통계, 생명표, 가계금융복지조사의 대부분)은 같은 뷰어의 **쪽 이미지**를 열어 눈으로 읽었다. (이 방법은 새 규칙 5에 따라 앞으로 쓰지 않는다 — 보도자료 본문·KOSIS 표를 우선한다.)
2. **KOSIS 통계표 화면**: 브라우저 창에서 표 화면(`https://kosis.kr/statHtml/statHtml.do?orgId=…&tblId=…`)을 열고 화면에 그려진 표의 셀 값을 읽었다. 기간은 화면의 「시점」 창에서 사람이 고르듯 골랐다. KOSIS OpenAPI(인증키)·표 내려받기는 쓰지 않았다.
3. **기관 누리집 본문**: 교육부 보도자료(HTML), 최저임금위원회 결정현황(HTML), 한국생명존중희망재단 첫 화면, 질병관리청 예방접종도우미·국가건강정보포털, WHO 누리집, PubMed 논문 기록(브라우저 창).

### 이용 조건·출처 표시 (EV3)
- 국가데이터처 보도자료 게시글은 「`첨부파일 안의 공공누리유형` 조건에 따라 이용할 수 있습니다」라고만 적는다. **공공누리 유형 번호(1~4유형)는 첨부 문서 안에 있어 이번에도 확인하지 못했다**(미확인). 어떤 유형이든 공통인 「출처 표시」(기관·자료 이름·연도)는 데이터에 `source.org`·`source.table`·`accessedOn`으로 넣었고, M2·M3의 출처 표기 UI는 이 값을 글자로 보인다. 상업적·변경 이용 제한이 있는 유형인지는 M2 착수 때 첨부 문서에서 확인해야 한다.
- KOSIS 표는 「국가데이터처」 출처 표시가 필요하다고 화면 하단에 안내된다(표시 방법은 같다). 교육부 보도자료는 본문 끝에 「공공누리 출처표시 조건」을 밝힌다(확인함).
- 외부 링크는 화면에 걸지 않는다(EV6). `source.url`은 문서 점검용이다.

## 3. 지표별 수집 기록

「원문 대조」 열은 값을 읽은 곳과 서로 맞춰 본 것이다. 상세한 교차 확인은 `koreaStats.json`의 `verification.crossChecks`와 `tests/koreaStats.test.ts`에 있다.

### 3.0 데이터 표기 규칙 (M2·M3·M5 개발자용, R-142·R-147)
- `unit`은 시리즈 값의 단위이고 표(table)는 `null`이다. 큰 숫자 `latest`는 **`latestUnit`**이 단위이고, 지표 제목과 다른 값이면 **`latestLabel`**이 무엇인지 적는다(표·막대는 필수). 예: `birth-mother-age`는 막대 단위가 `천 명`(연령별 출생아)이지만 `latest`는 모의 평균 출산연령 33.8**세**다.
- `decimals`: 공식 표기 소수 자릿수(합계출산율 2, 출생아 수 0). 열·행·보조 시리즈에도 있을 수 있다. 화면 표기는 `formatIndicatorValue`·`formatPointValue`(`src/data/koreaStatsAccess.ts`)가 이 값을 따른다.
- `headline`: 큰 숫자가 둘 이상일 때(평균 초혼 연령 남자·여자). `axis`: 연도 시계열의 `step`·`regular`·`gaps`(간격이 1년을 넘는 구간)·`breaks`(시계열 단절). 차트는 `year`를 비례 축에 놓는다.
- `scopeLabel`: 카드에 함께 적을 기준 문구(시도별 합계출산율 「2025년 기준(17개 시·도)」, 주민등록 인구 「2026년 9월 기준(16개 시·도, 주민등록)」).
- **지표 안 미확인 하위 항목 규칙(R-140)**: 한 지표 안에서 일부만 원문과 못 맞췄으면 지표를 통째로 `usable: false`로 하지 않고 `verification.unverifiedParts: [{ part, reason }]`에 적는다(`part`: `extraSeries:<라벨>`·`series:<연도|라벨>`·`row:<열>=<값>`·`field:<점 경로>`). 접근자는 그 부분을 잘라 낸 복사본(`partial: true`)만 돌려주고, 인용(`refs`)이 그 부분을 가리키면 테스트가 실패한다(`tests/koreaStatsAccess.test.ts`). 지금 데이터에는 해당 항목이 없다(육아휴직 분모를 확인해 해소).
- 설계값(`designValue`)·파생값은 통계가 아니다: `birth-by-sido.rows16`(광주+전남 합산)·`eraRegions`(지난 세상 시·도 목록)·`birth-by-sigungu.regionChanges2026.rows`(인구 비례 재배분)이 해당하고 화면에는 「설계값」으로 표기한다.

- 확인(1절): 전남광주통합특별시(2026-07-01), 인천 제물포·영종·서해·검단구(2026-07-01), 화성시 4개 일반구(2026-02-01) — 행정안전부 주민등록인구현황 표 주석정보.
- **시도(룰렛)**: `birth-by-sido.rows16` = 2025 출생아를 2026 16개 시·도로 합친 파생값(광주 6,495 + 전남 8,719 = 전남광주 15,214명, 합 254,341, 비율 합 100.0, 가장 큰 나머지 방식). 지난 세상(1950~1989년생)은 `eraRegions`(시대별 시·도 목록 10~15개와 현재→당시 대응 `from`, 설계값), 지금·다가올 세상은 16개 시·도. 접근자 `getRouletteRegions(birthYear)`.
- **시군구(출생신고)**: `birth-by-sigungu.regionChanges2026`. 인구 기준(KOSIS 주민등록, 2026.06 옛 구·2026.07 새 구): 영종구 = 중구 출생아 × 영종구 인구(138,091) ÷ 중구 인구(179,030), 제물포구 = 중구 나머지 + 동구, 서해구·검단구 = 서구 출생아를 두 구 인구(392,173 : 273,735)로, 화성시 4개 구 = 화성시 출생아를 구 인구(234,363 : 160,788 : 175,045 : 429,477)로. 합계출산율은 옮겨 온 옛 구 값(설계값). 시도 합·전국 합 불변. 접근자 `getSigunguRows2026()`.
- 표기 문구(`meta.birthStatsBasisFootnote`): 「출생 통계는 2025년 행정구역 기준이며, 2026년에 바뀐 시·도와 시·군·구는 인구 비례로 옮긴 설계값입니다.」 — 출생신고 화면 하단 표기용.
- 한계: 지난 세상의 시·도 목록(직할시 독립 연도: 부산 1963·대구와 인천 1981·광주 1986·대전 1989, 울산·세종은 당시 없음)은 일반 연혁 지식이며 공식 연혁 원문과는 대조하지 않았다.

## 4. 갱신 방법과 주기 (SC4)

앱은 실행 중 외부 요청을 하지 않는다. 값은 **개발자가 고치고 빌드·배포**한다. 값을 고치면 `npm run gen:basis`로 근거 문서·CSV를 다시 만들고 `npm run check:basis`·`npm test`로 확인한다.

## 6. 형진 님의 생애 단계별 데이터 소스 목록 연결 (`docs/data/korea-life-data-sources.csv`)

- 원본 CSV(형진 님 다운로드 폴더의 `한국인생단계별_데이터소스_활용처.csv`, 31행)를 **그대로 복사하지 않고** 같은 열 10개(단계·순번·데이터_소스·작성기관·핵심_지표·게임_활용처·패널_여부·관련_링크·공식_사이트·비고)에 열 8개(기준연도·잠정/확정·접근방식·이용조건·원문대조·게임_마일스톤·근거_basisId·정정_내역)와 열 3개(**원본_순번·대응_메모·미대조_값**)를 더해 다시 정리했다. 이 파일은 `scripts/lifeDataCsv.ts`가 만든다(`npm run gen:basis`).
- **행 수 53(원문 대조 완료 20·부분완료 10·미완료 23)**: 원본 31행(예방접종·영유아 건강검진 / 사망원인통계·생명표는 각각 두 행으로 분리해 **33행**) + 마스터 보완 **20행**(노인빈곤율·자살률과 109·지역별 인구·출생 체중, 소득이동·국민이전계정·육아휴직·가족과 출산 조사·청소년건강행태·학교폭력·임금·산재·범죄피해·장래인구추계·과거 통계연보·최저임금·학자금대출·결혼 비용·가계신용·기준금리·은행 대출금리 등). `원본_순번` 열이 원본 1~31이 어느 행이 됐는지(분리는 `4(분리)`·`23(분리)`, 추가는 `추가`)를 보이고 `tests/spec003Baseline.test.ts`가 원본 31개가 모두 대응되는지 확인한다.
- **원문 대조**: 위 완료·부분완료·미완료 행 수는 CSV의 `원문대조` 열에서 센 값이고 테스트가 같은 수를 확인한다. 「근거_basisId」 열이 이 문서·`events-stats-basis.md`의 행 번호와 연결된다. 원문에서 추적하지 못한 값(65세 기대여명 21.7년, 15~29세 실업률 6.1%)은 `[미대조]` 표시와 `미대조_값` 열에 적었다.
- 언론 기사 링크(연합뉴스·매일경제)는 1차 출처(KOSIS·기관 보도자료)로 교체했다. 정책브리핑(korea.kr) 보도 링크도 기관 원문 보도자료로 바꿨다. 교체하지 못한 값은 「원문대조 미완료」로 표시했다.
