## 2. 순수 함수

```ts
type GenreId = 'trot' | 'folk' | 'citypop' | 'njs' | 'electropop' | 'lofi' | 'chiptune';
type Mood = 'base' | 'tense' | 'lively';

eraGenreOf(year: number): GenreId          // 아래 표. 모든 정수 연도(1940~2100)에서 정의된다
bgmMoodAt(year: number): Mood              // BGM_MOOD_YEARS 조회. 금지 해와 후보가 아닌 해는 'base'
bgmGenreAt(year: number): { genre: GenreId; mood: Mood }   // 위 둘의 합
```

- 입력은 `calendarYear = birthYear + age` 하나다. 같은 달력 연도면 어느 세대·어느 나이든 **같은 장르·같은 변주**(BG3 단언).
- `eraGenreOf` 표:

| 달력 연도 | 장르 | 비고 |
|---|---|---|
| ≤ 1969 | `trot` | 1940년대 포함 |
| 1970~1979 | `folk` | |
| 1980~1989 | `citypop` | |
| 1990~1999 | `njs` | |
| 2000~2009 | `electropop` | |
| 2010~2019 | `lofi` | |
| ≥ 2020 | `chiptune` | 전망 구간(2026~)도 계속 |

- 세대의 `bgmReference`(GD1)는 표시·문서용이다 — 한 사람이 평생 그 장르만 듣지 않는다.
- 생애 장르 전환 횟수: 출생 1940, 사망 2025 이후라면 1970·80·90·2000·10·20의 **6회**가 최대다(2020 이후 `chiptune` 유지). 시험: 모든 (출생 연도 1940~2020 × 사망 나이 0~110) 조합에서 ≤ 6.
- 복원: 새로고침·저장 복원 때 BGM은 저장하지 않고 현재 달력 연도에서 `bgmGenreAt`을 다시 계산한다(설정 `bgmMode` 없음, MG1).

## 3. 장르별 시간 단위 (변주 길이의 근거)

지금 엔진: 4/4, 한 곡(pattern) = 4마디, 현재 BPM 76(마디 3.16초, 패턴 12.6초). 장르별 BG1 템포의 중심값 ▲로 계산한 시간 단위:

| 장르 | 템포 범위(BG1) | 중심 BPM ▲ | 한 마디(초) | 패턴 4마디(초) | 1배속 조용한 해 11.8초 ≈ 패턴 |
|---|---|---:|---:|---:|---:|
| trot | 84~96 | 90 | 2.67 | 10.7 | 1.1 |
| folk | 88~104 | 96 | 2.50 | 10.0 | 1.2 |
| citypop | 96~108 (발라드 68~76) | 102 | 2.35 | 9.4 | 1.3 |
| njs | 100~112 | 106 | 2.26 | 9.1 | 1.3 |
| electropop | 120~128 (발라드 72~80) | 124 | 1.94 | 7.7 | 1.5 |
| lofi | 70~84 (하프타임) | 77 | 3.12 | 12.5 | 0.9 |
| chiptune | 140~160 | 150 | 1.60 | 6.4 | 1.8 |

- 1배속에서 서술 해 28.7초는 패턴 2~4개, 선택 카드가 있는 해는 읽는 시간에 따라 더 길다. 그래서 **사건 하나 = 변주 한 해 = 패턴 1~3개**로 들린다.
- 한 장르는 한 연대(약 10년)이고, 1배속에서 한 연대는 약 3~4분이다(BG4의 「한 장르가 보통 3~4분」과 일치).
- 4~8배속에서는 한 해가 1.5~7초라 변주가 한 패턴보다 짧게 지나간다. 변주는 **해에 묶고**(최소 지속 시간을 두지 않는다) 높은 배속에서는 거의 들리지 않을 수 있다 — 이를 받아들인다 [B-03]. 최소 지속을 두면 금지 해로 변주가 새어 나가 N23과 충돌한다.

## 4. 변주 사양 (BG3)

### 4-1. 종류와 정의

| 종류 | 템포 | 음계·진행 | 질감 | 쓰임 |
|---|---|---|---|---|
| `tense` | 기본보다 6~12 BPM ▲ 느림 | **단조 쪽으로 한 가지**(장조 장르는 병행 단조 중심으로, 이미 단조인 장르는 낮은 음역·여백 쪽으로) | 장식음·타악 밀도를 줄이고 음역을 낮춘다 | 경제 위기 등 |
| `lively` | 기본보다 6~12 BPM ▲ 빠름 | **장조 쪽으로 한 가지**(장조 장르는 상행 진행·장7화음 강조, 단조 장르는 병행 장조 쪽으로) | 타악·장식 밀도를 높이고 음역을 올린다 | 큰 대회·호황 등 |

- 변주는 템포와 음계(장·단 쪽) **둘 중 한 가지 이상을 바꾸되 같은 장르의 악기·리듬 언어를 유지**한다. 변주도 **오리지널 악보**다(BG6 — 실제 곡의 멜로디·리프를 쓰지 않는다). 변주를 알려진 곡의 분위기에 가깝게 만들지 않는다.
- 비극을 음악 연출로 극화하지 않는다는 N23의 취지에 따라 `tense`는 **경제·문화 사건**(외환위기·금융위기·석유파동)에만 쓴다. 전쟁·참사·재난·정치·감염병의 해에는 `tense`도 `lively`도 없다.

### 4-3. 진입과 복귀

- 변주 진입·복귀는 **마디 경계에서 패턴을 갈아 끼우는 것**이다. 장르 전환(4~8초 교차 페이드, 마디 경계)과 달리 긴 페이드를 쓰지 않는다. 같은 장르이므로 음색·악기 구성은 그대로다.
- `bgmMoodAt(year)`이 `base`로 돌아가야 하는 순간(금지 해 진입 포함)에는 **다음 마디 경계(최대 1마디 ≈ 1.6~3.1초)** 안에 기본 패턴으로 돌아온다. 이 지연은 허용하지만 한 마디를 넘지 않는다.
- 인접한 변주 해(1997~98, 2008~09)는 한 변주를 끊지 않고 이어서 쓴다. 1986과 1988처럼 사이에 금지 해(1987)가 끼면 변주가 끊겼다가 다시 시작한다.

### 4-4. 기본 음악은 항상 흐른다

변주 금지 해에도 **세대 장르가 아닌 그 해의 시대 장르의 기본 음악**이 평소처럼 흐른다(N23). 사건 해에 음악을 끄거나 무음으로 만들지 않는다.

## 6. 금지 우선 규칙과 데이터

### 6-1. 필드와 빌드 검증 (timeline-schema.md V-21)

- `bgmMood: 'tense' | 'lively'`는 **`experience-economy`·`experience-culture` 사건에만** 붙일 수 있다. `experience-social`·`background`·`regional`·`conflict`·`projection`에는 붙일 수 없다(스키마 금지).
- `bgmBan: true`는 `background`·`regional`에 **필수**이고, 감염병 체험(`sensitivity: epidemic`)에도 필수다. `banYears: [from, to]`는 사건 연도보다 넓은 금지 범위(전쟁 기간 등)에 쓴다.
- 빌드 단계에서 `BGM_MOOD_YEARS: Record<year, 'tense'|'lively'>`를 만든다: 모든 `bgmMood` 사건의 `years`를 모으되 **같은 해에 `bgmBan` 사건이 하나라도 있으면 그 해는 넣지 않는다.** 한 해에 `tense`와 `lively`가 겹치면 빌드 실패(해 하나에 변주 둘 없음).
- 시험: (1) 생성 결과가 5절 표와 같다 (2) 변주 해에서 `bgmBan` 사건 0건 (3) `BGM_MOOD_YEARS`의 키가 연표 사건 `years`의 부분집합 (4) 같은 달력 연도는 어느 세대·나이에서도 같다.

### 6-2. 금지 판정의 범위 [B-02]

- **R-A (추천)**: 전국 `background`, **승인된** `regional`, 감염병 체험을 모두 금지 근거로 쓴다. 지역 체감은 형진 님이 승인한 사건만 들어오므로 보수적이다.
- R-B: 전국 `background`와 감염병만 쓰고 `regional`은 쓰지 않는다. 음악 변주를 더 많이 살릴 수 있으나, 어떤 지역의 사고·재난이 있던 해에 밝은 변주가 흐르는 일이 생긴다.
- **2002 충돌**: 월드컵(문화, 5-1)이 N23의 예시인데, R-11(태풍 루사 피해, 후보)이 같은 해에 있다. R-A에서는 R-11이 **승인되면 2002 변주가 사라진다.** 형진 님이 RG11에서 R-11을 승인할 때 이 효과를 함께 보여 줄 것을 제안한다(승인해도 되고, 승인하지 않고 변주를 살려도 된다). 달력 연도 단위라 월 구분은 하지 않는다(월드컵은 6~7월, 태풍은 8~9월이지만 모델은 연 단위).

## 7. 전환·페이드·재생 시간

- 장르 전환은 마디 경계에서 4~8초 교차 페이드, 같은 해에 두 장르가 겹쳐 흐르지 않는다(BG3). 장르 경계 해(1970·80·90·2000·10·20)에서만 일어난다.
- 변주 전환은 4절의 패턴 교체이며 교차 페이드를 쓰지 않는다. 변주 진입은 해가 바뀐 뒤 **다음 마디 경계**에서 시작한다(최대 1마디 지연).
- 일시정지·탭 가림·끄기 상태에서는 `bgmGenreAt` 계산만 유지하고 소리는 BG5의 기존 규칙(탭이 가려지면 `suspend`)을 따른다. 사용자가 BGM을 켜기 전에는 아무것도 불러오지 않는다(지연 로드, GM0 결정 1).
- 배속 변경과 「다음 결정으로」 건너뛰기: 연도가 빠르게 지나가도 소리는 **현재 달력 연도에 맞는 장르·변주**로 마디 경계에서 수렴한다. 건너뛴 연도의 변주를 나중에 재생하지 않는다.
