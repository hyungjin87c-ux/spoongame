## 1. 번들 크기 (CM6: 초기 로드 gzip ≤ 400KB▲)

`npx vite build`(출력 폴더만 임시 폴더로 바꿈)로 만든 결과를 node의 zlib(gzip 레벨 9)로 압축한 크기다.

| 파일 | 원본(바이트) | gzip(바이트) |
|---|---:|---:|
| index.html | 398 | 284 |
| assets/index-*.js | 335,969 | 101,429 |
| assets/index-*.css | 6,925 | 1,955 |
| **합계** | **343,292** | **103,668** (약 101.2KiB) |

- 400KB 예산의 약 26%를 쓰고 있다. 이미지·폰트·음원 같은 별도 자산은 지금 없다(외부 요청 0).
- Vite가 화면에 찍는 gzip 합은 104.2kB(10진 킬로바이트: JS 101.92 + CSS 1.96 + HTML 0.28)로, 압축 레벨이 달라 약간 크게 나온다. **비교는 같은 방법끼리** 한다.
- 앞으로 더해질 데이터 크기(M6a 산출물, 아직 번들에 들어가지 않음): `src/data/koreaStats.json` 140,281바이트(gzip 30,320), `src/data/citations.json` 44,997바이트(gzip 9,736) — 둘을 통째로 넣으면 gzip 약 40KB가 늘어 **약 143.7KB**가 된다. M2가 화면에 필요한 지표만 가져오거나 `verification` 설명을 줄이면 더 작아진다.
- 얼굴 SVG(M1)·BGM(코드 생성이라 파일 없음)은 이 숫자에 아직 없다.
