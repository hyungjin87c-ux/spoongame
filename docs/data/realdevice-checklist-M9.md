# 1차 릴리스 실기기 점검 (형진 님용) — 약 20분

- 주소: https://hyungjin87c-ux.github.io/spoongame/
- PC 7개(약 9분) + Android 5개(약 11분). 문제가 있으면 **번호 + 한 줄**(필요하면 스크린샷 — 직접 적은 글은 가려 주세요)을 채팅이나 「의견 보내기」로 알려 주세요. 괜찮으면 「모두 통과」 한마디면 됩니다.
- 플레이 시간 실측(1배속 한 판)과는 **따로** 해 주세요. 아래 점검은 8배속·「다음 결정으로」를 써도 됩니다.
- 원본 목록: `docs/data/content-M9.md` 5절.

## PC (평소 쓰는 브라우저)

| # | 하는 것 | 이렇게 보이면 통과 |
|---|---|---|
| PC1 | 첫 화면에서 창 폭을 최대 → 반쪽 → 좁게, 그다음 Ctrl + 로 200%까지 확대 | 로고·인구 문구·세상/길이 카드가 보이고, 「태어나기」가 늘 같은 자리, 가로 스크롤바 없음, 통계 슬라이드가 저절로 넘어감 |
| PC2 | 「태어나기」 → 룰렛 → 출생신고에서 F5 | 룰렛이 5~6초 부드럽게 돌다 멈춤, 새로고침해도 같은 출생신고, 직업·지역 글자가 낱말 중간에서 안 끊김 |
| PC3 | 「살아가기」 → 8배속, 창 좁히기, 다크 모드 켜고 끄기 | 3열이 한 화면, 좁히면 1열로 접혀도 위쪽 줄이 안 튐, 두 테마 모두 글자가 잘 읽힘 |
| PC4 | 「다음 결정으로」 → 카드 → 「카드 접기」 → 「결정 다시 열기」 → 「생각 남기기」에 한글·이모지(Win + .) 적기 | ▲초록·▼붉음 영향 줄이 읽히고 선택지가 아래 띠에 안 가려짐, 같은 카드가 돌아옴, 「나의 기록」에 글이 깨짐 없이 남음 |
| PC5 | 마우스 없이 Tab·Enter·Space로 첫 화면 → 결정 카드 선택까지 | 포커스 표시가 늘 보이고 가려지지 않음 |
| PC6 | 플레이 중 F5 · 뒤로가기 후 다시 열기 · 같은 주소 두 탭 · 다른 탭에 30초 있다 오기 | 같은 나이로 복귀(진행 막대는 0%부터 — 알려진 제한), 두 탭일 때 첫 탭 안내 문구가 많이 놀랍지 않은지, 30초 뒤 나이가 같거나 많아야 한 살 |
| PC7 | 「나가기」 → 「이어서 살기」 → 8배속으로 끝까지 | 같은 나이로 복귀, 엔딩에 플레이 시간·출발선 막대, 「다시 태어나기」 동작 |

## Android (폰 브라우저)

| # | 하는 것 | 이렇게 보이면 통과 |
|---|---|---|
| AN1 | 「태어나기」부터 8배속 + 「다음 결정으로」로 엔딩까지 한 판 | 첫 화면을 밀어도 「태어나기」 고정, 룰렛 부드러움, 주소창이 접히고 펴져도 위아래 줄이 안 튐, 결정 카드 선택지가 아래 띠에 안 가려짐, 엔딩 정상 |
| AN2 | 출생신고에서 홈으로 나갔다 오기 · 1배속에서 30초 나갔다 오기 · 브라우저 완전히 닫고 「이어서 살기」 | 같은 화면으로 복원, 나이가 같거나 많아야 한 살, 같은 나이로 이어짐 |
| AN3 | BGM 켜고 끄기(소리 켬), 새로고침 직후 다시 켜기 | 잔잔한 소리가 나고 끄면 멈춤 |
| AN4 | 「생각 남기기」 입력란 탭 → 한글·이모지(가족·국기) → 적어두기 | 키보드가 올라와도 두 버튼이 보이고 화면이 확대·밀림 없음, 「나의 기록」에 그대로 남음 |
| AN5 | 폰 설정에서 글자 크기 최대 → 새 판으로 첫 화면·룰렛·출생신고·결정 카드·「나가기」 확인 | 글자 겹침·한 글자 줄바꿈 없음, 버튼·안내가 아래 띠 뒤로 숨지 않음(밀면 닿음) |
