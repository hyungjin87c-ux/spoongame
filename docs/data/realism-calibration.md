## 1. 기준선이 보여 준 것 — 단계별로 쪼개기

기준선 3-3절의 정석 문 조합 분포(random, 65세 이상 산 판)에서 역산했다. 상위 8조합이 지난 95.7% · 지금 96.6%라 **나머지 4.3% · 3.4%에 든 조합은 모른다**(그래서 각 비율은 하한이다). C 취업(`has_career`) · M 결혼(`married`) · K 출산(`has_child`) · H 내 집(`own_home` 또는 주거 `own`).

| 단계 | 지난(X 대리) | 지금(밀레니얼 대리) | 계산 |
|---|---:|---:|---|
| C 취업한 판 (하한) | 85.7% | 87.8% | C 포함 6조합 합 |
| M 결혼한 판 (하한) | 29.1% | 26.9% | CM-- + CM-H + CMK- + CMKH |
| K 자녀 둔 판 (하한) | 6.9% | 5.3% | CMK- + CMKH |
| H 내 집 (하한) | 41.3% | 44.5% | C--H + CM-H + CMKH + ---H |
| **통과율 M ÷ C** | **34.0%** | **30.6%** | |
| **통과율 K ÷ M** | **23.7%** | **19.7%** | |
| 통과율 H ÷ (CMK) | 47.8% | 58.5% | CMKH ÷ (CMK- + CMKH) |
| C × (M÷C) × (K÷M) × (H÷K) | 3.3% | 3.1% | = CMKH (기준선 3.3 / 3.1%) |

- **가장 많이 잃는 곳은 결혼(34%/31%)과 출산(24%/20%)**이다. 내 집(H)은 결혼·출산과 독립적으로 40% 안팎이다.
- 선택자를 바꾸면 크게 변한다(기준선 3-3절): 「4개 중 3개 이상」이 random 17.7 / 16.4% → auto 32.1 / 38.7%, AL10식 정석이 3.5 / 4.2% → 8.6 / 11.8%, 순서 무관 4단이 3.3 / 3.0% → 3.8 / 5.9%. `auto`는 결혼 지향으로 설계된 선택자가 아닌데도 이렇다. 이것이 H1을 첫 가설로 세운 이유다.
- 지금 모델은 시대 안에서 출생 연도가 판에 영향을 주지 않아 X·밀레니얼을 가를 수 없다(지난 = 1950~1989년생 혼합, 지금 = 2026년생). **이 표는 세대별 값이 아니라 대리값이다.** GM10에서 세대 7종 × 1000판으로 다시 잰다.

## 2. 비교표의 틀

### 2-1. 비교 규칙 (단위 맞추기)

공식 통계와 견줄 때 지켜야 할 규칙이다. 이 규칙을 어기면 숫자가 같아도 비교가 아니다.

| # | 규칙 | 이유·예 |
|---|---|---|
| M1 | **같은 단위**: 게임의 한 사람 대 통계의 개인 또는 가구를 맞춘다. 자가·소득·순자산은 가구 단위 통계(가구주 연령 기준)라 게임에서도 「배우자를 포함한 가구」를 본다 | EC7이 이미 같은 한계(R2)를 안고 있다(9절). 개인 단위 통계가 있으면 그쪽을 먼저 쓴다 |
| M2 | **누적과 시점을 구분**: 게임 지표를 `ever(a)`(그 나이까지 한 번이라도)와 `at(a)`(그 나이의 상태) 둘로 낸다. 생애미혼율은 `1 − ever_married(50)`, 자가점유율은 `at_own(a)`, 고용률은 `at_employed(a)` | N잡 기준선(17~30%)은 누적이라 시점 통계(부업 비율)와 견줄 수 없었다(`alpha-life.md` 5-3) |
| M3 | **코호트 읽기**: 출생 연도 `b`의 나이 `a` 값은 조사 연도 `b+a`의 연령 `a` 값이다. **관측 가능한 최대 나이**(`b + a ≤ 2025`)까지만 비교한다 | 예: 밀레니얼 1981~1996년생은 25세까지는 모두 관측되지만 35세는 1990년생 이전만 관측된다. 관측 안 되는 구간은 목표 없음(전망) |
| M4 | **생존자끼리**: 게임도 그 나이까지 산 판만, 통계도 그 나이의 인구를 쓴다 | 분모를 「전체 1000판」으로 두면 일찍 죽은 판이 섞인다(H4) |
| M5 | **성별**: 게임의 정석 사슬 이벤트에는 성별 분기가 없다(`youth-military`만 남성). 통계가 성별로 크게 다르면(혼인·고용) 성별 합계와 견주고, 성별 분해는 보고만 한다 | 게임이 성별 차이를 모델링하지 않는 한계 |
| M6 | **정의 일치**: 게임의 `married`는 「함께 살기로 한다」 선택으로 켜진다(법적 혼인 단정 아님). 비교 문서에 정의를 한 줄 적는다 | 정의 차이를 숨기지 않는다 |
| M7 | **대리 세대**: GM10 전에는 지난 = 1950~1989년생 혼합, 지금 = 2026년생이다. 통계 쪽도 **같은 출생 연도 범위의 코호트**를 쓴다(X만 쓰지 않는다) | 대리 세대 한계 |
| M8 | **허용 폭은 목표가 아니다**: 목표 = 공식 값(근거 id), 허용 폭 ▲ = max(5%p, 2 표준오차)(확률형) / ±30%(중앙값형, EC7 선례). 허용 폭은 판정에만 쓴다 | 지어낸 목표 0 |

### 2-3. 세대 대리 1000판 결과표 (출력 형식)

`scripts/baseline004.ts`에 `--only=funnel`(신설 제안, 5절)을 더해 아래 표를 낸다. 행 = 세대(GM10 전에는 지난·지금 대리) × 선택자(`random`/`auto`/`course`), 열 = 아래.

| 열 | 내용 |
|---|---|
| 표본 | 판 수, 65세 이상 산 판 수, 45세 이상 산 판 수 (분모를 셋 다 보고) |
| 사슬 노출 | 사슬 이벤트별 `seen`(열렸는가) 비율, 선택지별 선택 비율 |
| 단계 통과율 | C, M÷C, K÷M, H÷(CMK), 그리고 각 단계 처음 나이 분포(중앙값·사분위) |
| 시점 값 | 25·30·35·40·50·65세의 `at_own`, `at_employed`, `at_married`, `bond` 분포 |
| 4단 변형 | 순서 무관 / 순서대로 / AL10식(입사→결혼→자가→정년퇴직) / 3개 이상 |
| 기타 | 사망 나이 평균, 대학 `college` 비율, `divorced` 비율 |

### 2-4. 판정

| 판정 | 조건 |
|---|---|
| 일치 | 게임 값이 공식 값 ± 허용 폭(M8) 안 |
| 보고 | 이탈. 3절 가설과 연결해 원인을 적고 마스터에게 보고 |
| 목표 없음 | 공식 값이 없거나 관측되지 않은 구간(M3) — 게임 값은 보고만 |
| 보류 | 지표 정의가 아직 비교 가능하지 않음(R07 등) |

## 3. 정석 4단 3~4%의 원인 가설

「확인 방법」은 코드 읽기(R)와 시뮬레이션(S)을 구분했다. 시뮬레이션은 모두 `scripts/`에서 하고 게임 코드는 바꾸지 않는다. 우선순위는 설명력 순이다.

### H1. 선택자 효과 — 균등 무작위 선택이 「예」를 1/3~1/2로 만든다 (최우선)

- **근거**: `chooserFor('random')`은 보이는 선택지를 균등하게 고른다(`scripts/simulateLib.ts`). 결혼 사슬의 각 문은 선택이다 — 미팅(나간다/미룬다), 결혼(함께 산다/기다린다/헤어진다 = 1/3), 출산(갖는다/기다린다/없이 = 1/3), 집(월세/부모 집 또는 돌아감/빚내서 = 보이는 선택지 2~3개 중 하나, 빚내서는 1/3~1/2). 1절의 통과율(34·24·48%)은 이 수와 같은 크기다. 취업→결혼 34%는 종이 계산으로 「파트너가 생기고 결혼 제안이 열릴 확률(약 0.75 안팎) × 결혼 선택 수락(재시도 포함 약 0.44)」 정도로 설명될 수 있다(시뮬레이션으로 확인 필요). `auto`로 바꾸면 2.5~2.8배가 되는 것도 같은 방향이다.
- **확인 방법 (S)**: 선택자 `course`(정석지향)를 `scripts/simulateLib.ts`에 추가한다 — 보이는 선택지 중 `has_career`·`has_partner`·`married`·`has_child`·`own_home` 중 하나를 켜는 선택지가 있으면 그것을, 없으면 시드 난수로 고른다. 같은 시드에서 `random`·`auto`·`course`의 1절 표를 낸다.
- **판정**: `course`의 M÷C·K÷M·H÷K가 `random`의 2배 이상이면 3~4%의 대부분은 선택자 효과다. 이때 **게임 구조는 정석 4단에 대한 상한을 이미 충분히 열어 두고 있다**는 뜻이고 보정 대상은 지표 정의와 비교 방법이다.
- **주의**: `course`는 현실의 선택 성향이 아니다. **구조 상한을 재는 도구**이며 목표 값이 아니다(4절 P3).

### H2. 설정 경로가 하나뿐이고 나이 창이 좁다 (플래그가 특정 사건에만 켜진다)

코드로 확인한 설정 경로(`src/data/events/*.json`):

| 플래그 | 켜는 이벤트·선택지 | 조건·창 |
|---|---|---|
| `has_partner` | `youth-meeting/meet`(24~36, 가중 11) · `youth-matchmaker/meet`(23~34, **지난 세상만**, 가중 16) · `youth-approached/give`(22~36, 외모 60 이상, 가중 10) · `youth-workplace-romance/ask`(24~38, 취업 필요, 가중 9) · `youth-meeting-again/meet`(30~46, `met_intro` 필요, 가중 10) · `youth-reunion/meet` | 모두 once, 선택 1/2 |
| `married` | `youth-marriage/marry`(27~45, 가중 40, `has_partner` 필요) · `youth-marriage-again/marry`(30~48) · `youth-second-chance/marry`(26~56) | **전부 `has_partner` 필요** |
| `has_child` | `youth-child/have`(27~39, `married` 필요, 가중 24) · `youth-child-again/have`(33~44, **`child_postponed` 필요** — 즉 `youth-child`에서 「기다린다」를 고른 판만) | 한 번에 하나, once |
| `own_home` | `youth-housing/loan`(22~36, 가중 14, **`married`이면 열리지 않는다**) · `middle-home-loan/move`(40~55, 가중 10, 조건 없음) | 주거 `own`은 결혼 때 재력 4~5단계가 자동으로 얻기도 한다(`dwellingAfterFlags`) |

- **결과로 생기는 구조**: ① **39세 이후에 결혼한 판은 `youth-child`(27~39)가 닫혀 있고 `youth-child-again`은 `child_postponed`가 없으면 열리지 않으므로 자녀 경로가 없다.** 균등 선택에서 「기다린다」가 결혼을 늦추는 재시도 사슬(`marriage_waited` → `marriage_waited_twice`)이 같은 효과를 낸다. ② 결혼한 뒤에는 `youth-housing`이 닫혀 내 집은 `middle-home-loan`(40~55, 한 번)뿐이다(재력 4~5단계는 결혼 때 자동 자가). ③ 파트너를 얻는 문의 가중이 9~16으로 낮다(결혼 40, 출산 24와 비교).
- **확인 방법 (R)**: 위 표를 이벤트 데이터에서 자동으로 뽑는 점검(`setFlags`/`conditions.flags` 색인). **(S)** `--only=funnel`에 「경로 소멸」 계수를 낸다 — 결혼 나이 `a`별로 남은 자녀 경로(열려 있는 창)가 있는 판의 비율, 결혼 판 중 `youth-housing`이 닫힌 뒤 집 마련 경로가 `middle-home-loan` 하나뿐인 판의 비율.
- **판정**: 경로 소멸이 K÷M의 하락에 기여하는 비율을 `course`와의 차이에서 분리한다(`course`에서도 K÷M이 크게 낮으면 구조 문제다).

### H3. 노출 병목 — 선택 카드 슬롯 경쟁과 once·낮은 가중

- **근거**: 선택 카드는 청년 단계 연 확률 0.5, 선택 사이 최소 2년(`MIN_YEARS_BETWEEN_CHOICES = 2`)이라 연평균 `0.5 ÷ 1.5 ≈ 0.33`장, 20~39세 20년에 **약 6.7장**이다(`alpha-life.md` 2-3절 계산). 이 슬롯을 청년기 결정 이벤트 후보(30대 평균 후보 18.7개 중 결정 13.9, 기준선 1-3절)와 나눈다. 사슬 이벤트는 모두 `once`이며 파트너 문(가중 9~16)은 결혼(40)보다 한참 낮아 **「문 앞까지 못 오는」 판이 생긴다.** 추가로 `canChoice`는 평생 선택 카드 수 하드 상한(30)과 소프트 상한(24 이후 확률 ×0.3)에 막힌다.
- **확인 방법 (S)**: 사슬 이벤트별 `seen` 비율(「열린 판」)과 `seen` 뒤 선택 비율을 분리 출력한다. 가중 ×2 민감도를 한 번 돌려 노출률이 얼마나 오르는지 본다.
- **판정**: `course`에서도 M÷C·K÷M이 낮으면(예: `youth-meeting` 노출 < 50%) 노출 병목이다. 이 경우 레버는 L1·L3(5절).

### H4. 표본·정의 — 분모와 판정 규칙

- 기준선은 「전체 1000판」과 「65세 이상 산 판」을 같은 열 머리에서 섞어 적었다(3-3절). 일찍 죽은 판(영유아~청년 사망)은 사슬을 밟을 수 없다. 사망 시점 분포는 `deathChance`가 정한다.
- 판정이 **누적**(생애 어느 때든)이고 **정석 4단 순서 무관** 정의가 `own_home` 또는 `dwelling = own`의 「처음 own인 나이」를 쓴다. 공식 통계와 견주려는 지표(시점 값)가 아니다.
- **확인 방법 (R)** `courseOf`를 읽어 분모·판정을 확인(이번 문서에서 읽음). **(S)** 분모 세 가지(전체·45세 이상·65세 이상)로 같은 표를 낸다.
- **판정**: 분모에 따른 차이가 1%p 안이면 이 가설은 작다.

### H5. 「자가」의 이중 진실 — 플래그 `own_home`과 주거 `own`

- 결혼으로 `family → own`이 되는 재력 4~5단계 판은 `own_home` 플래그가 켜지지 않는다(`dwellingAfterFlags`는 주거만 바꾼다). 그래서 `own_home` 플래그를 조건으로 쓰는 이벤트(`middle-home-loan/shrink`의 `requires.flags: own_home`)는 이 판에게 열리지 않고, 플래그만 보는 지표는 이 판을 「집 없음」으로 센다. 기준선의 H는 둘을 합쳐 셌다(`courseOf`).
- **확인 방법 (S)**: `dwelling = own`이고 `own_home` 없는 판의 비율, 그 판이 `middle-home-loan`을 만난 비율.
- **판정**: 비율이 크면 L2의 (a)(플래그 동기화)를 먼저 한다. 4단 비율에는 영향이 없다(기준선이 합쳐 셌다).

### H6. 혼인·출산 나이 창이 세대와 무관한 고정값

- 이벤트의 `ageRange`는 시대 구분 없이 같다(`youth-marriage` 27~45, `youth-meeting` 24~36). 저장소의 평균 초혼 연령은 2005년 남 30.87 · 여 27.72에서 2025년 남 33.85 · 여 31.62로 올랐지만 **그 이전(1970~2004)은 미확인**이다(DC21). 이전 코호트(산업화·베이비붐·86)가 실제로 더 일찍 결혼했다면 하한 24~27세는 그들에게 늦은 값일 수 있다.
- **확인 방법**: DC21 확보 뒤 세대별 평균 초혼 연령과 이벤트 창의 겹침을 표로 낸다(**R**).
- **판정**: 세대별 초혼 연령 분포의 상당 부분이 창 밖이면 `window` 유형 연도 규칙(economy-model 16-4 ym-13)을 쓴다.

### H7. 외모 가중이 파트너 사슬에 걸려 있다

- `youth-meeting`·`youth-marriage`·`youth-reunion`·`youth-meeting-again`에 외모 70 이상 가중 ×1.5~2.5, 외모 30 이하 ×0.4~0.6의 `modifiers`가 걸려 있다(`youth.json`). 외모 분포가 넓으면 파트너 문을 못 보는 판이 만들어진다. 외모는 SPEC-008에서 상태 카드로 옮겨지고 살아가며 바뀌므로 그때 이 가중이 재설계된다.
- **확인 방법 (S)**: 외모 구간별 `has_partner` 비율. **판정**: 구간 간 차이가 크면 SPEC-008 외모 설계와 함께 다룬다(이번 보정 범위 밖).

## 4. 보정 원칙

1. **P1 통계가 확인된 범위에서만 목표를 둔다.** 목표 = 공식 값(근거 id) 하나. 통계가 없는 칸은 목표 없이 보고만 한다. 허용 폭은 판정에만 쓴다(M8). 지어낸 목표 0.
2. **P2 정의를 먼저 맞춘다.** 지표가 비교 가능한지(M1~M7)부터 확인하고, 게임을 고치기 전에 측정을 고친다(누적/시점, 분모, 대리 세대). 레버를 건드리는 것은 그다음이다.
3. **P3 구조 상한 원칙.** 선택자가 전부 「예」를 골랐을 때(`course`) 도달 가능한 비율이 공식 통계 이상이면 구조는 충분하다. 선택 성향(사람이 결혼을 얼마나 고르는가)은 목표로 두지 않는다 — 사람의 선택은 게임의 자유이고 모든 선택에 대가가 있다(E11).
4. **P4 수저별 격차(게임 주제)를 보존한다.** 보정 전후로 5단계 대 1단계의 40대 순자산 중앙값 비(G3 가드 ≥ 4배)와 단계별 혼인·출산·자가·진학의 격차를 지키고, 소득계층별 공식 격차가 확인된 지표(자가점유율 저 46.7 · 중 63.6 · 고 74.8, 사교육 참여율의 소득별 차이)는 격차의 **방향**을 검증한다. 게임의 수저(부모 재력)와 통계의 소득계층(현재 가구 소득)은 같지 않으므로 크기 비교는 참고만 한다.
5. **P5 세대 차이를 지우지 않는다.** 혼인 시기가 늦어지고 출산율이 낮아지는 변화(저장소: 평균 초혼 연령 2005~2025, 합계출산율 1970~2025)는 세대 차이의 일부다. 모든 세대에 같은 평균으로 맞추지 않고 **출생 연도별 코호트 값**을 쓴다.
6. **P6 정석을 정답으로 만들지 않는다.** 결혼·출산·내 집은 선택지의 하나이며 대가가 있다. 자동 결혼·강제 이벤트·재무 조언처럼 읽히는 문구를 만들지 않는다(G1·AL B4와 같은 방향). 보정의 목표는 「그 길이 현실만큼 열려 있다」지 「그 길이 보상받는다」가 아니다.
7. **P7 한 번에 하나, 순서를 지킨다.** ① 정의 정정 ② 계측 ③ 최소 레버 ④ 재측정. 각 레버는 경제 가드·시간·분포 회귀를 통과해야 채택한다(5절).
8. **P8 범위.** 공식 목표는 이미 관측된 세대에만 둔다. Z는 관측된 나이(M3)까지, 알파는 목표 없음(전망, PJ8). 산업화·베이비붐·86은 확보된 통계 범위에서만 목표를 둔다(1940~60년대 통계 부족, N1).
9. **P9 기준선 보존.** 보정 전 `check:economy`·`report:time`·이 문서의 1절 표를 스냅숏으로 얼리고 레버마다 차이를 기록한다.
10. **P10 게이트.** 레버 채택은 마스터 승인. 콘텐츠를 바꾸는 레버(L2(d), L5)는 reviewer 판독을 거친다.

## 5. 레버와 위험도

위험도는 「경제 가드 / 시간 / 분포」 세 축(요청 기준)을 낮음·중간·높음으로 적고, 그 밖의 위험은 따로 적었다. **경제 가드**는 `economy-model.md`의 알려진 한계 근처 항목을 가리킨다 — 9-10절: `past:end-negative` 29.5%(한계 30%, 0.85 SE), 지금 세상 60세 이상 부채 보유 59.8%(허용 ≤ 60.1%, 0.5 SE), `present:end-g3` 동률.

| 레버 | 내용 | 경제 가드 | 시간 | 분포(수저 격차) | 그 밖의 위험·선행 조건 |
|---|---|---|---|---|---|
| **L0 측정 정정** | `course` 선택자 추가, 분모·누적/시점 정리, `--only=funnel` | 없음 | 없음 | 없음 | 게임 코드 변경 없음. **가장 먼저** |

2. **구조 상한은 대부분 충분하다**(course, 65세 이상 산 판): 취업 92 / 97%, 결혼 96 / 94%(M÷C 95 / 94%), 내 집 78 / 84%. **모자란 곳은 자녀**: 결혼한 판의 자녀 도달(K÷M) 77 / 75%인데 공식 기혼여성은 93~98%(무자녀 1.9~4.9%, DC22)다.
3. **자녀 부족의 큰 몫은 「첫 결혼이 늦다」(H6)** 이다. course의 결혼 나이 중앙값 33세 · 평균 33.2 / 33.7세인데 공식 평균 초혼 연령은 1990 남 27.8 · 여 24.8 → 2025 남 33.9 · 여 31.6세다. 게임 course의 초혼 나이대별 자녀 도달률을 공식 초혼 연령 분포(아내)에 입히면 85~97%(계산값, 11-3절)로 공식 93~98%에 닿는다 — **자녀 사건 자체의 문이 아니라 결혼 시기가 병목**이다.
4. **H2(구조)도 숫자로 확인**: 39세 이후 결혼한 판의 자녀 도달은 **모든 선택자에서 0.0%**(칸마다 31~98판)이고 공식은 40세 이상 초혼 여성의 **18.8%** 가 자녀를 둔다. 반면 이중 진실(H5, 결혼 때 자동 자가인데 `own_home` 꺼짐)은 전체 판의 0.4~3.2%로 작고 정석 4단에 영향이 없다. 노출 병목(H3)은 작고(course에서 파트너 문 도달 96~98%), 분모(H4)는 0.4%p 안이다.
5. **비교표(11절)**: 구조 상한이 공식에 못 미치는 곳은 **자녀(R03) · 초혼 시기(R02) · 대학 진학(R05)**. 게임이 공식보다 높은 곳은 **취업(R06) · 자영(R11)**(정의·모델 차이), 상한은 충분한데 성향(random·auto)이 낮은 곳은 **미혼율(R01) · 자가(R04)**(선택자 효과 — 목표 없음).
6. **차이 큰 지표 상위 5와 레버 후보(12절)**: R03 자녀(L4 → L1 → L2(c)) · R05 대학 진학(L1, ym-12 보류와 함께) · R06 취업(레버 해당 없음 — 정의 정정 먼저) · R11 자영(정의 정정 먼저, L1) · R02 초혼 시기(L4·L1, R03과 같은 레버).

## 11. 통계와 같은 정의로 맞춘 비교표 R01~R13 (2-2절의 틀을 채움)

### 11-1 비교 규칙을 어떻게 지켰나

- **M1·M6 단위·정의**: 게임의 한 판 = 가구주로 읽는다(자가·취업·자영은 가구주·개인 통계와 견줌). 「결혼」은 `married` 플래그(「함께 살기로 한다」 선택), 「자가」는 주거 `own`.
- **M2·M4 누적/시점·생존자**: 미혼 = 1 − ever_married, 자가 = at_own, 취업 = at_employed를 **5세 연령대 안 다섯 나이의 평균**으로 냈다. 분모는 그 나이까지 산 판.
- **M3 코호트 읽기**: 통계는 출생 코호트 = 조사 연도 − 나이대로 읽는다(예: 2020년 50~54세 = 1966~70년생). 관측 안 되는 구간은 비교하지 않았다. **지난 = 1950~1989년생 혼합**이라 통계 쪽도 같은 범위의 코호트를 나란히 놓았고, 지금 = 밀레니얼 대리는 1981~1996년생 코호트(2025년 현재 30대 중반~40대 초반)를 쓴다. 2026년생(실제 지금 세상)은 관측되지 않는다.
- **M5 성별**: 성별 합계와 견주고, 남·여를 따로 읽을 때는 11-3에 적었다(공식: 미혼 비율은 남이 여보다 크다, 초혼은 남이 늦다).
- **M7 대리 세대**: 위와 같다. GM10에서 세대 7종 × 1000판으로 R01~R12를 다시 잰다(R13).
- **M8 허용 폭**: 확률형은 ±5%p(판 1000개의 2 표준오차 3.2%p보다 큰 쪽). **초혼 연령(R02)은 중앙값형이지만 ±30%(약 ±9세)는 의미가 없어 판정에 쓰지 않았다** — 허용 폭은 13절에서 마스터가 정한다. 표의 ▼ ▲ = 공식 범위보다 5%p 넘게 낮음·높음, = 범위 ±5%p 안.

1. **초혼 연령의 허용 폭**(M8): ±30%는 의미가 없어 이번에 판정을 하지 않았다. 추천: **평균 ±2세**를 판정에만 쓴다(목표 아님). R02가 일치로 바뀌는 조건은 L4 뒤 재측정이다.
2. **R06(취업)·R11(자영)을 보고 지표로 강등**할지: 게임에 비취업 상태가 없어 공식 고용률과 같은 정의로 견줄 수 없다. 추천: 보고 지표로 두고 「목표 없음」, 정의 정정(「일하는 상태」·「사업 지속」)은 GM9 `jobs` 슬롯(AL4)과 같이.
3. **레버 착수 여부와 순서**: 승인은 L0까지다. 구조 상한이 모자란 R03·R02(결혼 시기)·R05만 후보다. 추천: **L4(세대별 나이 창, 설계 문서 A의 `yearRange`와 조율) → L1 → L2(c)**, R05는 ym-12와 묶음. L3·L6은 이번에 제외.
