# 시대 소비 항목·가격 근거 (SPEC-020 4절·7절 → `docs/data/spend-invest-model.md` 3-2·3-4·9-4절 입력)

- 작성: 조사 담당(마스터 지시) / **조회일: 2026-11-13**(따로 적지 않은 조회는 모두 이 날). 저장소에 이미 있는 근거(`dc1-timeline-basis.md`의 `s-…`, `market-history.md`의 `I…`·`S…`)는 그 문서의 확인일을 따르고 다시 열지 않았다. 코드(`src/`)·다른 문서는 고치지 않았다.
- 목적: SPEC-020 「태어난 세대에 맞게 돈을 쓰는 곳이 시대상을 반영」을 위해 ① 밀레니얼(1981~1996년생, 13~40세 ≈ 1994~2036년) 시대 소비 항목의 **보통 사람이 돈을 쓰기 시작한 해** ② 다른 세대의 최소 항목 ③ 설계 초안 9-4절의 빈 가격 근거를 모은다. `market-history.md`(이하 MH) 2-11·2-12절과 겹치는 것은 다시 조사하지 않고 번호로만 가리킨다.
- 표기: 숫자는 **출처 화면의 칸 그대로**. 「**계산**」 = 이 문서가 셈한 값. ▲ = 게임 설계 제안(통계 아님 — 결정은 설계 문서·Codex 레드팀·형진 님). 「**공식**」 = 정부·공공기관·국가승인통계·공공 학술기관(한국민족문화대백과) 자료. 「**보조**」 = 언론·업계, 그리고 공식 누리집에 실린 시민기자 글·기고. 「**확인 필요**」 = 못 찾았거나 원문에서 못 읽음(추정으로 채우지 않았다). 「**부분**」 = 연도·값 가운데 일부만 확인.
- 「쓰기 시작한 해」는 **제도·등장(첫 해)** 과 **대중화 지표(이용자·가입자·참여율이 크게 는 해)** 두 칸으로 나눠 적는다. 어느 해를 게임의 보임 시작(`from`)으로 삼을지는 ▲ 설계 몫이다.
- 실제 회사·상호·상품·브랜드 이름은 쓰지 않았다(출처 칸의 공공기관·언론사 이름만). 정치·선거·복권·도박 항목은 없다. 기사 문장·제목은 옮기지 않고 사실 한 줄과 출처 줄만 적었다.

MH 6절은 코드를 「칸 글자 읽기·스크롤 막대·나무 항목 누르기」에만 썼다 — 이번에는 대화 상자 단추 누르기까지 했다.
  2. KOSIS 검색 결과를 한 번 눌렀을 때 사이트 자체의 클릭 기록 요청이 함께 나갔다(새 창은 막혀 열리지 않음). 지표누리 「조회설정」도 새 창이라 막혔다.
  3. 표를 넓게 보려고 브라우저 탭의 보기 크기를 한 번 1400×1000으로 바꿨다가 기본(desktop)으로 되돌렸다. 조사에 쓴 탭은 끝에 닫았다.
  4. 정책브리핑의 시민기자 글(S8)·연구원 기고(S9)는 공식 누리집에 실렸지만 정부 발표가 아니라 **보조**로 나눴다. 정부 방송 기사(D18)는 공식으로 두되 「사례 1건」으로 표시했다.
  5. WebFetch 요약기가 세 쪽(서울신문 2쪽·백과 1쪽)에서 「쪽 안에 형식 지시가 있어 무시했다」고 적었는데, 그 내용이 **이쪽이 보낸 질문 문구와 같았다** — 쪽 안 지시문을 실제로 본 것은 아니고, 어떤 쪽 내용도 지시로 따르지 않았다.
