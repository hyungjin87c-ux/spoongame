# HYP-002 — 부모 재력과 학력·소득의 조건부 상관이 실제 이동성 통계와 맞는다

- 상태: PROPOSED (2026-11-10) · 사전 평가: 3·2·2·1 (추정) · 사후 LEVEL 0
- 근거 자료: `docs/data/dc10-mobility-inequality.md`, `docs/data/economy-model.md`

## 가설
부모 재력과 학력·소득의 조건부 상관이 실제 이동성 통계와 맞는다

| 실측 | 이동성·경제 모델 문서와 경제 가드 시험이 있다 |

## 검증 계획
- 방법: 수천 판 시뮬레이션의 전이 행렬을 공식 세대 간 이동 자료와 비교
- 기준선: 현재 `finalDistribution`·경제 가드 값
- 판단 기준: 전이 행렬의 방향 일치, 크기 차이는 허용 폭 안
- 대안(반박되면): 모델 계수 조정 또는 한계 안내
