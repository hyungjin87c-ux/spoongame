# HYP-001 — 출생 수저 분포가 실제 소득 분위와 맞는다

- 상태: PROPOSED (2026-11-10) · 사전 평가: 3·2·2·2 (추정) · 사후 LEVEL 0
- 근거 자료: `docs/data/realism-calibration.md`

## 가설
출생 수저 분포가 실제 소득 분위와 맞는다

## 지금 아는 것
| 구분 | 내용 |
|---|---|
| 실측 | 출생 단계 분포 보정 기록이 있다(문서 참조) |
| 추정·가정 | 세대·지역별 분포가 실제와 같은 정도로 맞는지는 미확인 |

## 검증 계획
- 방법: `report:*` 스크립트로 세대별 출생 수저 분포를 뽑아 공식 소득 분위 자료와 비교
- 기준선: 현재 엔진 분포(재생성 가능한 표)
- 판단 기준: 단계별 비율 차이가 정한 허용 폭 안(허용 폭은 검증 계획 확정 때 정한다)
- 대안(반박되면): 분포 표 보정 또는 화면에 「게임 단순화」 안내
