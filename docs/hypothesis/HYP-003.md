# HYP-003 — 개인의 선택과 구조적 제약이 균형 있게 느껴진다

- 상태: PROPOSED (2026-11-10) · 사전 평가: 3·1·1·2 (추정) · 사후 LEVEL 0
- 근거 자료: 엔딩 분포, 결정 카드 영향, 플레이테스트

## 가설
개인의 선택과 구조적 제약이 균형 있게 느껴진다

## 지금 아는 것
| 구분 | 내용 |
|---|---|
| 실측 | 선택이 결과에 주는 영향을 재는 시험·보고 스크립트가 있다(선택 전략별 비교) |
| 추정·가정 | 플레이어가 「노력해도 소용없다」나 「노력하면 다 된다」 한쪽으로 읽는지는 미확인 |

## 검증 계획
- 방법: 같은 출생 조건에서 선택 전략별 결과 차이 측정 + 플레이테스트 문항(선택이 의미 있었는가)
- 기준선: 현재 전략별 결과 차이 보고값
- 판단 기준: 구조 효과와 선택 효과가 모두 0이 아니고 한쪽이 압도하지 않음(기준값은 계획 확정 때)
- 대안(반박되면): 결정 카드 효과·문구 조정
