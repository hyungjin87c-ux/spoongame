reviewer의 디자인 검수 항목 7개 — **정체성 전달 / 심볼의 뜻 / 가독성·위계 / 일관성 / 표현(조롱·비하·정치색 오해 없음) / 접근성 / 저작권** — 로 확정 심볼과 모든 화면을 1~5점으로 매겼다. 지난 회차들에서 자가 검수의 「해소」 판정이 실제와 다른 일이 있었다(D-07, R-121, 그리고 4차 문서의 R-190 관련 서술 — 아래 0절에 바로잡았다). 그래서 **① 주장마다 근거 이미지 경로를 적고, ② 작은 아이콘은 DPR 1 실제 픽셀 크기 시트와 4배 확대본을 직접 보고 적었으며, ③ 「기존 기호로 읽힐 수 있는가」를 가장 엄한 눈으로 먼저 적었다.** 이미지에서 확인되지 않는 것은 주장하지 않는다. 문턱(DS7)은 모든 항목 ≥ 4.

### 0-1. DPR 1 시트에서 크기별로 본 것 (`spoon-sizes-dpr1.png`, 왼쪽 원본 기준 — 5차 재촬영)
- **16px**: 머리 지름 약 5px, 자루 1px. 밝은·다크 = 다섯 재질색의 작은 숟가락, 머리 안은 민무늬. **강제 색상·단색 = 검게 채운 같은 모양**(4차의 외곽선 고리는 없다). 숟가락·핀 사이의 인상은 남지만 칩에서는 늘 이름·점과 함께 있다.
- **20·24px**: 숟가락으로 또렷. 네 테마 모두 채움. 「칩 24px 실제 조합」 줄의 아이콘과 같다.
- **32px(큰 변형)**: 흙 = 테두리 원 안 아래쪽 채움(◒ 인상 가능, 금지 목록 밖·2회차 해소 판정 유지), 동 = 민무늬 채움, 은 = 왼쪽 위 **흰 빛 조각**, 금 = 왼쪽 위 **흰 점**, 다이아 = 가운데 마름모 구멍. 「큰 칩 32px(출생신고)」 줄은 칩 변형(실루엣)이라 표식이 없다 — 규칙대로.
- **48px**: 다섯 표식이 재질(담긴 흙·무광·광택·반짝임·커팅)로 읽힌다. 다크·단색에서도 은·금의 흰 표식이 몸체보다 밝다.

## 3. 남은 약점 (4점이지만 적어 두는 것, 또는 구현 단계 확인 사항)
- (6차에 해소 — 4절) 상태 4색의 이웃 쌍이 가까웠던 문제(5차: 지식↔관계 13.1, 다크 행복↔관계 13.4, 적록 이상 추정치만): 지식↔관계·행복↔관계를 **명도**로 갈랐고(ΔL\* 라이트 18.4·18.2, 다크 14.2·15.6) Machado 2009 protan·deutan 시뮬레이션의 최소 ΔE2000이 라이트 10.6·다크 10.8(5차 색은 2.5~5.0). 시트 `status-colors-cvd.png`. **남는 약점**: 라이트 지식 파랑 #2778ff가 네 색 중 가장 선명하다 — 은·다이아(L\* 50 언저리)와 링크·포커스(L\* 36~41)가 파랑 자리를 차지해 모든 거리 기준을 넘는 자리가 L\* 52~53의 고채도 하늘빛뿐이었다. 12px 바 한 줄이고 이름·아이콘·숫자가 함께 있어 수용했지만 담담한 톤에서는 가장 튀는 색이다.
- 지식 파랑과 `--c-link`·`--c-focus`는 여전히 같은 파랑 계열이다(ΔE2000 라이트 16.9·11.3, 다크 18.7·16.0 — 테스트 기준 ≥ 10, 5차의 1.4에서 벌어짐). 자리와 모양이 다르지만 링크 글자를 상태 카드 안에 두지 않는다(`design-system.md` §1·§10).
- (6차에 처리) 흰 글자 고대비에서 은·금 표식이 몸체와 합쳐지던 것: 강제 색상에서 `--sp-mark: Canvas`로 두어 두 극성 모두 표식이 남는다(`title-a-mobile-forced-band.png`·`-forced-dark-band.png`). 실기기(Windows 고대비)는 여전히 Playwright 에뮬레이션으로만 확인했다.
- 강제 색상·단색 16px 칩 아이콘은 「검은 핀」 인상이 조금 남는다(채움이라 열쇠·돋보기는 아니다). 칩에는 이름·점이 늘 함께 있고, 단독 사용은 문서로 금지했다.
- 큰 변형 32px의 흙수저(테두리 원 + 아래 채움)는 단독으로 ◒처럼 보일 수 있다(2회차 해소 판정 유지, 띠에서는 이름과 함께).
- 엔딩 연표의 사건 줄(합쇼체 예시)과 요약·사망 줄(현행 함수 출력)은 M7e 전까지 어체가 다르다 — 시안 주석으로 표시했고 합쇼체 전환 뒤 화면이 함수 출력을 따르면 저절로 통일된다.
- 구간 글자가 가장 긴 「동수저(하위 40%와 상위 28% 사이)」의 320px 시안은 없다(마스터 결정: M3/M4 e2e). 데스크톱 또래 목록 「· 남」 줄바꿈은 M3 확인 사항.
- 단순화 심볼의 돋보기 인상(헤더), 출생신고 비교표의 360px 밀도, 데스크톱 캐러셀 큰 숫자의 위계는 3차와 같다(보류·구현 때 조정). 「전남광주」 약칭은 developer 확인 사항, 글꼴은 시스템 글꼴(C15).
