# 결정 줄 질문 문장 — 첫 묶음 infant 15 (SPEC-014 QS3, 2026-11-08 designer, **형진 님 승인 2026-11-08 — 추천 문장 그대로**)

인생 기록 결정 줄의 윗줄(지금은 사건 제목, SPEC-012 QF4)을 「…할까?」 꼴 질문 문장으로 바꾼다(SPEC-014 Q3 (가): 해체 속말 의문형, 생애 단계 5묶음 전수 승인). **이 첫 묶음에서 말투를 정한다** — 아래 1절 표가 결정안이고, 형진 님이 승인하면 school(17) → youth(22) → middle(22) → senior(18)도 같은 말투로 쓴다. 대상은 `src/data/events/infant.json`의 선택지 사건 **15개**(서술 사건 21개는 결정 줄이 없어 질문이 없다). 문장 규칙은 SPEC-014 「질문 문장 규칙」 1~10.

- 파일 자리: 승인 뒤 developer가 `question` 필드로 JSON에 넣는다(이벤트 데이터 값만, 확률·조건·선택지·효과 불변 — QS3). 승인 기록은 이 문서(SPEC-014 G3의 `log-question-sentences.md` 자리를 이 파일로 쓴다 — 묶음마다 절을 더한다).
- `src/`·`tests/`는 읽기만 했다. 커밋하지 않았다.
