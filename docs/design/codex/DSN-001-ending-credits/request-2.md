## 1. 1회차에서 정해진 것 (형진 님 결정 — 그대로 따른다)
1. 크레딧은 회고 화면에서 버튼으로 연다(사망 기록 문서 아래).
2. SPEC-017 첫 장면의 마무리 한 줄은 「생애 기록을 펼칩니다」 방향의 전환 문장으로 줄인다.
3. 「생각 남기기」 글은 첫 버전에서 넣지 않는다.
4. 소리는 무음.
5. 명단은 가족 카드가 확인하는 이름만.
6. **선택은 생애 단계(학창·청년·중년·노년)마다 본인이 고른 큰 결정 한 건씩, 최대 4건**(1회차의 「가족이 정한 일 1 + 본인 1」을 바꾼다 — 고르는 규칙을 데이터로 정해 제안하라).
7. **시대 줄은 청년기 이후에서 단계마다 한 줄, 최대 3줄, 무거운 줄 최대 1줄**(1회차의 「첫 줄 + 가운데 줄」을 바꾼다).
→ 6·7은 1회차 `plan.md` 4절 표와 12절 샘플 전문에 반영해 `plan-2.md`에 고친 표와 새 샘플로 보여 달라.

## 2. 이번 장면 — 수저 변화
- **무엇을**: 크레딧의 끝부분(「○○의 생애 기록을 마쳤습니다」 앞 또는 같은 장)에서 **태어날 때 수저가 마칠 때 수저로 천천히 바뀌는 그림**과 한 줄을 보인다. 막대·눈금·백분위 그래프는 쓰지 않는다(삭제된 「출발선 대비」의 반복이 되지 않게).
- **마칠 때 수저를 정하는 법**(마스터가 정함 — 그대로 쓴다): 사망 나이의 **실제 가구 순자산 분포**(가계금융복지조사 2025, `networth-distribution.md` 4절 안 B — 가구주 연령대별)에서 이 사람의 최종 순자산이 아래에서 몇 % 자리인지 추산하고, **태어날 때와 같은 경계**(그 세대의 출생 수저 비율 누적 — `startBandOf`가 쓰는 값)로 수저 이름을 붙인다. 예: 밀레니얼은 하위 26% 안쪽 = 흙수저, 26~56% = 동수저, 56~83% = 은수저, 83~97% = 금수저, 상위 3% = 다이아몬드수저.
- **문장**: 사실만, 평가 없이. 예시(문구는 제안해 달라): 「흙수저로 태어나 은수저로 마쳤습니다」 / 「금수저로 태어나 금수저로 마쳤습니다」 / 「은수저로 태어나 흙수저로 마쳤습니다」. 「성공」「역전」「몰락」 같은 평가어·감탄 없음. 그 아래 작은 근거 줄(예: 「같은 나이 가구의 순자산 기준 추산」) — 몇 % 자리를 숫자로 보일지(예: 「아래에서 약 60%」)는 너의 제안과 이유를 적고 형진 님께 묻는 것으로 남겨라.
- **20세 전에 끝난 삶**: 자기 자산이 없다 → 태어날 때 수저만 조용히(바뀌는 연출 없음). 문장 제안.
- **순자산이 0 이하**: 흙수저로 정해진다. 빚을 강조하거나 금액을 보이지 않는다.
- **그림**: 기존 수저 실루엣 다섯 단계(`sp-1`~`sp-5`)를 쓴다 — 새 일러스트·래스터를 만들지 않는다. 「천천히 바뀜」의 방식(겹쳐 바뀜·재질이 스며듦·한 칸씩 지나감 등)을 2~3안으로 그려 보고 추천안을 고른다. 색만으로 단계를 전하지 않는다(이름·점 다섯과 함께 — 수저 칩 규칙).
- **움직임 줄이기**: 바뀌는 연출 없이 「태어날 때 ○ · 마칠 때 ○」 두 수저를 나란히 정지해서 보인다. 스크린리더는 문장 한 번(그림은 장식).
- **길이**: 장면 길이 제안(예: 3~5초) — 1회차 길이 규칙(D 식)에 어떻게 더해지는지.
- **경제 쏠림에 대한 주의**: 지금 게임 경제에서는 20세 넘어 마친 판의 약 40%가 순자산 0 이하로 끝나 흙수저 끝이 많다(측정 기록). **노년 경제 보정이 먼저 이뤄진 뒤 이 장면을 배포한다**(형진 님 결정). 디자인은 어떤 분포에서도 성립해야 하고, 흙수저 끝이 많다는 이유로 장면을 바꾸지 않는다.
