## 1. 두 그림체

같은 조각 기하(자리·비례·구도)를 두 **그리기 방식**으로 낸 것이라, 어느 쪽을 골라도 조각 수·자리 규칙은 같다. 생성기의 `mk(style)` 도우미 하나가 갈린다.

| | 그림체 1 **종이 오림**(`s1`) | 그림체 2 **굵은 선 그림책**(`s2`) |
|---|---|---|
| 한 줄 | 선이 없고 평평한 종이 조각을 겹친다. 큰 조각(집·몸통·머리·독)은 (3,3) 밀린 반투명 그림자 조각 하나로 두께를 낸다 — 판화·종이 오림의 문법 | 둥근 먹선 한 굵기(3단위 ≈ PC 2.4px·360에서 1.5px)와 옅은 채움. 창틀·기와·전선·사람이 모두 같은 선 |
| 얼굴 | **그리지 않는다.** 머리 모양(파마·단발·쪽·묶음)과 옷으로 사람을 읽는다 | 점 눈 둘 + 작은 미소(얼굴 시스템 `faceLayers`의 「담담한 미소」와 같은 표정, 선 색은 `--c-face-line`과 같은 값이라 다크에서도 살색 위에 보인다) |
| 시대 읽힘 | 실루엣으로 — 기와 물결, 전봇대, 포대기, 한복 치마폭, 연탄 | 선으로 — 기와 물결선, 창살, 자전거 살, 아파트 난간 |
| 다크 | 같은 그림을 어두운 종이에 놓은 것(토큰만 바뀜). 그림자 조각은 더 진하게. 창은 따뜻한 유리색을 유지한다(낮밤 표현이 아니라 창이 읽히게 한 것) | 먹선이 밝은 선으로 뒤집혀 「칠판에 그린 그림」처럼 보인다 — 라이트와 인상이 더 벌어진다 |
| 360(328px 폭) | 선이 없어 작은 크기에서 노이즈가 없다. 식구 6명·개가 모두 구분된다 | 1.5px 선이 겹치는 곳(난간·자전거·얼굴)이 촘촘해진다. 읽히지만 라이트 PC보다 피로하다 |
| 크기 | 조각 평균 gzip 335B(개별) · 덩어리 환산 176B | 378B · 194B(+10~13%) |
| 위험 | 표정이 없어 「따뜻함」을 그림이 아니라 문장이 맡는다(SPEC 원칙과 같다 — 그림에만 있는 정보는 없다) | 얼굴이 있으면 「닮음」·「희화화」 판독 대상이 생긴다(점 눈 + 미소 한 가지라 위험은 낮지만 0은 아니다) |

### 추천: **그림체 1 종이 오림**
1. 게임 정체성과 맞는다 — 종이색 바탕(`--c-bg` 한지색·`#f9f7f2`)에 종이를 오려 붙인 그림이 바탕과 한 재질로 읽힌다. 절제된 어조(감탄 없음·표정 없음)와도 맞는다.
2. 작은 화면과 다크에서 더 안정적이다(선이 없으므로 축소·반전에 잃는 것이 없다).
3. 낙인·닮음 판독에서 가장 안전하다(얼굴 0, 비례는 어린이·노인 모두 같은 둥근 머리·단순 몸통).
4. 바이트가 가장 작다(2절).
- 형진 님이 **표정이 있는 쪽**을 원하시면 그림체 2, 또는 **혼합**(종이 오림 + 점 눈·미소만)도 비용 없이 가능하다(같은 기하, 도우미 옵션 하나). 혼합은 요청이 있으면 한 장 더 그려 보인다.

## 2. 조각 구조와 파라미터 (FH2 · FH5 · FH8)

장면은 `SceneSpec` 모양의 자료(배경 id · 뒤 소품[] · 집 · 앞 소품[] · 반려동물[] · 식구[])를 **자리(슬롯)에 놓아** 합친다. 좌표계는 640×256(가로 2.5:1), 지면선 y=200, 식구 발바닥 y≈246~250. 시안 생성기의 `SCENES`·`place()`·`sceneSvg()`가 구현의 `sceneOf → renderScene`과 같은 모양이다.

## 3. 예산 실측 (FH8 · 완료 기준 11)

측정: `budget.json`(생성기가 쓴다). raw·gz는 조각 안쪽 마크업(`<g>` 내용) 바이트, 「덩어리」는 그림체의 조각 전부를 `{id: 마크업}` JSON으로 묶어 gzip한 값(실제 지연 덩어리에 가까운 추정 — 공통 문자열이 함께 눌려 개별 합의 약 절반).

| | 조각 수 | 조각별 gzip 평균(개별) | 덩어리 gzip | 조각당(덩어리) | 93조각 추정 | 110조각 추정 |
|---|---|---|---|---|---|---|
| 그림체 1 종이 오림 | 24 | **335B** | 4,227B | 176B | 16,380B | 19,374B |
| 그림체 2 굵은 선 그림책 | 24 | **378B** | 4,658B | 194B | 18,050B | 21,349B |

- 층별 가중 추정(가장 무거운 집 조각을 21개로 셈 — 집 659~666B, 식구 409~491B, 배경 358B, 소품 202~237B, 반려동물 355~371B, 틀 150B 가정): 개별 gzip 합 **s1 35.5KB / s2 38.5KB**, 덩어리 환산(×0.51~0.53) **s1 18.7KB / s2 19.8KB**.
- 판정: 두 그림체 모두 **조각 평균 ≤ 0.45KB**(가장 보수적인 개별 값으로도 0.34·0.38KB)와 **조각 덩어리 ≤ 45KB**(가중 개별 합 35.5~38.5KB, 덩어리 환산 19~20KB) 안이다. `family` 덩어리 합계 ≤ 75KB에는 표·이름 목록·소품 연도 표(≤ 30KB)를 더해도 여유가 있다. **마스터 확정 제안**: 조각 덩어리 예산 45KB → 그대로 두되 측정 기준을 「덩어리 gzip」으로 명시(개별 합이 아니라), 상한 110조각까지도 예산 안.
- 예산을 먹는 쪽은 집 조각이다(기와 물결·창살·난간의 반복). 구현 때 반복 도형은 `<pattern>`·`<use>`로 더 줄일 수 있다(아파트 먼 창은 이미 pattern).

## 4. 자리와 접근성 (FH1 · FH3 · FH4 · FH6)

- **자리**: 가운데 열 결정 카드 → **그림 카드** → (올해 마음 쓸 곳 자리, 주석으로 비워 둠) → 인생 기록. 측정(`shootFamily.mjs`): 1280×800 가운데 열 순서 `decision → scene-card → log`(결정 카드가 열려 있어도·접힌 띠여도 같다), 그림 534×200(= 25vh 상한, FH1 ▲), 1920×1080 534×214, 1280×620 534×155(25vh 155).
- **높이 규칙**: `aspect-ratio 640/256 · max-height 25vh · preserveAspectRatio slice` — 폭이 넉넉하면 위·아래를 조금 잘라(하늘·지면 8단위) 보이고, 좁으면 전체가 보인다. 360×740: 326×130(25vh 185 안), 320 글자 200%: 286×114.
- **휴대폰 순서(designer 결정)**: 결정 카드(order −1) 바로 아래 그림 카드(order −1, 문서 순서) → 프로필 → 상태 → 자산 → 인생 기록 → 식구 → 또래. 그림이 게임의 얼굴이라 맨 위 가까이 두되 결정 카드를 밀어내지 않는다. 접으면(`data-fold`) 그림만 사라지고 한 줄·펼침·「그림 펼치기」가 남는다(설정 저장은 구현).
- **한 줄과 펼침**(FH3): 「서울 성북구 · 단독주택 셋방 · 부모님·누나 둘·할머니와 함께」(14px 굵게, 360에서 2줄). `<details>` 「함께 사는 사람」 → 사람 줄(호칭 · 이름 · 나이 · 사이) + 반려동물 줄 + 「가족과 삶 열기」. 「그림 접기」는 줄 오른쪽 위에 고정(펼쳐도 자리 불변). 둘 다 키보드로 조작(접기 Enter 왕복 측정 통과).
- **대체 글**(FH6): `<svg role="img" aria-labelledby="scene-line scene-pets">` = 아래 한 줄 + 숨긴 반려동물 문장 — 측정값 「서울 성북구 · 단독주택 셋방 · 부모님·누나 둘·할머니와 함께 마당에서 기르는 개 한 마리가 있습니다.」 그림에만 있는 정보 0(소품은 분위기이고 「집에 있는 것」 줄이 글자로 맡는다). `aria-live` 없음(FH4 — 변화는 인생 기록 문장이 알린다).
- **다크**: 토큰만 바뀐다(`family.css` 두 블록). **강제 색상**: 그림은 `forced-color-adjust: none`(얼굴과 같은 규칙 — 정보가 아니라 그림), 틀 아래선 `CanvasText`, 펼침 점 `CanvasText`. 캡처 검사: 다크 1280·360, 강제 1280·360 넘침 0.
- **움직임 줄이기**: 바뀌는 해의 교차 페이드는 `.scene--swap .scene__svg { transition: opacity var(--dur-slow) }` — `--dur-slow`가 움직임 줄이기에서 0.01ms(tokens.css)라 즉시 교체된다. 그 밖의 움직임 없음(펼침 화살표 회전도 `--dur`를 따른다).
- 넘침: 1280·360·320 글자 200%·1920 전부 0, 외부 요청 0, 캡처 ≤ 106KB.

## 6. 형진 님께 물을 것
1. **그림체**: 1 종이 오림(추천) / 2 굵은 선 그림책 / 혼합(종이 오림 + 점 눈·미소).
2. 얼굴이 없는 사람(그림체 1)이 괜찮으신지 — 표정은 글이 맡습니다.
3. 다크 모드에서 창에 불빛(따뜻한 유리색)을 남기는 것 — 낮밤 표현이 아니라 창이 읽히게 둔 것인데, 빼기를 원하시면 토큰 하나로 뺍니다.
4. 휴대폰 순서: 결정 카드 바로 아래 그림(접기 가능) — 아니면 프로필 다음?
5. 1975년 어머니의 **포대기로 업힌 아기** 표현(시대 디테일) — 유지할지.
6. 그림 높이 상한 25vh(1280×800에서 200px) — 더 크게 원하시면 30vh(240px)안을 한 장 더 냅니다.

## 7. 마스터·developer에게
- 토큰 24개(`--c-scene-*`) 추가 승인 요청 — 값은 `family.css`, 라이트 = SVG 기본값. 기존 토큰 변경 0.
- 구현 때: 조각은 생성기의 `PIECES` 표를 데이터로 옮기고(`id · layer · box · draw`), 색은 토큰만, 반복 도형은 `<pattern>`/`<use>`. `person()` 한 함수로 연령대 × 성별 × 시대 옷을 만드는 방식을 권한다(조각 수를 16 + 6으로 묶는 FH8의 전제).
- 남은 시안(이 게이트 범위 밖, FH7 ▲ 장면 목록): 1950년대 농촌 3세대 + 마당 개, 2010년대 대도시 다세대 3인, 한계 장면 8명 + 2마리 — 고른 그림체로 FM3 착수 전에 그린다.
