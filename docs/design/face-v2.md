## 1. 진단 — 지금 외모 5단계가 그림에서 어떻게 다른가

`faceLayers.ts`의 단계 신호는 둘뿐이다: **머리 부피**(0.8→1.2배, 윤기 줄 0→6, 이마 2→0px)와 **선의 굵기·진하기**(1.6→3.2, 불투명도 0.62→1, 눈 하이라이트 0.3→0.95). 부품의 종류·크기·자리·피부·주름·표정은 모두 같다(R-126·R-135② 반영 3차의 결과, 의도적으로 은근하게).

96px(프로필·엔딩 자리)에서 본 결과(시안 1절 샷):

- 1 ↔ 5는 나란히 두면 갈린다. 1 ↔ 3, 3 ↔ 5는 나란히 두어도 겨우 갈리고, **한 장만 보면 단계를 읽을 수 없다.**
- 가장 큰 차이가 머리 부피라 지금은 외모가 「머리숱」으로 읽힌다. 「이목구비가 뚜렷하고 예쁜」·「수수한 인상의」가 글로는 분명한데 **이목구비 자체의 신호(눈썹 농도, 얼굴의 굴곡)가 없다.**
- 72px(DS4 하한)에서는 선 굵기 차이가 1px 안쪽이라 사실상 같은 얼굴이다.

결론: 플레이테스트 의견(「외모가 뚜렷하면 사진에 드러나야」)은 그림이 글보다 약해서 생긴 것이고, 머리 부피를 더 키우는 쪽이 아니라 **이목구비 신호를 더하는** 쪽이 맞다.

## 2. 뚜렷함 ↔ 수수함 — 표현 안 셋 (+ 결합안)

모든 안의 공통 규칙: 표정은 같은 담담한 미소 · 피부색 한 톤 · 얼굴형·귀·목·주름은 단계와 무관 · 쌍꺼풀·콧날 **선**은 어느 단계에도 없다 · 가장 흐린 선도 피부와 3:1 이상(불투명도 0.62).

### 2-1. A 안 「선의 대비」 — 현행 축 확장

| 파라미터(1→5단계) | 지금 | A 안 | 뜻 |
|---|---|---|---|
| `lineWidth` | 1.6 / 2.0 / 2.4 / 2.8 / 3.2 | **1.3 / 1.8 / 2.4 / 3.0 / 3.6** | 눈·코·입 선 굵기(3단계 기준 불변) |
| `lineAlpha` | 0.62 / 0.74 / 0.86 / 0.94 / 1 | 0.62 / 0.72 / 0.84 / 0.94 / 1 | 선 진하기(하한 0.62 그대로) |
| `browWidth` | 1.4 / 1.8 / 2.3 / 2.8 / 3.2 | **1.0 / 1.6 / 2.3 / 3.0 / 3.7** | 눈썹 굵기 |
| `browAlpha`(새) | = lineAlpha | **0.56 / 0.7 / 0.84 / 0.94 / 1** | 눈썹 농도(「짙고 또렷」↔「옅고 가늘」) |
| `browLen`(새) | 1 | **0.86 / 0.93 / 1 / 1.06 / 1.12** | 눈썹 길이 배율 |
| `eyeHighlightAlpha` | 0.3 / 0.45 / 0.6 / 0.78 / 0.95 | 0.18 / 0.38 / 0.6 / 0.8 / 1 | 눈빛(「눈빛이 또렷」) |

부품 수·종류·자리·크기 불변 → 기존 시험(눈 위치 불변·부품 목록 동일·단조) 그대로 통과한다. 혼자 쓰면 1 ↔ 3은 여전히 약하다.

### 2-2. B 안 「그림자 두 획」 — 굴곡

선은 지금 그대로. 4·5단계에만 **살색 그늘**(`--c-face-skin-shade`, 선이 아니라 면의 명암) 두 획: ① 콧날 왼쪽 옆 한 획(불투명도 4단계 0.45 · 5단계 0.7, 굵기 2.6) ② 관자놀이 아래에서 광대뼈 밑까지 짧은 한 획 양쪽(0.24 · 0.4, 굵기 4). 1~3단계는 0(평면). **첫 샷에서 광대 획을 턱선까지 내렸더니 남성 얼굴에서 수염 자국으로 읽혀** 광대뼈 밑(얼굴 높이 0.58)에서 끊었다.

- 수수함 = 「덜 그린 얼굴」이 아니라 「빛이 고른 얼굴」. 1단계가 못나 보이지 않는 까닭이 여기 있다.
- R-135②(「상위 단계에만 구조 부품 추가 금지」)와의 관계: 더해지는 것은 선·부품이 아니라 그늘이다. 그래도 「4·5단계에만 있는 노드」이므로 `features` 층이 아닌 **별도 `shade` 층**에 두어 「features 부품 목록 단계 무관」 시험은 그대로 두고, `shade` 층만 「4·5단계에만 있고 색은 skin-shade뿐」으로 따로 단언하는 것을 제안한다. 이 해석은 형진 님·마스터 판단(9절 ②).

### 2-3. C 안 「비례」 — 눈·눈썹 크기

눈 세로 크기(`eyeScale`) 0.88 / 0.94 / 1 / 1.06 / 1.12, 눈썹 길이 같은 비율. 차이가 가장 바로 보이지만 **「눈이 작다」가 단계의 표시**가 되어 조롱으로 기울 수 있고(시안 샷에서 1단계가 눈을 가늘게 뜬 얼굴로 읽힌다), 「눈 크기·위치 단계 무관」 시험과 어긋난다. **권하지 않는다.** 비교용으로만 두었다.

### 2-4. AB 안 (추천) = A + B

5단계: 선 굵고 진하고, 눈썹 짙고, 눈빛 밝고, 콧날·광대에 굴곡. 1단계: 선 가늘고 옅고, 눈썹 옅고 짧고, 평면. 두 신호가 같은 방향으로 움직여 96px 한 장으로도 양 끝이 읽히고, 72px(시안 2절 끝 두 줄)에서도 1 ↔ 5가 갈린다. 3단계는 지금과 거의 같은 얼굴(기준점 불변)이라 옛 저장의 가운데 얼굴이 낯설어지지 않는다.

## 3. 시대의 유행 층 — 같은 얼굴에 머리·화장·옷깃·안경

**고르는 열쇠 = 달력 10년대**(출생 연도 + 나이를 10년 단위로 내림) × 나이대(연령대 id) × 성별. 세대 id를 쓰지 않는 까닭: 밀레니얼(1981~96년생)의 청소년기는 1994~2015년, 베이비붐(1955~63년생)의 청년기는 1975~2002년처럼 한 세대 안에서도 10년대가 갈린다. 「몇 년에 몇 살이었나」가 유행을 정한다.

첫 시안 세 칸(시안 3절, 모두 AB 안):

| 10년대 · 나이대 | 남 | 여 | 안경 |
|---|---|---|---|
| **1960~70년대 청년기**(산업화·전후 세대) | 귀를 덮는 장발(`sideLen` 20, 물결 1.2), 가운데가 갈라진 앞머리(`curtain`), 긴 구레나룻(`sideburn` 10), 넓은 양복 깃 + 넓은 넥타이(`suit70`) | 가운데 가르마 긴 생머리(`part` 0, 58/60), 가는 아치 눈썹(굵기 0.55배, 제어점 −3.6)·아이라인·입술 전체 색(`makeup '70s'`), 둥근 블라우스 깃(`blouse70`) | 검은 뿔테 둥근 사각(`horn70`, 선 2.3) |
| **1990년대 후반~2000년대 청소년기**(밀레니얼) | 눈썹을 덮는 샤기컷(`shag` — 끝이 여섯 갈래), 교복 셔츠 깃 + 좁은 넥타이(`uniformM`) | 일자 앞머리(`straight`) + 어깨 생머리, 교복 둥근 깃 + 리본(`uniformF`) | 작은 금속테 타원(`metal00`, 회색 1.1) |
| **2000년대 후반~2010년대 청년기**(밀레니얼) | 옆을 바싹 친 댄디컷(`dandy`, `tight`, 윗머리 5.5), 좁은 셔츠 깃(`shirt10`) | 시스루 뱅(얇은 앞머리 + 굵은 가닥 셋, 사이로 이마가 비침) + 끝을 만 긴 웨이브(물결 3.2), 일자 눈썹(굵기 1.2배, 제어점 −0.7)·틴트 입술(가운데만)(`makeup '10s'`), 라운드 넥(`tee10`) | 큰 뿔테 둥근(`round10`, 선 2.0) |

- 「지금 표」(기본 `HAIR`)는 10년대 표에 없는 칸의 폴백이다. 아동 이하·중년 이상은 아직 기본 표 그대로(다음 회차 후보: 1980년대·1990년대 청년기, 2010년대 청소년기, 중년의 10년대 머리).
- **안경**은 소품 층이다. 모양은 10년대가, **쓸지는 판의 시드**가 정한다(외모 단계·수저·지식과 묶지 않는다 — 안경 = 공부·계층으로 읽히는 것을 막는다). 비율은 명세에서(제안 25%).
- 유행이 피부·체형에 닿지 않는 것을 코드로 보장: `FASHION` 칸의 키는 `hair`·`collar`·`makeup`·`glasses` 넷뿐이고 얼굴형·피부 토큰은 읽지 않는다. 시험 후보: 「`FASHION` 모든 칸의 키 집합 ⊆ {hair, collar, makeup, glasses}」, 「시대를 바꿔도 `head`·`ears`·`neck` 층 노드 동일」.
- 화장은 여성 칸에만 있다. 1970년대의 가는 눈썹·아이라인, 2010년대의 일자 눈썹·틴트는 그 시대 사진에서 가장 흔한 두 가지만 골랐다. **실존 인물을 닮게 그리지 않았고** 특정 연예인의 머리 이름을 쓰지 않았다.
- 새 토큰 제안 **하나**: `--c-face-shirt`(셔츠·블라우스·교복 깃의 밝은 천, 폴백 `#efe9dc`; 다크도 같은 값 — 얼굴 타일은 두 테마에서 같은 그림). 그 밖의 색은 모두 기존 `--c-face-*`(넥타이·리본은 `--c-face-line` 0.78~0.9).

## 4. 구조 제안 — 조합 폭발을 막는 층 함수

```
faceNodes({ ageGroup, gender, tier, decade, seed? })
  = background
  + hair.back(decade·ageGroup·gender, tier)        ③ 머리(부피는 tier)
  + neck(ageGroup) + clothes(decade·ageGroup·gender) ④ 옷깃
  + hair.mid
  + ears + head(ageGroup·gender)                    ① 얼굴형
  + shade(tier)                                     ② 그늘(B)
  + features(ageGroup·gender·tier, makeup(decade))  ② 선의 대비(A) + 시대 화장
  + wrinkles(ageGroup)
  + glasses(decade, seed)                           ⑤ 소품
  + hair.front
```

- 각 층은 **자기 키만 읽는 순수 함수**다(지금 `faceLayers.ts`와 같은 노드 목록 방식, React·Date·Math.random 없음). 조합은 연령대 8 × 성별 2 × 단계 5 × 10년대 7 × 안경 2 = 1,120이지만 **그려 두는 것은 0장**이고 코드는 표 줄과 함수의 합이다.
- 표 크기: `FASHION[decade][ageGroup][gender]` = 7 × (청소년·청년·중년·장년 4) × 2 = **56칸**, 칸마다 머리 숫자 11개 + id 셋. 지금 시안은 그중 3칸을 채웠다. 영유아·아동·노년은 10년대 표 없이 기본 표(유행 차이가 작고, 어린이 머리로 시대를 말하면 과하다).
- 머리 모양은 **새 경로가 아니라 기존 파라미터 + 필드 셋**(`fringeStyle` 5종, `sideburn`, `tight`)으로 만든다. 새 그리기 함수는 `fringeStyle` 분기 넷, `fringeStrands`, 옷깃 6종, 안경 3종, 그늘 1종 — 전부 합쳐 **raw +5.8 KB, gzip +170 B**(경로가 수식이라 압축이 잘 된다).
- `src`에 넣을 때의 모양(developer 인계안): `faceLayers.ts`는 그대로 두고 `faceFashion.ts`(FASHION 표 + 옷깃·안경·화장 함수)·`faceShade.ts`(B)·`TIER_PARAMS` 값 교체(A)로 나눈다. `Face.tsx`는 `decade = Math.floor((birthYear + age) / 10) * 10`을 더 넘긴다. `useMemo` 키에 `decade`가 들어가므로 한 판에서 다시 그리는 횟수는 연령대 경계 7번 + 10년 경계 ≤ 10번.

## 6. Codex 참고 그림이 필요한가

**지금은 아니다.** 선·면 파라미터만으로 (가) 다섯 단계의 양 끝, (나) 세 시대가 96px·72px에서 읽힌다(4절 샷). 필요해지는 때:

1. 10년대 표를 56칸까지 채울 때 **1980~90년대 머리**(남 2:8 가르마·여 큰 웨이브 파마 등)를 선 몇 개로 어떻게 줄일지 — 시대 사진을 보고 「선 세 개로 요약」하는 참고 스케치가 있으면 빠르다. 그때도 **참고만** 하고 그림은 SVG 파라미터로 다시 그린다(실존 인물·브랜드 0).
2. 형진 님이 뚜렷함을 AB 안보다 **더 세게** 원할 때 — 선·그늘로는 한계가 있고 구조(쌍꺼풀·콧날)를 더하면 R-135②와 부딪히므로, 그 전에 「어디까지가 조롱이 아닌가」를 참고 그림 두세 장으로 먼저 합의해야 한다.

## 9. 판단이 필요한 것 (형진 님)

1. **표현 안**: AB(추천) / A만 / B만 / C. 또는 AB를 바탕으로 세기(그늘 0.4 → 0.3처럼) 조정.
2. **B의 그늘과 R-135②**: 「4·5단계에만 있는 살색 그늘」을 구조 추가로 보지 않고 명암으로 볼지(추천: 별도 `shade` 층 + 시험). 아니라고 보면 A만.
3. **시대 층 첫 범위**: 세 칸(1970s 청년·2000s 청소년·2010s 청년) 그대로 밀레니얼 먼저 가고 나머지 10년대는 다음 회차로(추천), 또는 7 × 4 × 2 전부를 한 번에.
4. **안경**: 시드로 약 25% 무작위(추천) / 쓰지 않음 / 다른 비율.
5. **새 토큰** `--c-face-shirt` 추가 허용(추천) / 기존 색으로만(깃이 옷과 같은 색이 되어 교복·양복이 안 읽힌다).
6. **지연 로드**: `Face`를 lazy로(추천 — 첫 화면 −11 KB) / 지금처럼 정적.

## 10. developer 인계 (명세 확정 뒤)

1. `TIER_PARAMS` 값 교체 + `browAlpha`·`browLen` 추가(A) — 단조 시험 성질은 그대로(비감소), `checkContrast`의 선 하한 0.62 쌍 그대로.
2. `shade` 층(B) — 4·5단계만, 색 `--c-face-skin-shade`, `tests/designAssets.test.ts`에 「features 부품 목록 단계 무관」은 그대로 두고 「shade 층은 4·5단계에만, 노드 색 skin-shade뿐」 추가.
3. `faceFashion.ts` — `FASHION[decade][ageGroup][gender]`(시안 `faceV2Lib.mjs`의 표·옷깃·안경·화장 함수를 TS로), 폴백은 기본 `HAIR`·기본 옷. 시험: 키 집합 ⊆ {hair, collar, makeup, glasses} · 시대를 바꿔도 `head`·`ears`·`neck` 노드 동일 · 모든 색 `--c-face-*` 토큰.

5. `tokens.css` — `--c-face-shirt` 라이트·다크·강제 색상(얼굴은 `forced-color-adjust: none`이라 매핑 불필요) 추가, `checkContrast` 쌍 없음(얼굴 안 장식).
