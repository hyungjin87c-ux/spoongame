### 4-1. 배속 한 단추의 동작·이름

- **누를 때마다 1 → 2 → 4 → 8 → 1배**(`SPEEDS` 순환). 보이는 글자 「1배」「2배」「4배」「8배」(tabular). 아이콘 없음 — 「다음 결정으로」의 ▶▶(`i-next`)와 겹치는 그림을 피한다.
- 접근 가능한 이름 `aria-label="배속 1배, 누르면 2배"` — 보이는 글자 「1배」가 이름에 들어 있다(WCAG 2.5.3 Label in Name). 누른 뒤 바뀐 값은 `role="status"` 한 줄 「배속 2배」가 읽는다(자동 모드 전환 문장 `autoOnStatus`와 같은 자리를 써도 된다). `aria-pressed`는 쓰지 않는다(켜짐·꺼짐이 아니라 값이다).
- 입력 가드·연타 방어는 `GuardedButton` 그대로. 자동 모드 중에도 누를 수 있다(지금 배속 넷과 같다).
- 키보드: Tab 정지점이 7 → **4**(일시정지 · 배속 · 다음 결정으로 · 자동 모드). 「다음 결정으로」의 `aria-disabled`(Tab 순서 보존, R-036) 그대로.
- 지금 버튼 넷에서 8배로 가려면 한 번, 한 단추에서는 세 번 누른다 — 이것이 유일한 손해다. 1배 ↔ 2배 사이가 가장 잦은 전환이라 체감은 작다(엔딩 플레이 시간의 `offSpeed` 집계에는 영향 없음).
- 검토하고 버린 대안: ① `<select>` 「1배 ▾」 — 휴대폰에서 시스템 선택창이 뜨고 `GuardedButton` 가드를 못 거치며 모양을 토큰으로 못 맞춘다 ② 길게 누르면 메뉴 — 발견하기 어렵다 ③ 분절 컨트롤 4칸 — 44 × 4 = 182px라 한 줄에 글 버튼 둘(222px)이 못 선다(A′로만).

### 4-2. 모바일에서만 바뀌는 둘

- **일시정지는 아이콘만**(이름 「일시정지/다시 진행」은 sr-only, 아이콘 ⏸/▶ 교체) — 지금 320px 규칙(`max-width: 359px`)을 360에도 적용한 것. 이름이 상태를 전하는 방식(copy.md)은 sr-only로 그대로다.
- **「다음 결정으로」「자동 모드 꺼짐」은 아이콘 없이 글만**(`.icon { display: none }`) — 아이콘(18 + 간격 8)을 두면 한 줄 필요 폭이 362 > 328이다. 자동 모드 켜짐은 색 반전 + 아래 막대 + 글자 「켜짐」으로 알리므로 아이콘이 없어도 색에만 기대지 않는다. PC(≥ 960)에서는 둘 다 지금처럼 아이콘 + 이름.
