# 디자인 자산 출처와 라이선스 (SPEC-003 DS8)

**한 줄 요약: 외부 이미지·글꼴·아이콘·음원을 하나도 쓰지 않았다** — 예외 하나는 첫 화면 일러스트로, 형진 님이 ChatGPT(OpenAI)로 생성해 제공한 그림을 designer가 다듬었다(아래 표의 「첫 화면 한반도 일러스트」 행, 출처·약관 확인 포함). 그 밖의 모든 그래픽은 designer가 직접 그리거나 코드로 만들었다. 라이선스를 확인하지 못한 자산은 쓰지 않는다는 규칙(`.claude/agents/designer.md`)을 그대로 지켰다. 3차(REV-003-D-1 반영)에서 심볼을 A안으로 확정하고, 4차(REV-003-D-2 반영)에서 수저 아이콘을 실루엣 + 닫힌 표식으로 다시 그리고 상태 바 색을 바꿨으며, 5차(REV-003-D-3 반영)에서 은·금 표식을 밝은 채움으로, 상태 바 색을 다시 골랐고, 6차(REV-003-D-4 후속)에서 상태 바 색을 명도 차·색각 기준으로 한 번 더 조정했지만 출처 방식은 같다(전부 직접 제작). 색각 시뮬레이션은 공개 논문의 행렬 수치(Machado 외 2009)를 옮겨 적어 계산한 것이지 자산을 들여온 것이 아니다. 통계 값은 `src/data/koreaStats.json`(developer가 출처를 확인한 공개 통계)에서 읽는다.

## 글꼴 결정 근거와 대안 (C15, 마스터 확정 대기)
- 지금은 시스템 글꼴이다: 용량 0, 외부 요청 0, 라이선스 의무 0, 기기마다 눈에 익은 글꼴로 보인다. 단점은 기기마다 모양이 다르다는 것(워드마크는 직접 그린 도형이라 영향 없음).
- 모든 기기에서 같은 글꼴을 원하면 후보는 **Pretendard**(SIL Open Font License 1.1)다. 도입하려면 (1) 형진 님 또는 마스터가 받아도 된다고 승인, (2) 글꼴 파일을 저장소에 넣고(외부 CDN 금지) `OFL.txt` 전문과 저작권 표기를 이 문서에 추가, (3) 하위 집합(subset) 방식으로 초기 로드 400KB 한도(CM6)를 확인해야 한다. 이번에도 파일을 받지 않았다.

## 참고 캡처('80억 분의 1')와의 관계
- 형진 님이 보낸 캡처 5장은 **구조·흐름만** 참고했다. 이미지는 저장소에 복사하지 않았다(로컬 경로로만 열람).
- 그래픽·색·배치에서 복제하지 않은 것(`docs/spec/SPEC-003-개편.md`의 「가져오지 않는 것」과 대조)

| 캡처에 있는 것 | 이 디자인 |
|---|---|
| 적갈색(크림슨) 띠 + 청록 강조 색 조합 | **쪽빛(남색) + 놋쇠색 + 한지색** 바탕. 띠·강조색에 적갈색·청록을 쓰지 않았다(▼·건강 같은 뜻 있는 붉은 계열 토큰은 따로 있고, 캡처와 자리·역할이 다르다) |
| 세리프 글꼴의 큰 이름 | 시스템 산세리프 굵은 글씨 |
| 픽셀 아트 얼굴·장면 일러스트 | 벡터 평면(둥근 곡선) 얼굴, 장면 일러스트 없음 |
| 세계 지도 점 그래픽, 출생 국가 비교, 종교 | 없음(한국 지역·한국 통계 중심) |

## 실존 인물·상호·단체 심볼
- 얼굴은 특정인을 닮게 그리지 않았다(연령대·성별·외모 단계의 일반형).
- 시안의 이름(이서연·김도윤 등)은 흔한 이름의 조합으로 가짜 데이터이며 특정인과 무관하다. 시안의 직업·주소·수치(통계 카드·확률표 제외)는 가짜 값이고 화면마다 「시안 · 가짜 데이터」 표기가 있다. 지역과 수저는 고정관념과 어긋나게 섞었고 계층 상징 지명을 쓰지 않았다(R-125). 실제 상호·기업·브랜드 이름은 쓰지 않았다.
- 한반도 실루엣은 어느 단체·기관의 기존 심볼(한반도기 등)을 본뜨지 않았고, 항상 숟가락과 한 묶음이라 겹치지 않는다(단독 사용 금지, 하늘색 계열 금지 — `design-system.md`). 분단선·경계·색 구분이 없다.
- 시안의 통계·연구 인용 문장은 **자리 표시**다(「기관·저자(연도), 자료 이름」). 실제 값·인용은 M6a 근거 수집(EV1)에서 원문 확인 뒤 채운다.
