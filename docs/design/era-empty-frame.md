## 1. 캡션 자리 (세 안 공통 — 제안 1)

| 항목 | 값 | 근거·측정 |
|---|---|---|
| 글자 | `--fs-xs` 12px · 보통 굵기 · `--c-text-2` · 줄 높이 1.3 · `word-break: keep-all` | 작은 글자이되 하한(12px) 그대로. 대비: 파인 면(`--c-surface-2`) 위 **7.53 / 7.61**(라이트/다크) · 띠 바탕(`--c-surface`) 위 **8.65 / 8.78** — 캡션 규격 ⑧(≥ 4.5) |
| PC(카드 536, 칸 175×140) | 캡션은 그림 **아래** 줄. 그림 상자 = 칸 − 캡션 = **175×118**(한 줄 23px). 그림(좌표 40×32, `slice`)은 위아래 약 11px(8%)씩 잘린다 | `.era`를 `grid-template-rows: minmax(0,1fr) auto`로, 그림 SVG는 상자에 절대 배치(상자의 5:4 고유 높이가 칸을 키우지 않게). 캡션이 두 줄이면 그림 상자 175×102 |

| 휴대폰 띠(카드 ≤ 480, 칸 326×80) | 그림 100×80 그대로, 캡션은 그림 **옆** 둘째 칸(폭 218px, 18자까지 한 줄). 「예측」 칩이 있으면 칩(정적 배치, 위 8px) 아래 4px | 그림·칩을 가리지 않는다(규격 ④) — 측정 단언 통과 |

| 교차 페이드 | 그림과 같은 `.era__prev` 방식(캡션은 요소 교체) | 규격 ⑤ — 시안은 정적이라 보이지 않는다. developer가 `usePrevWhileSwapping` 키에 캡션을 포함하면 된다 |

- **글자 200% · PC(1280, 3열 유지)**: 캡션 한 줄 38px → 그림 상자 175×102(위아래 14%씩 잘림), ≥ 7자는 두 줄(69px) → 175×71. SPEC의 필수 점검은 **360 + 200%**(넘침 0 통과)라 PC 200%는 그대로 두었다. 잘림이 거슬리면 대안: 컨테이너 쿼리를 `max-width: 480px` 대신 **`30rem`**으로 바꾸면 글자 112% 이상에서 PC 카드도 띠 배치(집 전폭 + 창 띠)가 된다 — 다만 집 그림의 크기가 바뀌므로 SPEC-013 「안 할 것(시대의 창 이외 변경)」에 걸려 마스터 결정이 필요하다. 시안에는 넣지 않았다.
- 캡션은 창 전체 링크(`a.era`) 안에 있어 누르면 그해 기록 줄로 가는 동작이 그대로다(규격 ③). 툴팁·hover 글이 아니다(②).

## 2. 세 안의 규격 (제안 2)

공통: `.era__pic--empty > svg`(점무늬) 없음. 칸 바탕 `--c-surface-2`(집 그림 칸과 같은 쟁반) 그대로. 빈 해 `.era[data-empty]`와 가리기 켠 해 `.era[data-hidden]`이 같은 틀.

| 안 | DOM(`EmptyFrame`) | CSS | 강제 색상 |
|---|---|---|---|
| A 「고른 면」 | `<span class="era__pic era__pic--empty">` 빈 상자 | 없음(바탕만) | 칸 테두리(기존 `.era { border: 1px solid CanvasText }`) |
| **B 「빈 종이」** | `… <i class="era__sheet"></i>` | `.era__sheet { position:absolute; inset:6px; background: var(--c-surface) }` | `.era__sheet { border: 1px solid CanvasText }` |
| C 「사진 모서리」 | B + `<i class="era__corner era__corner--tl">` ×4(tr·bl·br) | `.era__corner { position:absolute; width:10px; height:10px; background: var(--c-border-strong) }` + 모서리마다 `clip-path: polygon(…)` 삼각, 종이 모서리(6px)에 붙인다 | `.era__corner { background: CanvasText }` |

- 크기 실측: 360 띠에서 종이 88×68(모서리 10) · PC 빈 해 163×128 · PC 가린 해 163×106. 색 단차 종이/쟁반 **1.15:1**(장식 — 대비 요구 없음, 카드 면↔파인 면의 기존 단차와 같다) · 모서리/종이 **4.02 / 4.29**.
- 그림 바이트 0(CSS뿐), 글꼴 조각 영향 0(새 글자는 캡션 「가려 둔 장면」뿐 — 모두 조각 안, T6 ② 확인은 developer). `era-paper` 패턴 `<defs>`가 사라져 `EmptyFrame`이 더 작아진다.
