## 1. 결론 먼저

1. **톤 추천 = A 「바랜 인쇄물」**(2절). 세피아(10년대마다 다르게) + 30° 망점 + 종이 한 겹. 1950~60년대 세피아 → 70~80년대 바랜 컬러 → 90년대 선명 → 2000년대 디지털(망점이 사라진다)로 **시대가 톤에서도 읽힌다**. 톤은 그림 바깥 CSS 필터(바이트 0) + 그림 안 한 겹(장당 ≈ 20B)이라 비용이 거의 없고, 집 그림(종이 오림, 필터 없음) 옆에 두면 「같은 그림체의 옛 인쇄물」로 읽혀 창이 따로 놀지 않는다(2:1 실제 자리 실측 — 시트). B 「색 빠진 사진」은 작은 칸에서 조금 더 또렷하지만 집 그림과 「같은 그림체의 다른 색」으로만 보여 시대감이 약하다.
2. **정교화**: 장당 평면 조각 **평균 59개(36~96)** — r1 16개의 3.7배. 뒤(먼 건물·하늘·관중석)·가운데(주제)·앞(바닥·소품·밀린 그림자) 세 층, 빛은 왼쪽 위에서(그림자는 오른쪽 아래, 창 빛은 바닥 위 평면 웅덩이), 시대 디테일(연탄 구멍·양은 도시락·다이얼 구멍 열 개·발 내린 창·버스 뒷문 계단·타일 줄눈·투표함 봉인 띠). 반복 질감(관중·돌담·책등·타일·망점 등 11개)은 **공유 `<pattern>`**으로 덩어리에 한 번만 들어간다(762B).
3. **무거운 장면은 빼지 않는다(r2)** — 연표의 큰 사건은 모두 그림을 둔다(4절 ○ 23장). 다만 **상징과 장소로만**: 1979 가을은 정지 화면이 뜬 텔레비전과 빈 방석 둘, 1980년 5월은 금남로의 가로수·내려진 셔터·길 위 신발 한 켤레, 1987은 기표소 커튼과 봉인된 투표함. 참상·시신·피·군·무기·불·깃발·구호·실존 인물·정당 상징 0. 장면마다 FT3 판단을 시트 캡션과 4절 표에 적었다. 「무거운 장면 가리기」는 설정으로 남기고 **기본값은 끈다**(r1의 「상한 10년마다 2」는 푼다).
4. **해마다 「사건」과 「일상」 중 무엇을 띄울지(3-1절)**: 사건이 있는 해는 사건, 없는 해는 그 10년의 **일상 그림 4장 중 플레이어 나이대에 맞는 것**(어린이·청소년·청년/어른·모두). 가리기를 켠 해는 r1처럼 빈 칸이 아니라 **그해의 일상 그림**으로 바꾼다(제안 — 물음 2). 1940~2025 = 사건 **61장**(+ 대안 둘째 장 7) + 일상 **36장**(10년마다 4) = **97~104장**, 빈 해 0.
5. **예산(5절)**: 12장 실측 장당 gzip **1,095B**(톤 겹 포함, 개별) · 12장 덩어리 **9,310B** + 공유 패턴 762B. 104장 추정 **≈ 84KB**(한 줄 문장까지) — `family` 한 덩어리에 넣기에는 크므로 **10년 하위 덩어리 9개**(각 ≈ 10.4KB, 한 줄·패턴 포함 ≤ 11KB)로 나누어 **판 하나가 한 번에 받는 양 ≤ 16KB**를 지킨다. 새 예산 제안: 장당 ≤ 1.5KB · 10년 덩어리 ≤ 16KB · 창 전체(지연, 누적) ≤ 110KB.

## 3. 규칙

### 3-1. 고르기 `eraOf(year, ageBand, settings)` — 순수 함수 (r2)

1. 그해에 **승인된 사건 그림**이 있으면 사건. 둘이면(1980 5월/컬러 TV 등) **무거운 쪽을 우선**하고, 둘 다 무겁지 않으면 `hash01(seed,'era',year)`로 하나(같은 판에서는 같은 그림).
2. 없으면 그 10년의 **일상 그림 4장** 중 플레이어 나이대(`ageBand`: 어린이 0~12 · 청소년 13~19 · 청년/어른 20~ · 모두)에 맞는 것. 맞는 것이 둘 이상이면 **직전에 보인 것과 다른 것**을 고른다(같은 그림이 연속 3해를 넘지 않게 — 생활 틀 반복 문제 해소).
3. **무거운 장면 가리기**(`settings.gentle`, 기본 꺼짐)가 켜지면 ○ 그림 대신 **2의 일상 그림**(r1 「빈 칸」 → r2 변경, 물음 2). 인생 기록 시대 줄은 가리기 부품(`.veil`)으로 문장을 가린다(FM2d 그대로).
4. **빌드 단언**: 1940~2025 모든 해 × 나이대 셋에 1 또는 2가 닿는다. 미승인(`approved: false`)은 빌드가 뺀다 → 2로 내려간다. 일상 36장을 **사건보다 먼저 승인**받으면 빈 칸이 없다.
5. 전망 구간(2026~)은 2025 세트 유지 + 시대 줄의 「전망」 칩(FM2d). 칸 안에 표시 없음.

### 3-2. 그림 규칙(공통, r2)

- 좌표계 **40×32 전체**(r1의 가운데 40×20 띠 규칙 해제 — PC 175×140·휴대폰 100×80이 모두 5:4라 잘림 0). 바깥 1단위는 중요한 것을 두지 않는다.
- 세 층(뒤·가운데·앞) + 밀린 그림자(`shade`, 빛은 왼쪽 위). 조각 **평균 60 안팎, 상한 100**. 반복 질감은 공유 패턴(`eraR2Lib.mjs#ERA_DEFS` 11개 — 망점·관중·돌담·타일·마룻장·책등·건물 창·셔터·자개·벽지·발)으로.

## 5. 예산과 덩어리 (r2 실측 `era-window-r2-budget.json`)

| | 장 수 | 개별 gzip(톤 겹 포함) | 덩어리 gzip | 한 줄까지 | 비고 |
|---|---|---|---|---|---|
| 12장 실측(1970~80년대) | 12 | 13,138B(장당 **1,095B**, 832~1,368) | **9,310B**(비율 0.71) + 공유 패턴 762B | 9,886B | 조각 평균 59(36~96) |
| 104장 추정 | 104 | 113.9KB | 80.8KB | **83.8KB**(+패턴 84.5KB) | 한 덩어리로는 FH8 75KB를 넘는다 |
| **10년 하위 덩어리 하나** | 11~12 | 12.6KB | 9.1KB | **≈ 10.4KB(+패턴 11.1KB)** | 판이 그 10년에 들어설 때 받는다 |

- **새 예산 제안**: 장당 개별 gzip ≤ **1.5KB** · 10년 하위 덩어리 ≤ **16KB**(한 줄·패턴 포함) · 창 전체(9덩어리 누적, 지연) ≤ **110KB**. `family` 조각 ≈ 14.1KB + 표 ≤ 30KB에 창 한 덩어리를 더해도 **판 하나가 한 번에 받는 양 ≤ 60KB ≤ 75KB(FH8)**. 86해를 완주하면 창 덩어리 9개를 차례로 받아 누적 ≈ 95KB — 첫 화면 초기 로드(400,000B)와는 무관(FT5). 마스터가 FH8 문구(「family 합계 75KB」)를 「한 번에 받는 양」으로 읽어도 되는지 확인해 주시면 좋다(물음 — 마스터).
- 비율 0.71은 r1(0.57)보다 높다 — 장면마다 다른 조각이 많아 중복이 적기 때문. 공유 패턴과 재사용 조각(책상·투표함·크레인·모니터·추모의 꽃)을 늘리면 0.6대로 내려갈 여지가 있다.
- 조각 수 예산(집 그림 110)과는 따로 센다(마스터 결정 그대로).

## 6. 데이터 모양(제안 — developer FM5, r2)

```ts
type EraPicture = {
  id: string; years: [number, number]; decade: 40|50|60|70|80|90|2000|2010|2020;
  kind: 'event' | 'daily'; topic: '생활'|'문화'|'경제'|'사회'|'스포츠'|'재난'|'정치';
  hCode?: string; ageBand?: '어린이'|'청소년'|'청년'|'어른'|'모두';   // daily만
  line: string;            // 시대 줄 문장(≤ 22자) = 접근 이름 · title
  heavy: boolean;          // 가리기 설정 대상(기본 꺼짐) → 켜면 같은 10년의 daily로
  approved: boolean;       // 형진 님 사건별 승인 — false면 빌드가 뺀다
  ft3: string;             // 판단 한 줄(시트 캡션 그대로, 코드 주석/검수용)
  draw: (h) => string;     // 40×32, 토큰만, 공유 패턴 url(#era-*) 참조
};
// 덩어리: eraPictures[decade] — 10년마다 하나(지연), ERA_DEFS(공유 패턴)는 family 덩어리에 1회.
// 톤: CSS — .era__pic[data-dec="70"] svg { filter: … } (라이트/다크 표는 2-2절), 그림 안 겹은 draw가 toneLayer()로 붙인다.
```
- `eraOf(year, ageBand, settings)` 시험: 전 해×나이대 닿음 · heavy + gentle → 같은 10년 daily · 사건 둘이면 heavy 우선 · 같은 시드 같은 그림 · 연속 3해 같은 daily 없음 · 전망 해 = 2025.
