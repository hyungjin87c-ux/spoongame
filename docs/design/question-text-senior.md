## 2. 판단이 필요했던 문장 (형진 님께) — **승인 2026-11-08: 모두 추천안 그대로**(대안·고침 없음)

1. **13 `senior-last-wishes`** ○ — 「정리할 때라는 생각, 무엇을 남길까?」는 `text`의 낱말만 썼고 자해·죽음을 직접 말하지 않는다(규칙 7). 그래도 「정리할 때」가 무겁게 읽히면 대안(「정리할 때가 왔다는 생각, 어떻게 할까?」)도 같은 낱말이라 차이가 작다 — 더 누르려면 「가까운 이들에게 남길 말, 어떻게 할까?」(21자, label 「전한다」와 다름)를 쓸 수 있다.
2. **2 `senior-illness`** ○ — 「검사를 더 받을까 약으로 지낼까?」는 label(「적극적으로 치료받는다」 「약으로 버틴다」)을 그대로 쓰지 않고 `text`의 「검사를 더 해 보자」와 되물었다. 「약으로 지낼까」가 한쪽 선택지에 가깝게 느껴지면 대안(가).
