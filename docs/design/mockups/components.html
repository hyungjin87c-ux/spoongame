눌림 상태는 색 반전 + 굵은 아래 막대 + aria-pressed로 알립니다. 터치 대상은 44×44px 이상. 비활성은 둘: 진입 직후 0.4초 입력 가드(과도 상태)는 0.55 흐림, 지속 비활성(「다음 결정으로」 — 자동 모드 내내·선택지 대기 중, 「생각 남기기」 — M7c 전)은 옅은 글자(--c-text-3) + 점선 테두리로 글자 4.5:1을 지킵니다(라디오 카드 「준비 중」과 같은 모양, 2026-10-17 — 구현 R-337).

도구 줄 (모바일) — BGM 켜짐·다크모드 켜짐 상태, 「생각 남기기」 준비 중(M7c 전)

켜짐 = aria-pressed="true" + 색 반전 + 아래 막대 + 아이콘 교체(다크모드: 달 → 해) + 읽기 전용 「켜짐」. 이름은 낱말 단위로 두 줄까지 줄바꿈. 「생각 남기기」는 M7c까지 지속 비활성(점선·옅은 글자) + 버튼 안 「준비 중」 알약(.tool-soon — 라디오 카드 「약 1시간」의 메타 알약과 같은 모양, R-326): 눌러도 아무 일이 없고 접근 가능한 이름은 「생각 남기기 준비 중」. 알약만큼(약 19px) 도구 줄이 높아지는 것은 받아들였다.
