## 4. 부품과 구현 메모 (developer)

- **새 토큰 0 · 새 색 쌍 0 · 새 아이콘 0 · 새 글꼴 파일 0.** 쓴 색 쌍은 모두 `contrast-report.md`에 있다(보조 글 `--c-text-2`/`--c-surface` 8.65 · `--c-surface-2` 7.53, 고른 칩 글자 `--c-on-brand-soft`/`--c-brand-soft` 10.45, 칩 테두리 `--c-border-strong`/`--c-surface` 4.02 · `--c-surface-2` 3.49 — 다크 각각 8.78·7.61·9.87·4.29·3.72). 체크 표시는 스프라이트 `i-check`.
- **고르기 단추**: `button.chip-opt`(첫 화면 「시·도 칩」과 같은 부품) + `aria-pressed`, 묶음은 `role="group"` + 제목·설명 연결. 라디오가 아닌 까닭: 라디오는 방향키만으로 값이 바뀌어, 고르면 접히는 이 패널이 첫 방향키에 닫힌다. 보이는 높이 36px, 굵은 포인터에서 `::after`로 위아래 4px씩 늘려 44px(`--hit`), 줄 간격 8px이라 누르는 영역이 겹치지 않는다. 「넘기기」·「바꾸기」는 `.btn--sm`(44px).
- **고르면** 그 시기의 묻기가 끝나 상시 줄로 접힌다(계약 5-1의 `sec` 올림). 누른 칩이 사라지므로 포커스는 「바꾸기」로 옮긴다. 접힌 직후 같은 자리에 「바꾸기」가 드러나므로 연타의 둘째 탭이 떨어지지 않게 `GuardedButton` 입력 가드(400ms)를 건다(계약 4 연타).
- **「바꾸기」**는 `aria-expanded` + `aria-controls`로 같은 칩 묶음을 카드 안에 펼친다. 펼친 동안 글자는 「닫기」.
- **나타날 때** 포커스를 가져가지 않는다(부모 카드와 같은 비모달). 화면 읽기 사용자에게는 늘 있는 낭독 영역에 위 「등장 낭독」 한 문장을 한 번 넣는 안을 제안한다.
- **수동 결정 시트가 열린 동안**은 바깥이 inert라 바꿀 수 없다. 코어는 대기 중 변경을 허용하지만(5-2), 시트는 사람이 고르는 카드 전용이라(PD8 a) 시트 안에 넣지 않았다. 시트를 접거나 고른 뒤 바꾼다.
- **배치(안 A)**: `SceneCard` 뒤, `LogCard` 앞. `@media (max-width: 959px) { .focus-card { order: -1; } }` 하나로 한 열에서 그림 바로 아래에 온다(order −1 묶음은 DOM 순서: 결정 카드들 → 그림 → 이 카드 → 시대의 창).
- **CSS 원문**: `focus.html`의 「제안: 마음 쓸 곳」 블록. 안 A만 고르면 `.focus-band`·`.focus-chip`·`.focus-row` 규칙은 버린다.
- **확인한 것**: 다크(라이트와 같은 구조), 강제 색상(칩 테두리 CanvasText, 고른 칩 Highlight + 체크 모양), 글자 200%에서 세 안 × 여섯 상태 × 360·320폭 36경우 모두 가로 넘침 0·상자 밖 글자 0, 시안 콘솔 오류 0, 외부 요청 0. WebKit은 보지 않았다.

## 7. 확신이 낮은 곳

- 「더 자주 마주칠」: 사건이 두세 개뿐인 주제(13~19세 「일」 등)는 노출 비가 작을 수 있다. 측정(2-5절)에서 1.3 아래 주제가 남으면 「마주칠 수 있을 뿐」으로 바꾸는 안을 둔다.
- 목록은 Q6 재분류 전의 어림이다. 건강·일이 더 줄면 두 개짜리 목록이 생길 수 있는데, 두 개짜리 캡처는 만들지 않았다(칩 수만 다르다).
- 안 A는 자동 모드에서 인라인 결정이 떠 있는 몇 초 동안 화면 밖에 있다. 이것을 「방해하지 않음」으로 볼지 「눈에 띄지 않음」으로 볼지는 플레이로 확인해야 한다.
- 등장 낭독 한 문장과 입력 가드는 제안 수준이다(계약에는 없다).
- 시대의 창이 빈 틀인 해(17·44세)는 승인 그림이 없는 해의 실제 화면이다.
